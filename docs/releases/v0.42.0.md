# AgentNave v0.42.0

App 新增「技能」页：这里列出 AgentNave 推荐的协作写法，做成可选 Skill，装到哪个宿主由你决定。第一个是代码评审门控 `agentnave-review`，8 个评审角色各用哪个 CLI、哪个模型，也直接在这页里选。

## 新功能

- 「技能」页：每个可选 Skill 一行，展开后可以看说明和完整写法。点宿主按钮即可安装或停用；新接入的宿主会自动出现在按钮里。由别的方式安装的副本显示为灰色，App 不改动。
- 评审门控 `agentnave-review`：创建或更新 PR、要求评审或合并前，主控按失败风险把改动定为 R0–R3 级，通过 AgentNave 派只读评审工位，逐条裁决问题、续接原工位复核，并在 PR 上留评审记录。默认关闭。
- 评审工位：正确性、架构、安全、性能、测试可靠性、简化、专项、反证 8 个角色，各自可以指定 CLI、模型和思考档位，选完立即保存。宿主用不了所选 CLI 时，改用宿主自己的子代理；模型不在组员里时，改找提供同一模型的其他 CLI。
- `list_members` 回执新增 `review`，给出每个评审工位能否使用、原因和可替代的 CLI。

## 改进

- macOS 上三个窗口按钮和顶部导航合到同一行，浅色和深色模式下颜色都与页面一致。按住顶栏空白处可以拖动窗口，双击可以缩放。
- 左侧工作区列表的长名称改为省略显示，不再出现横向滚动条。

## 升级

在 App 内选择「全部更新」，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.42.0"
```

- 「全部更新」会更新 App、本机服务和由 App 管理的 Skill。手动升级时还需安装同版本 App，并把外部管理的完整 `agentnave-manager` Skill 目录（含 `references/`）更新为 `v0.42.0`。
- MCP 工具、保存的历史和 `members.json` 都不需要迁移。评审工位存在单独的 `review.json` 里，旧版服务不读这个文件，所以只先更新了 App 时，组员配置照常可用。

# AgentNave v0.60.1

## 更新

- **Windows 端可以收到更新了**：发布流水线新增 Windows 安装包与更新签名。此前 release 只带 macOS 资产，`latest.json` 没有 `windows-x86_64`，所以 Windows 上的「检查更新」永远认为已是最新。
- 更新检查默认先直连 GitHub，失败才走国内镜像；镜像不再可能用「无更新」的响应挡住真正的发布。
- 首次安装本机服务时，直连失败会先试 `--offline`（依赖已在 uv 缓存时可用），再试清华镜像。

## 修复

- 升级到新版本目录后，宿主配置会自动切换到新启动器，不必逐台点「改用新启动器」。
- 装回旧版 App 时，宿主的 Skill 不再被强制降级，避免「Skill 旧、服务新」的分裂状态。
- 下载失败会丢弃缓存的更新条目，重试时重新检查各更新源，而不是锁死在同一个镜像。
- 取得安装权后重新比对版本，避免并发时重复安装或把服务降级。
- 裸命令接入的宿主不再被静默忽略：汇总栏与导航角标会计入「启动器仍是旧的」，卡片上给出迁移操作。
- 启动顺序固定为「初始化宿主 → 完成服务升级 → 刷新宿主条目」，不再有启动期竞态。

## 升级

- App：Windows 用安装包覆盖安装，macOS 走应用内更新或替换 App。
- 本机服务：App 启动时会自动跟到自身版本；运行中的旧服务不受影响，宿主下次启动生效。

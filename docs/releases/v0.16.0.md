# AgentNave v0.16.0

Studio 的任务和节目创建、续接自动返回看板入口。导演页默认进入后台，首页显示运行与待审状态；公共页保持公开条目白名单，并区分主持人与同名席位。

## 工具与上下文

- Studio 从 15 个 MCP 工具收缩到 14 个，移除 `open_dashboard`。旧调用改为 `list_conversations`，它会提供已有历史的首页地址；内部看板启动方法仍复用。核心八个工具不变。
- 主持人发言、会话修改与审核决定只返回小回执，不再回传整份历史、正文或私密指令。完整状态仍由 `read_conversation` 显式读取。
- 审核回执只确认决定已保存；进行中的轮次随后提交和收尾，使用 `wait_round(include_output=false)` 确认终态。恢复轮次的提交情况按真实记录报告。
- 精简调用 Skill，保留原生权限、持续会话、盲答与审核边界。没有万能 action 路由、新依赖或后台进程。

## 看板稳定性与空闲开销

看板启动失败不会回滚保存、重复执行任务或丢失成功句柄。标准库并发 HTTP 服务避免空闲连接阻塞；无人浏览时暂停后台全量扫描与运行投影，隐藏标签页暂停轮询。读取故障显示过期状态并可恢复。读探测锁竞争只允许一次短暂交接等待，不抢占另一宿主的写锁。

## 升级

从本 tag 同步升级两个已安装包。使用 Studio 的宿主应将 `agentnave` MCP 注册指向 `agentnave-studio-mcp`，随后重连；仅升级包不会切换宿主已运行的服务。保留数据目录、排除项和 Provider 原生配置。运行时安装不会覆盖宿主 Skill 自定义内容；核对后更新完整 Skill 目录。

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.16.0"
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.16.0#subdirectory=packages/agentnave-studio" --with "git+https://github.com/TimWongUp/agentnave.git@v0.16.0"
```

现有 CI 在 Linux、macOS 和 Windows 验证格式、lint、类型、测试、构建和已安装 launcher 后自动创建 tag 与 Release。该发布不向包索引上传。

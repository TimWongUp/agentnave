# AgentNave v1.13.1

修复宿主接入后遗留的自身排除项与已恢复的连接中断提示：宿主自身的 CLI 不再被旧排除项挡住，重连后旧提示自动消失。

## 更新

- **宿主排除项**：宿主自身的 CLI 只按 App 的宿主 CLI 选择处理，环境变量 `AGENTNAVE_EXCLUDED_PROVIDERS` 中与当前宿主相同的项不再覆盖它；只排除其他 Provider 的项照常生效。
- **连接中断提示**：同一配置行之后出现健康连接即视为恢复，旧的「连接已中断」提示自动消除；带标识的配置行只认相同标识的故障记录。
- **子 CLI 与中继**：派发出的子 CLI 不再继承父宿主的身份与连接标识变量；中继清理超期记录时，同时清除写入中断留下的暂存文件。

## 升级

- App：应用内更新或替换 App 后，App 启动或刷新时会自动清理已接入宿主配置里遗留的自身排除项，并清除已被当前健康连接覆盖的旧连接中断提示。升级前已在运行的宿主按提示重连或重开一次，即可按新服务与清理后的配置运行。若从 v1.12 或更早版本升级，仍适用 `v1.13.0` 起 `agentnave.db` 单向迁移到 schema v3 的说明，见 [v1.13.0 发布说明](v1.13.0.md)。
- 手动安装：从 `@v1.13.1` 重装运行时与 Skill 并重连 MCP。

# AgentNave v0.38.0

长任务不再像卡住：App 的作答气泡会写明 CLI 正在思考还是在用哪个工具，以及上次输出是多久前。boss 同时派出好几个任务时，可以直接等「收件箱」，不用逐个记 ID。任何 CLI 跑偏都能打断后用原会话续接重问，Grok 也一样。

## 改进

- 运行中的任务和席位，输出超过一分钟没变时，「正在作答」下面会显示「思考中 · 上次输出 10 分钟前」「正在使用 Read」等，不再只挂着一行旧输出。
- `wait` 可以不传 `ids`，改为等收件箱：本服务上所有还没收到终态的任务和轮次，可用 `manager_session_id` 只看本 boss。每个终态只送达一次；没有待等项时立即返回 `nothing_pending`。
- `read_conversation` 新增 `limit`，长会话只取最近若干条，略去的条数在 `omitted`。

## 修复

- Grok 任务被取消或提前失败时也能拿回原生 `session_id`，可以续接重问。之前只有正常结束才有。

## 升级

在 App 内选择「全部更新」，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.38.0"
```

- `wait` 和 `read_conversation` 的参数有变化，升级后请重连各宿主的 MCP。
- App 与本机服务一起更新才能看到新的进度显示；旧 App 会忽略这些新字段，不影响使用。
- 保存的历史不变。

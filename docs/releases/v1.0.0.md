# AgentNave v1.0.0

第一个正式版。1.0.0 是最低兼容版本：早于它的程序和数据只做一次性迁移，不再保留运行时兼容分支。架构基线见 [ADR 索引](../adr/README.md) 与 [ADR-0050](../adr/0050-v1-compatibility-baseline.md)。

## 更新

- **菜单栏数字**：macOS 菜单栏的运行数和 N 拼成一张图标，可在「设置 → 常规 → 菜单栏数字字体」选择字体（默认 Futura）。数字变化时播放一次水滴动画，开启「减少动效」时只换数字。
- **无头 Linux 指引**：新增 [Linux 装完后的设置指引](../linux-after-install.md) 与 [无头 Linux 宿主接入指引](../linux-headless.md)。README 的宿主列表加上 Grok Bot，它只作为 Linux 宿主，不接入 macOS／Windows App。
- **不装 App 时的设置**：可以手写 `settings.json` 设置同时运行上限和消息保留天数，详见安装指南的 “Settings without the App”。
- **资源回收**：服务会回收用完的锁文件、孤儿席位目录，以及释放满 90 天仍无人认领的空交接工作区。这些回收不受保留天数控制。

## 修复

- 升级服务后，宿主不再沿用旧的工具定义导致所有调用失败；中继探测的迟到回复不再发给宿主；被 kill 的子进程会被回收，不再残留僵尸进程。
- 语音报错改为单独显示，不会被会话刷新清掉；点「关闭」、改设置或下一条播报成功后才消失。窄窗下对话栏会避开报错条。
- 摘要模型下拉框不再列出 TTS、图片、音乐、Embedding 等专用模型。已保存的选择和手填入口不变。

## 变更

- **升级在宿主重连后生效**：App 启动时按版本安装配套服务。各宿主要重连 MCP 后才用上新版本；宿主卡片在版本落后时直接提示重连，不再显示「更新中」。
- **会话库升级到版本 2**：服务第一次打开旧库时迁移。早期版本留下的旧身份会话（没有 boss 聊天身份的记录）会连同席位目录一并删除。旧库在迁移前，App 只能查看，删除、改名、交接和清理会提示先重连宿主。
- **Codex 始终可以在 Git 仓库外运行**：去掉「允许在 git 仓库外运行」开关和 `cli-options.json`，`list_members` 不再返回 `cli_options`，磁盘上的旧文件会被忽略。
- `role` 不再兼当 `explorer-*`／`worker-*` 工位名，编排工位请用 `seat`。评审角色名照常可作 `role`。
- 正式安装包不再包含界面 mock 数据。
- 消息列表里的头像圆角与右上角菜单一致。语音栏的 boss 头像加了一圈 boss 色的环。

## 升级

- App：走应用内更新，或直接替换 App。App 启动后会安装 1.0.0 服务，**之后逐个重连各宿主的 MCP**。
- 手动安装：用 `@v1.0.0` 重装运行时和 Skill，然后重连 MCP。
- 迁移会删除旧身份会话，这一步不可逆。需要保留的话，升级前先备份数据目录（默认 `~/.agentnave`）下的 `agentnave.db`。

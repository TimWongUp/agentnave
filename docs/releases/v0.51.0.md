# AgentNave v0.51.0

派出去的 CLI 默认就能跑命令了：权限改为按 CLI 设档位，缺省「自动」。

## 新增

- 设置页每个 CLI 可选权限档位「自动」或「完全放开」，点选即存，私聊和新开的会议都按它派发，与模型无关（「不限模型」和没列出的模型也生效）。
- 「自动」交给 CLI 自带的自动审核：Claude Code、Grok 用 `auto` 模式，Antigravity 用 `auto`，Codex 用 `--approve-for-me`；CodeBuddy（自带 auto 在派发时仍拒绝命令）和 DeepSeek（没有自动审核）直接完全放开。Pi 没有审批机制，不设档位。
- Codex 新增 `approve_for_me` 选项，续接时用等效配置。
- Claude Code 或 CodeBuddy 报成功、但途中有工具调用被拒时，结果带 `warnings` 提醒任务可能没做完。

## 变化

- 升级后没有改过设置的 CLI 也会按「自动」派发，不再保持原生权限；回执 `defaults_applied` 会列出套用的参数。CLI 自己配置得比「自动」更宽的（例如 Codex 设了 `danger-full-access`），请在设置页改选「完全放开」。
- 组员模型上手写的权限参数由 CLI 档位取代。boss 按你的明确要求显式传权限参数时，仍以它为准。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.51.0"
```

- 从 v0.48.0 或更新版本升级时，App 先展示更新内容，确认后按需升级服务、安装 App 并自动重启。
- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.51.0 的完整目录。
- 重连 MCP 可看到更新后的工具说明。历史与设置无需迁移。
- 从 v0.50.0 或更早版本升级的，另见 [v0.50.1 发布说明](v0.50.1.md)；从 v0.45.0 或更早版本升级、接入过 Gemini CLI 的，按 [v0.46.0 发布说明](v0.46.0.md) 处理旧配置。

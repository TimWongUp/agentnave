# AgentNave v0.58.0

并联轮单席失败及时提醒并支持轮内补跑；工作区区分桌面与终端来源，接入页按实际配置目录分行，同时改进长期引用回收和异常退出清理。

## 新功能

- 并联轮仍有席位运行时，失败或受阻席位使 `wait` 提前返回 `reason=seat_lost`，每席一次；只报告状态和错误，不交付答案或运行尾部。
- `run_round(group_id=..., retry_seats=[...])` 在全员结束前补跑失败或受阻席位，沿用本轮快照与私密指令，结果仍计入同一轮。串联与已结束轮次需另开一轮。
- 工作区根据会话记录区分 Claude 桌面、Claude Code、Codex 桌面和 Codex CLI；无法识别时保留原宿主名称。
- 接入页对读取不同配置的 Claude 桌面与 CLI、多套 Codex 目录分别列行，同一实际目录的别名只计一次。

## 修复与改进

- 补跑启动回执保留同轮已完成答案，待审核或终态正常交付；串联失败后仍优先交付待审结果。
- 回收已结束 collector、过期任务映射和已落盘且已交付的轮次正文，保留未读、待审与保存失败结果。
- POSIX 启动取消关闭状态管道；Windows 启动取消抵抗重复取消并排空输出管道，父进程句柄配合创建时间校验防止 PID 复用，服务退出关闭 Job 回收进程树。
- 同一会话在 worktree 等目录留有多份转录时读取最新一份，恢复 boss 模型与交接路径识别。
- 修复多目录接入的备份文件名、软链去重顺序、启动探测完成后的历史来源补查和技能页徽标。
- 更新宿主图标与角色动画，补齐 Windows 托盘 CI 检查和安装包构建。
- 澄清等待顺序：先完成不依赖结果的当前工作，再单独 `wait`；交付前收齐全部终态。

## 升级

通过 App 更新，或手动安装配套服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.58.0"
```

- App、服务与完整 Skill 目录使用同一版本；更新后重启或重连宿主以刷新工具参数。
- 历史、组员配置与认证无需迁移。
- 来源识别依赖会话中的非公开字段，升级 CLI 后可能退回原宿主名称；Windows、Linux 的桌面来源识别未做完整实机联调。
- 真实 CLI 登录失效与轮内补跑未做端到端验收，相关自动测试使用假 Provider。
- 此前升级说明见 [v0.57.0](v0.57.0.md)。

# AgentNave v0.52.0

boss 聊天可以把整个工作区交给另一个聊天接手；办公室新来五位同事。

## 新增

- 新工具 `handover`：只在你要求时，boss 把本聊天的整个工作区交出（可附交接说明），新聊天列出待接手的工作区并认领，之后在原工作区继续派活。老 boss 被接手后不能再派活，也不能用同一聊天另开工作区。App 的工作区右键菜单新增「交给其他 boss 接手」，工作区列表会显示「待接手」或「boss 已更换」。
- 识别 boss 模型的宿主更多了：除 Codex、Claude Code 外，还能从 Pi、CodeBuddy、WorkBuddy、Grok、Antigravity、Hermes 的原生会话读出 boss 模型。Claude Code 里没传 `manager_session_id` 时，改用 `CLAUDE_CODE_SESSION_ID`。
- 新增 Kimi、MiniMax、混元、豆包、Muse 五位小人。Grok 重修：头发剪短，紫色眼睛，加了一条会摆的恶魔尾巴。GPT 和 Gemini 的尾巴、DeepSeek 的耳朵会轻轻动。boss 工位跟着工位一起放大缩小。

## 修复

- 会议席位的完整回答每轮只交付一次；`wait` 返回运行快照时，已答完的席位不再提前交出全文。
- 同一原生会话在运行期间跨服务加锁，会议席位和私聊不能同时续接它。
- 有多个待审串联轮时，不会超出同时运行的上限。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.52.0"
```

- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.52.0 的完整目录。
- 重连 MCP 才能看到新工具 `handover`。数据库首次打开时自动加表，历史与设置无需迁移；旧版服务不认交接。
- 从 v0.50.1 或更早版本升级的，另见 [v0.51.0 发布说明](v0.51.0.md)。

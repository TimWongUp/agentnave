# AgentNave v0.27.0

“接入与更新”按各宿主实际收到的工具接口判断是否需要重新加载，不再仅因 App 或服务版本变化要求所有宿主重启。

## 自动检测

- 工具接口不变的服务更新在空闲时自动切换；接口变化时，中继向支持的宿主发送工具列表变更通知。
- 宿主卡片区分“接口已同步”“等待空闲更新”“需要重新加载”“无法自动确认”和“已手动确认”。重连后自动检测，不必逐个点击确认。
- 同一宿主有多个可见连接时一起检查；手动确认不会掩盖仍使用旧工具接口的连接。
- 配置和 Skill 按实际内容判断变化，版本号或版本标记变化不再单独触发提醒。首次安装或尚未确认的 Skill 变化仍需单独确认，MCP 连接不能证明 Skill 已加载。
- 自动刷新保留正在编辑的高级配置；宿主退出后立即移除连接观测，避免退出期间切换服务造成残留。

## 升级

在 App 内检查更新并安装，再查看各宿主卡片。旧版中继需重新连接 AgentNave MCP 一次，才能启用自动检测；必要时完整退出并重新打开对应宿主。仅重启 AgentNave 不会替宿主更新已有中继。

检测只覆盖已提供观测的连接；“接口已同步”证明工具列表已送达，不证明聊天模型已经采用新版工具，也不能证明 Skill 已加载。观测只保存版本与接口摘要，不保存提示词、工具正文、环境或凭据。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.27.0"
```

本版保留 v0.26.0 的办公室、工位访问等级与角色协作规则，已有历史和 Provider 权限不变。

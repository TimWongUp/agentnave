# AgentNave v0.39.0

App 不再替你决定默认模型：没设置时，每个 CLI 就用它自己的默认模型和档位，设置页会把它们显示出来。DeepSeek 选官方模型时能直接用 App 里保存的 key。办公室的会议更像真的开会：散会后大家走回工位，会议室才慢慢收起；右侧消息按办公软件的方式写。

## 改进

- 设置页未设置默认值时显示「跟随 CLI 默认 模型 · 档位」，档位条标出 CLI 自己的档位，模型列表里标出「CLI 默认」。默认值来自各 CLI 自己的设置；CodeBuddy 取其支持列表的第一项，Grok 取其模型缓存标注的默认档位；读不到就显示未知，不做猜测。
- 办公室里没有指定模型的工位，按 CLI 默认模型显示。
- DeepSeek 设置页列出 dsh 配置里各 provider 的真实模型。
- 会议列表最新的在前。散会时小人先走回工位，停 10 秒后会议室向上收起。
- 右侧消息改为「任务」「议题」「私下交代」「转发」「待你审核」等说法，回复归在所属消息下面。
- 工位小人的动作节奏各不相同，不再整齐划一。

## 修复

- DeepSeek 选 `deepseek-flash` 等官方模型时，headless 模式下读不到已保存的 key。现在官方路由默认打开 `stored_credentials`，显式传 `false` 仍然生效。
- DeepSeek 选配置中网关 provider 声明的模型时，会被错当成官方模型。
- 并联轮次的回答按公布时间记录，顺序会跳。现在按各席位完成的时间记录。

## 升级

在 App 内选择「全部更新」，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.39.0"
```

- 旧版 App 首次启动时预填进 `members.json` 的默认模型和档位会继续生效；想跟随 CLI，在设置页清除对应默认值。
- MCP 工具和保存的历史都没有变化。

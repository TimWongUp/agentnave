# AgentNave v0.48.0

更新改成先看更新内容，确认后一次完成。

## 更新

- 点更新时先重新检查，弹窗列出当前版本之后各版更新了什么，确认后才更新；窗口顶部、设置页、菜单「检查更新…」和菜单栏面板都打开这同一个弹窗。
- 确认后一次完成：下载新版 App，本机服务比新版旧时先升级服务，再安装 App 并自动重启；弹窗按这三步显示进度。服务升级失败就停下、不装 App，可在弹窗里重试。
- 重启后窗口右上角显示「已更新到 v<版本>」十分钟。
- 更新说明随更新清单带最近十个版本；你的版本更早时，弹窗另给 GitHub Releases 链接。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.48.0"
```

- 从 v0.47.0 升级仍走旧版 App 的流程：先更新 App 并重启，重启后自动升级本机服务。新的更新弹窗从下一个版本起生效。
- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.48.0 的完整目录。
- 工具接口没有变化，无需重连 MCP。历史、组员配置与设置无需迁移。
- 从 v0.45.0 或更早版本升级、接入过 Gemini CLI 的，按 [v0.46.0 发布说明](v0.46.0.md) 处理旧配置。

# AgentNave v0.31.0

第一次使用 App 时，会给每个 CLI 预填它的主力模型作为默认模型。办公室里的工位因此一开始就有明确的模型，不再大量显示「默认模型」。工位卡片的几处显示问题也一并修正。

## 新功能

- 数据目录里还没有组员配置时，App 会探测本机 CLI，写出首份配置。
  - 「任务」和「讨论」两种模式都列出全部 CLI，并且不限模型。放行范围和以前一样。
  - 能确定主力模型的 CLI，会设为两种模式的默认模型：
    - Codex：模型缓存里优先级最高的 GPT 模型；
    - Claude：`opus`；
    - Antigravity：`agy models` 的第一项；
    - Grok、DeepSeek：各自标为默认的模型。
  - Pi 和 CodeBuddy 的模型列表不标默认模型，所以不预填，继续用各自原生的模型。
  - 只在配置不存在时预填一次。之后以你在设置页的修改为准，App 不再补填。
- 在设置页开启「自选可用工具和模型」或启用某个 CLI 时，也会预选它的主力模型。

## 修复

- 工位笔记本上的 logo 现在位于盖子中心。之前默认终端标志会往下偏几个像素。
- 「只读」「可写」改为蓝色描边标签（只是 boss 声明的约定），「只能开会」保持灰色实心标签，两者容易区分。
- 工位卡片顶部给标签留出位置，人物和办公桌整体下移，不再顶到标签。

## 变更

- 首次预填后，默认模型会代替 CLI 自己设置的模型。想继续用 CLI 原生模型，在设置页清除对应 CLI 的默认模型即可。
- 预填会生成组员配置，两种模式因此变为受限。以后版本新增的 CLI，需要在设置页手动启用。取舍见 ADR-0020。

## 升级

在 App 内检查更新并安装，再按各宿主卡片提示重启或重连。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.31.0"
```

已有的组员配置不会被改动。已有会话和 Provider 权限保持不变。

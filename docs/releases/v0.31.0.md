# AgentNave v0.31.0

托盘 App 的设置页做了一轮修正，离开页面不会再丢掉未保存的修改；办公室里 boss 旁边新增待办板。运行期间不再持续整份写盘，托盘轮询也轻了很多。中继现在也能为按新 MCP 协议连接的宿主（如 Claude Code）在空闲时换用新安装。

## 新功能

- boss 办公室只占左半边，右半边放「boss 待办」：待审、进行中、最近失败三栏，每栏最多 3 条；三栏都空时列出最近活动的工位。点一条就切到对应的会议室或工位。宽窗口里有进行中的会议时，右半边照旧放会议室。
- 首次没有组员配置时，App 按各 CLI 的主力模型预填默认模型（Codex 取优先级最高的 `gpt-` 模型、Claude 为 `opus`、Antigravity 取列表第一项、Grok 与 DeepSeek 取标为 default 的模型；Pi 与 CodeBuddy 不预填）。写出后不再补填，也不覆盖你的修改。见 ADR-0020。

## 修复

- 设置页：
  - 有未保存的修改时，离开设置页会先提示「继续编辑 / 放弃修改并离开」，标签上也会亮点提示。
  - 关闭「自选可用工具和模型」前会先确认；关闭后保留各 CLI 的默认模型，只清除名单和该场景的专用设置。见 ADR-0021。
  - 取消最后一个思考档位时，不再清空默认档位。
  - 宿主页汇总显示需要重新加载的宿主数量，标签红点也算上它们。
  - 检查更新后会显示「已是最新版本」；未安装的 CLI 标为「未安装，暂不可用」；值为 false 的权限参数不再告警。
  - 界面里的「模式」统一叫「场景」，并修正了路径截断、状态行残留等多处细节。
- 宿主接入：
  - 移除 JSON 配置里唯一的条目后再接入，文件能按字节还原，不再留下错位的括号。
  - 备份改为配置文件和 Skill 文件分开计数，各保留最近 30 份，宿主配置文件的备份不会再被 Skill 文件挤掉。见 ADR-0015。
- 中继：按 2026-07-28 协议连接、不发 `initialize` 的宿主（如 Claude Code），中继现在也能在空闲时换用已安装的新版本，切换时宿主的订阅不中断。
- 办公室：工位 logo 居中；访问等级（只读、可写）与「仅开会」用不同样式区分；工位场景整体下移，不再顶到标签。

## 性能

- 运行文件 `live/*.json` 升到版本 2，只写运行中任务与席位的回复尾部和回报模型；内容不变时只刷新修改时间。此前长会话运行时每 1.5 秒整份重写，最大约 450 KB。
- 托盘按修改时间缓存解析结果，数据没变时复用路由响应；服务端扫描跳过未变化的会话，常驻内存减少。

## 升级

在 App 内检查更新并安装，再按各宿主卡片提示重启或重连。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.31.0"
```

托盘与服务需一起升级：旧托盘读不到新服务的版本 2 运行文件，运行中只显示状态、不显示流式尾部；新托盘仍能读取旧服务的运行文件。已有会话、组员配置与 Provider 权限保持不变。

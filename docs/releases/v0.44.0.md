# AgentNave v0.44.0

一次不改变当前功能的精简清理：删掉不再使用的代码、资源和早期版本的迁移逻辑，文档只保留当前版本需要的内容。

## 移除

- App 不再迁移 v0.20 之前的 `profiles.json` 档案，设置页的迁移提示一并移除。数据根里仍只有 `profiles.json`、没有 `members.json` 的安装，组员设置会从空白开始。
- App 不再把宿主配置里 v0.22 及更早的 `agentnave-studio-mcp` 命令改写为 `agentnave-mcp`，也不再在升级本机服务时卸载旧的 `agentnave-studio` 工具。残留的旧命令条目显示为自定义命令；缺失的 `agentnave-mcp` 路径仍会自动修复。
- 托盘不再把 v0.35 之前的审核值 `discard` 当作不公开；v0.37 起的 SQLite 存储从未导入这类记录。
- 删除不再使用的头像精灵图、看板与托盘中的对应路由，以及多处没有元素使用的样式。

## 文档

- README 精简为上手说明和工具一览，合同细节见 Skill、会话指南与架构文档。
- 安装指南只保留当前版本的升级说明，历史升级说明见各版本发布说明。
- Codex 与 Antigravity 的 YOLO 选项说明移入 `agentnave-manager` 的对应 CLI 参考，并修正 Antigravity 传 `false` 时的实际行为描述。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.44.0"
```

- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.44.0 的完整目录。
- MCP 工具、历史、组员配置与评审工位配置无需迁移。
- 仍只有 `profiles.json` 的安装，请在 App 中重新设置组员。仍残留 `agentnave-studio-mcp` 条目的宿主，请在 App 中移除该条目后重新接入，或把命令改为 `agentnave-mcp`；旧的 `agentnave-studio` 工具仍在时运行 `uv tool uninstall agentnave-studio`。

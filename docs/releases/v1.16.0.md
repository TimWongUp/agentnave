# AgentNave v1.16.0

办公室新增内嵌 CLI 终端，可以直接在 App 里打开终端对话，并调整了办公室与左栏布局。

## 更新

- **办公室终端**：直接在办公室打开真实 CLI 终端并对话；Claude 和 Codex 可从历史记录续接，检测到会话在其他程序中运行时会先提示确认。终端跟随 App 深浅外观。DeepSeek Harness 和 ZCode 没有终端界面，不出现在新建终端菜单中。（#475）
- **办公室和项目布局**：左栏「项目」旁可新建项目并打开第一个 agent；办公室、左栏与右栏统一显示 agent 名称，终端区域在窄窗口下也更易使用。（#475）
- **旧终端会话**：macOS 和 Linux 的「需要重开」提示逐条列出旧终端会话，可查看工作目录和启动时间，并在确认后结束指定会话。（#464）
- **工位选择**：编排工位的 CLI 下拉只列员工中启用的 CLI，已保存但停用的选择仍会标明状态。（#462）
- **转发消息**：私聊中一次转发多条消息时会按顺序标号，方便接收方逐条处理和在 App 中回看。（#470）
- **配额阻断**：模型额度不足时，可按提示在同一 CLI 中选择其他可用模型续接原会话；Codex 的第三方路由模型分别计算冷却状态。（#471）
- **待跟进事项**：任务和会议结果收齐时，会提示仍需关注的失败或阻断事项以及保留的隔离目录。（#472）
- **等待结果**：同一聊天重复发起阻塞等待时，后一次会立即返回提示，避免重复等待和唤醒。（#474）
- **工位选择稳定性**：决策模型遇到网络连接或超时问题时会再尝试一次，减少临时网络故障导致的选择失败。（#463）
- **Antigravity 交互派发**：使用 agy 原生终端状态识别任务进度，不再需要安装交互 hook；需要 agy 1.5.10 或更新版本。（014f8d48）

## 升级

- App：应用内更新或替换 App，按提示重连宿主。本版没有数据库结构变更。
- 手动安装：从 `@v1.16.0` 重装运行时与 Skill 并重连 MCP。
- 从 v1.14 或更早版本升级，仍适用 [v1.15.0](v1.15.0.md)、[v1.14.0](v1.14.0.md) 与 [v1.13.0](v1.13.0.md) 的升级说明。

# AgentNave v0.57.0

等待分为常规等待和按需核验两档，减少 boss 反复接收运行正文的上下文开销；App 内置同版本服务 wheel，并复用代理和 uv 镜像设置。

## 改进

- `wait_seconds` 仅接受 `0`、`240`，省略时最多等 240 秒。完成、阻塞或待审仍提前返回。
- 普通等待仅返回状态和最近活动；显式 `0` 才附带每个运行任务或会议工位最多 1000 字符的公开正文尾部。正式答案、阻塞原因、待审内容和交付规则保持原样。
- handover 接手后先读交接说明、可用的旧 boss 聊天尾部与相关会话，信息不足时扩大回读；交接说明可指向必要 worktree 和未提交工作。
- App 内置配套运行时 wheel，更新包也包含目标版本 wheel；安装和更新复用登录 shell 探测到的代理、uv 镜像变量，已有服务在线解析失败时尝试离线缓存。
- 拆分托盘舞台投影和超长测试模块，复用路由校验及可执行文件检测，保持现有行为。

## 升级

通过 App 更新，或手动安装配套服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.57.0"
```

- App、服务与完整 Skill 目录使用同一版本，更新后按提示重启或重连宿主。
- 旧调用中的 `1`、`45`、`300` 等等待秒数会被拒绝；常规省略参数，到期后继续等，不例行补调 `0`。
- 240 秒为已观察到的单次 300 秒宿主超时留出余量，不保证适合更短超时的宿主。
- 历史、组员配置与认证无需迁移。此前升级说明见 [v0.56.0](v0.56.0.md)。

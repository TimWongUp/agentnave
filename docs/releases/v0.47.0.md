# AgentNave v0.47.0

GPT 与 DeepSeek 换上新小人，办公室布局随窗口铺满，主窗口记住大小。

## 新小人

- GPT（Codex 等）的小人换成白龙娘，DeepSeek 的换成蓝色鲸鱼女仆，工位、会议室、菜单栏头像共 27 帧全套替换。
- 在 App 里替换过这两个家族小人的，继续用你的那套。

## 办公室

- 开放工位每行固定 4 个、均分铺满；窗口窄到单个工位不足 170px 时依次减为 3、2、1 个。
- 工位里的椅子、小人、桌子随卡片等比缩放，小人整体也比之前大一些。
- boss 区上下留白收紧；窄窗口下「最近对话」「会议」与 boss 贴得更近。
- 工位左上角只留权限标签，状态改在小人动作、气泡和悬停提示里；「休息中」不再带时长。
- 工位角色完整显示，最多两行；菜单栏面板里其他办公室一行只显示标题和头像，行高与办公室卡片一致。

## 主窗口

- 首次打开为 1440×900，居中，不超出屏幕；之后关闭或退出时记住大小，下次按它打开。最大化、全屏时不记。

## 开发

- `scripts/preview_tray.sh` 把当前分支编译成「AgentNave 预览」，与正式版并存、读同一份数据，但不改数据、宿主配置与 Skill，不更新也不升级服务，方便目测界面改动。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.47.0"
```

- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.47.0 的完整目录。
- 工具接口没有变化，无需重连 MCP。历史、组员配置与设置无需迁移。
- 从 v0.45.0 或更早版本升级、接入过 Gemini CLI 的，按 [v0.46.0 发布说明](v0.46.0.md) 处理旧配置。

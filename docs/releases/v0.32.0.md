# AgentNave v0.32.0

托盘 App 的办公室换了新布局：boss 办公室占满一行，两边是最近对话和会议；进行中的会议室搬到工位上方。角色补了几个新动作：刚完成任务会庆祝一下，失败时会沮丧，去开会时会走过去。本版只改托盘 App，服务端不变。

## 新功能

- 办公室布局：
  - boss 办公室占满一行，boss 在正中间。左边是「最近对话」，进行中的排在前面，并标出处理中、失败等状态；右边是「会议」，进行中的排在前面，并标出待审。两栏都显示三行，更多的在栏内滚动，点一条就切到对应的工位或会议室。原来的「boss 待办」由这两栏代替。
  - 进行中的会议室放在 boss 办公室和开放工位之间，占满一行，人多时自动换行。结束的会议只出现在「会议」列表里。
  - 会议室去掉了会议记录白板。席位只显示角色标签和模型名：角色标签挂在桌子前挡板上，颜色和工位标签一样；模型名写在桌子下方。CLI 名改为鼠标悬停时显示。
- 角色动作：
  - 工位和会议席位的人物一样大，走去开会时不再缩放。
  - 任务刚完成的工位会显示约 8 秒的完成神态，气泡里写「搞定」。
  - 上次失败的工位显示沮丧神态（头顶有汗珠），不再是把待命图调成灰色。
  - 去开会和回工位时，人物用两帧正面走路图走过去，每个人起步的脚不同，走路途中目的地的座位先空着。
- 美术：
  - 7 个角色的待命和眨眼都重画了，看不到手：手揣进口袋或缩进袖口。
  - 新增可选帧 `sad`、`walk-1`、`walk-2`。自定义角色可以只画基础的 7 帧，缺可选帧时，失败沿用灰色待命图，走路沿用坐着滑过去的效果。见 `apps/tray/ART-SOURCES.md`。
  - 默认形象「新同事」改为黑发。
  - 桌子前挡板改为镂空，能看到桌下的腿和脚，并补画了后桌腿；椅子补了气杆、五星脚和轮子；不在工作时，桌上的笔记本是合上的。

## 升级

在 App 内检查更新并安装。本版服务端没有变化，不需要重启或重连宿主。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.32.0"
```

已有会话、组员配置与 Provider 权限保持不变。

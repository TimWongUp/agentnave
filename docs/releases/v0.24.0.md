# AgentNave v0.24.0

App 宿主接入现在会自动安装和更新配套 Skill，并在界面中明确说明生效方式。

## 宿主 Skill

- 显式接入宿主时自动安装 `agentnave-manager` Skill；接入结果会区分自动安装、已是最新和外部管理。
- 启动、刷新检测和服务安装完成后的自动刷新，会为已有新版 `agentnave` 用户级入口的宿主补装缺失 Skill。
- 自动补装要求事务前后都保留新版 `agentnave` 入口；未接入宿主、自定义命令、外部 Skill、符号链接和其他入口不会被写入。
- Skill 安装失败会在后续刷新继续重试；显式接入写入 MCP 后，即使 Skill 首次安装失败，也会保留当前进程内的 manual root 供自动修复。
- 设置页移除“补装 Skill”操作，Skill 缺失时直接说明会自动安装。

## 生效提示

每个宿主卡片新增独立的“生效”说明，明确要求重启宿主应用或新建会话后应用 MCP 与 Skill 变更。WorkBuddy 仍需在修改配置后到“自定义连接器 › MCP 服务管理”重新信任 MCP。

## 升级

在 App 内更新并重启 AgentNave。重启后打开“设置 › 宿主接入”，点“刷新检测”即可自动补齐已接入宿主的 Skill；已有的外部 Skill 保持不变。

更新 MCP 或 Skill 后，重启对应宿主应用或新建会话。WorkBuddy 还需重新信任 MCP。

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.24.0"
```

本版本没有数据格式或工具合同变更；已有宿主配置、会话数据、Provider 权限和原生会话所有权保持兼容。

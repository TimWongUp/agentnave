# AgentNave v1.4.0

新增 Devin CLI 员工与 boss；高级编排重整为两档授权与五个专项，编排方法移入 Skill；等待窗口改为 270 秒，CLI 硬阻断会自动冷却；办公室支持可选视频小人包。

## 更新

- **接入 Devin CLI**：Devin 可作为员工和 boss，支持「自动」「完全放开」两档权限，托盘补齐它的桌椅与标志。未信任的工作区归为受阻。
- **高级编排重整**：
  - 写进宿主全局规则的编排段只保留授权。
    - 分工协作：并行写入须用户本人对当前任务指明；新增「boss 可主动开会」开关，默认只在用户要求时开会。
    - 并行分工：并行写入和开会由 boss 判断。
    - 详见 [ADR-0068](../adr/0068-rules-hold-authorization-skill-holds-method.md)。
  - `agentnave-manager` Skill 新增选执行者、简报详略、收尾两行，以及多任务方法 `references/workflows.md`（并行写入、流水线、择优、反证）。
  - 专项收敛为五个并各带范围：界面制作、写作、网页调研、社交平台调研、办公文件制作。
    - 界面制作改为普通专项，不再沿用通用执行。
    - 专项默认一个模型，可打开「区分难度」。
    - `list_members` 的 `orchestration.scopes` 给出各角色范围。
    - 详见 [ADR-0065](../adr/0065-predefined-specialist-roles.md)、[ADR-0069](../adr/0069-interface-seat-as-specialist-and-single-model-specialists.md)。
  - 评审工位区只在打开评审 Skill 时显示，新增「统一评审模型」。
- **等待窗口 270 秒**：
  - `wait` 单次最多等 270 秒，`wait_seconds` 只接受 `0` 或 `270`，可选 `seq` 区分连续等待。
  - App 把支持条目级工具超时的宿主下限设为 360 秒。
  - 详见 [ADR-0066](../adr/0066-unified-wait-window-and-call-sequence.md)、[ADR-0067](../adr/0067-wait-270s-window-and-host-background-limits.md)。
- **CLI 硬阻断冷却**：
  - 登录、计费、额度类阻断会让该 CLI 冷却 15 分钟。期间拒绝派发，工位标为不可用并给出替换建议；任一成功调用即解除。
  - 状态记在数据根的 `provider-health.json`。
- **办公室视频小人包**：可选下载视频版小人，代理镜像统一下载；新增 CSS 小人自制指引（[custom-characters.md](../custom-characters.md)）。boss 笔记本外壳显示宿主 logo。

## 修复

- 会议席位运行中显示「思考中／正在使用工具」，进行中的会议卡片显示输入摘要；各 CLI 推理阶段的活动状态补齐。
- 会话接手能匹配 Codex 续接后的 rollout 文件。
- 补齐点名 CLI 派发与会议等待指引。
- 办公室与消息列表滚动布局稳定；切换工作区时保持右侧栏。

## 升级

- App：走应用内更新，或直接替换 App。开着高级编排的宿主会在 App 启动后改写规则段，之前复制到「自定义」里的 v1.3.0 生成句会被迁移。按 boss 卡片提示重开或重连旧宿主副本，新的 `wait` 参数和 `scopes` 字段才会生效。
- 手动安装：用 `@v1.4.0` 重装运行时和 Skill，然后重连 MCP。无头 Linux 宿主按 [无头 Linux 宿主接入指引](../linux-headless.md) 核对 `orchestration.json` 的角色键。

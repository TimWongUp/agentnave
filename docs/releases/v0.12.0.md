# AgentNave v0.12.0

## Explicit conversation cleanup

`delete_conversation(room_id)` permanently removes an archived conversation with no unresolved
work. The calling Agent must obtain user authorization before deleting history. Archiving remains
reversible and does not delete data; the browser remains read-only.

Deletion removes AgentNave history, the private index, dashboard views and associated finished
invocation handles. Native CLI files and nonempty directories are preserved; external root
directories are retained even when empty. The result reports deleted metadata paths, retained
directories and the number of released invocation records. Metadata failures leave a live entry
for retry, with history restored when the index cannot be removed and storage permits recovery.

There is no automatic retention policy, scheduler, bulk cleanup or recycle bin. Provider-native
sessions and user files remain outside AgentNave's deletion ownership.

## Upgrade

Install the runtime and complete manager Skill from the same tag, then reconnect MCP to discover
the new tool. Existing registrations, provider permissions and history formats remain compatible.
The MCP surface now has 17 tools. No existing history is automatically deleted during upgrade.

```bash
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.12.0"
```

## Validation

Coverage includes archived-state enforcement, metadata failure and retry, preservation of native
files, invalidation of deleted views and invocation handles, and restart behavior. Provider calls
in the automated suite use fake executables; this release does not add a provider or change its
native invocation options. Release publication follows the existing cross-platform CI gates.

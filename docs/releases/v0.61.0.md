# AgentNave v0.61.0

## 更新

- **右栏改成目录加聊天**：打开工作区或点 boss 时，右栏先列一会议一卡、一任务一卡的目录，不再混排全部消息；点进去是聊天气泡，boss 在右，员工在左。
- **看工位更清楚**：同一轮其他员工的回答只占一行，点开可看全文。
- **@ 替代「私下交代」**：boss 单独交代某位员工的话用 @ 显示，排在这位员工的回答正上方。
- **名字统一**：到处都是「模型 · 档位」，优先显示 CLI 实际回报的模型，不再有的叫 `opus`、有的叫 `claude-opus-5-5`。Antigravity 模型名末尾的档位也拆了出来。
- **角色放最前面**：气泡旁的角色用紫色放在名字前；评审角色显示中文，如「正确性评审」；`worker-hard` 这类内部档位名不再显示。
- **工位卡片**：努力程度放在左上角，按档位用不同颜色。
- **boss 办公室**：「最近对话」改名「私聊」，只列私聊工位，会议席位不再混进来。
- 部分员工回答时，议题下方用头像和人数提示，不再列一长串名字。

## 修复

- 右栏目录里显示工作区交接说明和「更早的 N 条没有列出」。

## 升级

- App：走应用内更新或替换 App。
- 本机服务：App 启动时会自动跟到自身版本；这版没有改服务接口和历史格式，不需要迁移。

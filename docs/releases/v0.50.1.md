# AgentNave v0.50.1

升级时不再丢失还没取走的会议轮次结果。

## 修复

- 会议轮次刚结束、结果还没被等待取走时，本机服务不再自动换成新版本进程，避免新进程不认识这一轮、等待时报“未知 id”；只用回读会话而不等待的轮次，最多推迟升级七天。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.50.1"
```

- 从 v0.48.0 或更新版本升级时，App 先展示更新内容，确认后按需升级服务、安装 App 并自动重启。
- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.50.1 的完整目录。
- 工具接口没有变化，无需重连 MCP。历史、组员配置与设置无需迁移。
- 从 v0.49.0 或更早版本升级的，另见 [v0.50.0 发布说明](v0.50.0.md)；从 v0.45.0 或更早版本升级、接入过 Gemini CLI 的，按 [v0.46.0 发布说明](v0.46.0.md) 处理旧配置。

# AgentNave v0.53.0

DeepSeek Harness 和 ZCode 现在都能当 boss，ZCode 也能当组员；「节目」改称「会议」，开会默认两轮并联；OpenCode 不再作为宿主接入。

## 新增

- **DeepSeek Harness 当 boss**：App 接入页可以接入 DeepSeek Harness，桌面 App 和 `dsh` 都能识别。App 只增删 `~/.dsh/cordis.patch.yml` 里属于自己的那一项，新条目带 310 秒的工具调用超时，`wait` 不会被提前截断。
- **ZCode 当 boss 和组员**：
  - 当组员时，通过 ZCode 原生 app-server 协议指定模型和思考档位，可以续接原生会话；ZCode 的自动审批尚未实现，两个权限档位都会放开权限。
  - 当 boss 时，App 写入 `~/.zcode/cli/config.json` 的 `mcp.servers`，新条目带 310 秒超时（ZCode 默认 30 秒）。如果 `~/.agents/mcp.json` 里有其他 MCP 服务，App 会拒绝首次接入，并提示先把它们迁过去。
- **CLI 级设置**：与模型无关的组员设置按整个 CLI 保存在新文件 `~/.agentnave/cli-options.json` 里，对该 CLI 的每次调用都生效。第一个是 Codex 的「允许在 git 仓库外运行」，在执行者页的 Codex 卡片上打开。
- **开会默认两轮并联**：`run_round` 这种模式在 Skill、工具说明、看板和文档里都改叫「会议」。用户没说几轮时，boss 先开两轮并联，第一轮各自给方案，第二轮看过上一轮公开的答案再补充，最后由 boss 总结。只有用户要求时才加串联轮收尾。
- **区分 Claude 桌面端**：办公室会把从 Claude 桌面端接手的 boss 单独显示成「Claude 桌面」。
- **README**：改为中文默认，新增英文版，附实机演示。

## 修复

- 菜单栏面板：
  - 深浅色和所选主题保持一致。
  - 四角改为圆角。
  - 点面板以外的地方会自动收回。
  - 组员头像放大。
- 小人：
  - 举手时另一只手不再消失。
  - 头发白边已清理。
  - boss 头上不再显示气泡。
- 托盘：
  - WorkBuddy、Hermes 补上图标。
  - 执行者页的 CLI 图标不再压住名称。
  - 「仅开会」的工位不再变灰。
- 私聊任务失败时，历史里会保存报错原文，不再只有错误码；取消的任务只显示「已取消」。

## 移除

- OpenCode 未经实测，已不再作为宿主接入。`AGENTNAVE_HOST=opencode` 现在是未知值，会让服务启动失败；已有的 OpenCode 历史仍然可以读取。
- agentnave-review Skill 不再规定自己的触发时机，何时评审改由全局规则或用户点名决定。

## 升级

在 App 内选择「全部更新」，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.53.0"
```

- 「全部更新」会更新 App、本机服务和由 App 管理的 Skill。外部管理的 `agentnave-manager` 要换成 v0.53.0 的完整目录，其中新增了 `references/zcode.md`。
- 工具说明里的措辞有变化，重连 MCP 后才会生效。
- 接入过 OpenCode 的，需要手动清理旧配置：
  - 删除其配置中的 `mcp.agentnave`；
  - 删除 App 装过的 Skill 目录，默认是 `~/.config/opencode/skills/agentnave-manager`。
- `cli-options.json` 由新版 App 写入，旧版服务会忽略它。模型级的 `skip_git_repo_check` 继续有效。
- 从 v0.51.0 或更早版本升级的，另见 [v0.52.0 发布说明](v0.52.0.md)。

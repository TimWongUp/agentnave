# AgentNave v0.60.0

新增没有派发过任务的 boss 会话交接，明确并行等待的剩余任务，并修复编排关闭后仍暴露工位、Codex 参数重复及服务升级等问题。

## 新增与改进

- 支持转交只有 boss 的工作区，接手方可通过配套的 `agentnave-handover` Skill 读取交接材料与原生会话位置；App 展示交接状态，并支持删除无会话的工作区。
- `wait` 回执增加 `pending_ids` 与 `all_finished`。收到 `ready` 代表有事件可处理，有剩余句柄时继续等待；执行阻塞和会议待审都不会误判为全部完成。
- 高级编排关闭时，`list_members.orchestration` 明确返回 `enabled=false` 和空工位，派发不套用 Explorer／Worker 默认模型。按实际接入行和共享规则文件分组判断，区分同一 CLI 的多个账号；已保存的工位选择保留。
- App 启动时自动将落后的本机服务跟进到配套版本，不重复安装相同或更高版本，也不回退新版 Skill。更新检查先直连 GitHub，失败后尝试镜像；依赖安装支持缓存回退，保留通过 UV/PIP 环境变量指定的软件源及 Windows 大小写语义。
- 批量测量消息折叠，减少消息较多工作区的打开等待；放大 boss 舞台，增加笔记本翻盖动画，校准角色、头像和桌面摆件的位置。

## 修复

- Codex 首次派发与续接只传一次 `--skip-git-repo-check`，避免 CLI 因重复参数启动失败。
- Provider 连续报重试、五分钟没有其他活动时，以故障结束并清理进程树；静默超过一分钟后重新发生的重试另起一段，不累计之前的短暂故障。正常运行没有总时长上限。

## 升级

更新 App、配套服务和完整 Skills 目录到同一版本：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.60.0"
```

- 工具回执和接入身份发生变化，请在 App 完成接入修复后重连 MCP，让宿主重新读取 schema 与接入行身份。缺少行身份的旧连接不会借用默认账号的编排工位设置。
- 外部维护的 Skill 需同步更新完整目录，包括新增的 `agentnave-handover`；App 管理的 Skill 会随配套升级补齐。
- 历史数据库按需补充交接元信息，无需清空历史、组员设置或凭据。升级期间旧程序可能清理只有 boss 的空工作区交接标记，请一并更新 App 与服务。

# AgentNave v1.15.0

App 新增一键卸载：在设置里就能把 AgentNave 从各个宿主里清干净，任务和会议记录默认保留。

## 更新

- **一键卸载**：设置 → 关于 → 卸载 AgentNave。App 会从所有登记的宿主移除 AgentNave 的 MCP 条目、规则块、它自己装的 Skill 和 agy 的 `agentnave-interactive` hook，关闭开机启动，退出后删除 App 自己的数据；macOS 把 App 移入废纸篓，Windows 由安装器删除程序。有任务在跑时不能卸载；某个宿主清理失败时会列出来并可重试。（#460）
- **默认保留记录**：任务和会议记录（`~/.agentnave/` 或 `AGENTNAVE_DATA_DIR`）默认保留，确认页打开「同时删除任务和会议记录」才会删除。Claude 和 agy 的工作区信任标记、项目级 MCP 配置和各仓库的隔离目录不清理。（#460）
- **只删 AgentNave 自己的东西**：用户自己的 MCP 条目、规则内容和其他 hook 不受影响；用户写的或改过的 Skill 留在原处。（#460）
- **Windows 系统卸载走同一流程**：从「设置 → 应用」卸载时会打开 App 的确认页，取消则保留程序。用新版安装包覆盖升级、应用内更新都不算卸载；没有经过 App 的静默卸载（`/S`）只删除程序文件。（#460）

## 升级

- App：应用内更新或替换 App，按提示重连宿主。本版没有数据库结构变更。
- Windows：v1.14 及更早版本的卸载程序不会清理宿主；想用新的卸载流程，先升级到 v1.15。
- 手动安装：从 `@v1.15.0` 重装运行时与 Skill 并重连 MCP。
- 从 v1.13 或更早版本升级，仍适用 [v1.14.0](v1.14.0.md) 与 [v1.13.0](v1.13.0.md) 的数据库迁移说明。

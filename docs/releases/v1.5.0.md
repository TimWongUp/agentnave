# AgentNave v1.5.0

Devin 改用 ACP 运行，需要确认的操作交给 boss 代答；接入页按配置行识别跨平台宿主的 CLI 与桌面端，连接回执按行归属；修复 macOS 系统通知无法授权。

## 更新

- **Devin 改用 ACP**：
  - 在 `devin acp` 上运行，消息列表显示思考与工具状态。
  - 需要确认的操作交给 boss 代答，只会选「允许一次」或「拒绝」。
  - 模型不可用时直接失败，并列出可用模型。
  - `permission_mode` 只接受 `accept-edits`、`smart`、`ask`、`plan`、`bypass`（`dangerous` 等同 `bypass`），不再接受 `-p` 专有的 `normal`、`auto`、`yolo`、`autonomous`；`respect_workspace_trust` 移除。
  - 详见 [ADR-0070](../adr/0070-devin-runs-over-acp.md)。
- **跨平台宿主识别**：
  - 一份配置一行，卡片内列出发现的 CLI 与桌面端。
  - 连接回执带配置行，同一宿主的多份配置不再互借「已加载」。
  - Windows 认安装登记和应用商店包，Linux 认已知软件包。
  - WorkBuddy 改读 `WORKBUDDY_CONFIG_DIR`，Hermes 跟随活动 profile。
  - 详见 [ADR-0071](../adr/0071-cross-platform-host-readers-and-receipts.md)。
- **员工可用模型**：
  - 新增全选／全不选，每个 CLI 最多选 20 个；隐藏 Devin Fusion 模型。
  - Codex 员工可选运行来源：自动、桌面端内置或独立 CLI。选定的来源缺失时任务报错，不回退。
- **设置说明**：权限档位、单独干活与开会、Claude 交互模式、生图工位、统一评审、完成提醒时长、朗读详略、后台进程和全局规则文件旁加问号提示；外观页显示视频包大小。
- **安装盘背景**：macOS 安装盘换成小人背景，拖进「应用程序」的方向一目了然。
- **编排规则**：点名 CLI 时也经 AgentNave 派发；落在已开启专项范围内的任务交给专项，即使 boss 自己的工具也能做。

## 修复

- macOS 系统通知：安装包改为整包签名，「系统通知」能弹出授权请求，并出现在系统设置的通知列表里。
- 高级编排的「区分难度」开关点击无效。
- 组员工具结束后到下一段回复之间显示「思考中」，等待权限弹框时不显示；补齐 ZCode 工具结束状态，CodeBuddy 的空状态不再冲掉当前状态。
- 视频包装好后不再显示「重新下载」。
- Claude 桌面端是否单独成卡，按 Claude Code 实际写入的配置文件判断。

## 升级

- App：走应用内更新，或直接替换 App。macOS 安装包的签名方式变了，升级后已授予的系统权限（如麦克风）可能要重新授权一次。按 boss 卡片提示重开或重连宿主；同一宿主有多份配置时，每份要重连一次才会显示「已加载」。手写过 Devin `permission_mode` 的，改用新的取值。
- 手动安装：用 `@v1.5.0` 重装运行时和 Skill，然后重连 MCP。

# AgentNave v0.64.0

## 更新

- **会议语音播报**：会议和私聊的消息可以语音播报。会话栏下方有语音频道栏，显示在场成员、正在说话的人和播放控制，可以从头读，也可以自动读新消息。
- **口语摘要**：长消息先由摘要模型改写成口语再朗读，50 字以内的消息直接朗读。摘要会带上说话人和收听者，boss 私聊员工时先点名。摘要平台可以选 ChatGPT 订阅登录、各平台 API Key、Magpie 或自定义 OpenAI 兼容接口。
- **boss 身份跟随实际发言人**：每条记录保存发言的 boss 宿主。接手后的发言显示接手宿主的头像和声音，接手前的发言保持不变。
- **会议总结写回会议**：会议收尾时，boss 把总结写回会议，总结也可以直接播报。
- **设置页**：新增「语音」标签；各标签共用居中的一列；员工卡片的列对齐，思考档位不再超出卡片；交接说明默认折叠，点开再看。

## 修复

- 宿主重启并加载新版工具后，「需要重新加载」「待确认生效」的提醒不再残留或反复出现；短暂的探测连接也能证明新配置已生效。配置再次变化后，旧的生效确认作废。

## 升级

- App：走应用内更新，或直接替换 App。
- 本机服务：App 启动时自动升级到 App 的版本，不需要迁移。升级后每个宿主重连一次，让中继记录新的加载证据。
- 语音默认关闭，需要在设置的「语音」中开启。开启后，要朗读的会话内容会发送给你选择的语音和摘要服务。

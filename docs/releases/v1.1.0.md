# AgentNave v1.1.0

员工页能更新 CLI 了，员工要确认才能派发，语音播放重做了一遍。

## 更新

- **更新 CLI**：员工页显示哪个 CLI 有新版本，一键更新，多个时可全部更新。App 按 CLI 的实际安装位置走原路径更新（CLI 自带命令、Homebrew 或装它的 npm），不用管理员权限。判断不了的、要管理员权限的、随桌面应用附带的只显示版本。详见 [ADR-0055](../adr/0055-app-updates-member-clis.md)。
- **安装命令**：没装的 CLI 折叠在员工页底部，列出官方安装命令，点一下复制，到终端里运行。
- **移除和启用员工**：员工卡片右上角加了按钮，不用再去模型下拉里选「不用」。
- **语音**：
  - 摘要短、标准、详细三档改成硬上限，超长时按句截断。
  - 切换视图、关闭对话栏、切换工作区和隐藏窗口都不再打断播放。
  - 一次播完一个工作区再切下一个，手动点读插到最前。
  - 顶栏语音菜单改成播放器样式。
  - 菜单栏面板显示专辑卡，每张 boss 卡和每间会议室都能点「收听」。
- **Worker 界面工位**：高级页新增界面两档，用于页面、样式、交互和看图的实现，没设时沿用 Worker 同档。
- **正确性评审简单档**：高级页可选第二个正确性模型，R1 低风险改动用它，不选时用正确性工位。
- **评审流程**：`agentnave-review` 让正确性工位看完整 diff，专家按专业合并，合并要等哪些 CI 按用户偏好。

## 修复

- 暗色主题下开关看得清了，主题变量统一。
- boss 交接后，桌椅、笔记本标志和宿主名称立即切换，小人在新 boss 首次派活或主持后切换；旧 boss 的画像挂在相框里，消息很多时也不丢。

## 变更

- **员工要确认才能派发**：只有在员工页确认过的 CLI 才能派发。接入 boss 会自动确认同一个 CLI。升级时 App 按当时已装的 CLI 迁移一次，可用范围不变；不想用的自己移除。详见 [ADR-0054](../adr/0054-members-need-confirmation.md)。
- `list_members` 会标出没装的 CLI。在员工页关掉的 CLI 不能再当工位。
- 移除新手引导。
- 「模型名称」设置从外观移到常规，默认简短。boss 和员工页里没选的排到最下面。
- 编排预设不再决定何时评审；「并行复核」改名「并行分工」，去掉每次实现后的固定复核。

## 升级

- App：走应用内更新，或直接替换 App。App 启动后会安装 1.1.0 服务，**之后逐个重连各宿主的 MCP**。
- 手动安装：用 `@v1.1.0` 重装运行时和 Skill，然后重连 MCP。不装 App 时不受员工确认影响，`members.json` 里没写的场景仍然不限制。
- 设了「正确性（简单）」后，还没重连的旧服务读不了 `review.json`，所有评审工位暂不可用，重连后恢复。

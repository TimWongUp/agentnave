# AgentNave v0.50.0

Qwen、GLM 和 Claude 换新小人，任务结束或卡住时不再被漏掉。

## 更新

- Qwen 换成穿旗袍的清冷大小姐，发簪上的玩偶挂坠会摆动；GLM 换成黑发、黑白衣服的少女，打盹时戴眼罩，呆毛会动。
- Claude 换新形象，去掉呆毛，头后多了一圈星芒，随状态快慢转动；光芒只在头顶上半圈显示，不会被头发挡掉一半。
- 会议室席位上的小人与工位一样大；呆毛摆到最低点时不再出现折痕。
- boss 头上的状态气泡移到右上角，与工位一致，不再压住头像。
- 派发新任务或会议轮次时，回执会列出已结束、遇到阻塞或等待审核但还没取走的任务和轮次（`unreceived`）；`agentnave-manager` 要求派发后立即挂起等待，汇报进度前先核实状态。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.50.0"
```

- 从 v0.48.0 或更新版本升级时，App 先展示更新内容，确认后按需升级服务、安装 App 并自动重启。
- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.50.0 的完整目录。
- 回执只新增可选字段，旧调用方不受影响；重连 MCP 后可看到更新后的工具说明。历史、组员配置与设置无需迁移。
- 从 v0.45.0 或更早版本升级、接入过 Gemini CLI 的，按 [v0.46.0 发布说明](v0.46.0.md) 处理旧配置。

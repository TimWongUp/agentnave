# AgentNave v0.19.0

编排改为严格单向：被 AgentNave 启动的子代理不能再调用编排工具。用户可以在菜单栏应用里维护编排档案，主控用新工具 `list_profiles` 读取；菜单栏应用还能清理会话记录。工作室会话空闲后释放写锁，多个宿主可以接着写同一会话。

## 单向编排

- supervisor 启动 CLI 时设置环境标记。服务入口启动时检查标记与祖先进程，发现自己运行在被 AgentNave 启动的 CLI 之下，或无法判定时，只提供不含工具的服务，并在说明中给出原因。Windows 只检查环境标记。见 ADR-0011。
- `agentnave-manager` Skill 新增“编排场景”：问意见、交叉复核、分头做、同题多做择优、分歧收敛（默认 3 轮）、接力，都是现有调用方式的组合，由主控验收。交接清单补充“试过什么、为何放弃；已定决策及理由”。

## 编排档案与 `list_profiles`

- 档案保存在数据根的 `profiles.json`：名称、CLI、`provider_options`（含模型与 effort）和说明。
- 核心与工作室新增只读工具 `list_profiles`（核心 11 个、工作室 17 个工具）：每次现读文件，文件不存在返回空列表；逐条用与 `start_agent` 相同的参数白名单校验，给出 `valid`、`error` 以及本宿主是否允许该 CLI。服务端不按档案名替主控套参数；用户本轮要求优先，权限类参数只在用户本轮明确要求时才传。
- Skill：用户没点名 CLI 时，主控先读档案按说明选择，再显式传参。

## 菜单栏应用

- 右键菜单新增“管理会话…”：列出全部会话，可按已结束、空闲、失败与时间筛选，单选、多选或清理 N 天前的会话，页内确认后逐条显示结果。运行中、待审核的会话不可删。删除由应用原生完成，取与工作室相同的会话锁，只删 `state.json` 与 `views.json`，保留目录、锁文件和席位文件。见 ADR-0012。
- 右键菜单新增“设置…”：增删改编排档案，保存前检查结构并原子写入；参数是否有效以主控读取时的校验为准。

## 工作室

- 会话写锁不再持有到服务退出：没有运行中的轮次或任务、没有待审回答且已保存时即释放。另一个宿主可以直接续接，菜单栏应用也能清理。会话被删除后不会从缓存重建。

## 升级

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.19.0"
```

随后从本 tag 更新完整的 `agentnave-manager` Skill 目录。各宿主的中继会在空闲时自动换用新服务；要看到 `list_profiles` 与新的 Skill 文字，需重连一次 MCP。菜单栏应用会在应用内提示更新到本版本，更新后也可用面板的“一键升级”安装服务。

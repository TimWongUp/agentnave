# AgentNave v0.7.0

This release unifies lifecycle responses and pairs the runtime with updated CLI handoff guidance.

## Breaking response change

Start, wait and cancel now return flat `invocation_id`, `status`, `reason` and `elapsed_ms`
fields, with applicable `activity`, `error`, `output`, `output_age_ms` and `session_id`.
Callers must migrate from v0.6.0's nested `state`, `snapshot` and `result` responses.
Usage/cost fields and raw event details are no longer returned.

## Waiting and execution feedback

- Wait default and maximum are 600 seconds. Completion and recognized execution blockers return
  early; an expired wait leaves the CLI running. Respect shorter host tool-call limits.
- Running responses carry the latest public reply tail, capped at 1,000 Unicode characters,
  with its age and available native activity. Thinking, tool inputs and tool results are excluded.
- Recognized execution blockers are reported once per category per invocation, in order, without
  stopping the CLI. The Manager decides whether to continue waiting or cancel. Unknown errors,
  ordinary tool failures, retries and silence are not guaranteed to trigger early returns.
- Final output retains the existing capture bound instead of the 1,000-character running limit.

The paired Skill requires explicit Antigravity terminal directories and `pwd` verification before
project operations. Native `project` selection is not a working-directory override. CodeBuddy
guidance preserves native permissions and treats task evidence separately from conversation success.

## Install or upgrade

```bash
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.7.0"
```

Update the complete `skills/agentnave-manager/` directory from the same tag through the existing
Skill installer or deployment manager. Preserve host registrations, environment and exclusions.
Hosts sharing the stable launcher share this runtime update; restart their MCP connections and
load the Skill in a fresh context to use the new schemas. Rollback uses the paired v0.6.0 runtime
and Skill and restores its older response contract. Provider history, credentials and permissions
remain under provider control.

## Verification and limits

The release workflow validates macOS/Linux tests, formatting, lint, types, source archive contents,
distribution installation and MCP tool discovery before publishing. Real provider checks during
development covered waiting feedback and execution blockers; two Antigravity directory probes
also verified explicit terminal `Cwd`. These checks do not certify every desktop host's active
connection. Directory handoff is a behavioral instruction, not enforced isolation. AgentNave
retains in-memory invocation state and does not add persistent output storage.

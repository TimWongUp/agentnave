# AgentNave v0.36.0

App 少打扰：宿主卡片只在真要重开时提示，Skill 更新不再要求重启；办公室最新工位排在最前，空闲工位不会过一阵就睡着；窗口可以像普通 Mac 应用一样收起再原样打开。

## 改进

- 宿主卡片只在需要重新加载时出现提示，去掉“接口已同步”“无法自动确认”“生效”等说明文字。
  - 判断只看 MCP 接入配置和工具接口；Skill 更新不再提示，Agent 使用时会读取最新文件。
  - 当前没有活跃连接的宿主不再提醒，下次连接自然用上新配置；服务切换时心跳短暂暂停不算断连。
  - 提示写明这个宿主的具体重启方式，重开后自动消除。
- 办公室工位按最新在前排列；空闲工位保持清醒，直到办公室在它之后又开出新工位才打盹（同一会议室的席位不算）。
- 右侧对话栏不再显示工位立绘，消息区更大。
- 菜单栏图标旁不再显示“待审 N · 运行 M”，数量保留在悬停提示和面板里。

## 修复

- 点程序坞图标、再次启动或从菜单栏选“打开 AgentNave”时恢复原来的窗口和页面，不再跳回首页；关闭窗口只是隐藏。
- 不公开的会议回答按完成时间计入工位活动（保存的席位记录新增完成时间，旧记录按下一轮开始时间估算）。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.36.0"
```

MCP 工具接口没有变化，无需重连宿主。升级后 App 会忽略旧格式的重新加载记录，此前手动点过的“我已重新加载”随之失效，但不会因此出现新提示。

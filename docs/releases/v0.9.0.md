# AgentNave v0.9.0

## Fixed five-minute waits

`wait_agent` now accepts only `invocation_id`. Each request waits for a fixed 300-second
window, returning early on completion or a recognized execution blocker. Wait expiry leaves
the CLI running; continue waiting with the same ID or explicitly cancel it. There is no total
runtime deadline.

## Caller migration

Remove `wait_timeout_seconds` from callers. Upgrade the runtime and complete
`agentnave-manager` Skill together, then reconnect MCP to refresh the schema. For older
runtimes that still expose the argument, the Skill uses 300 seconds.

In Codex, `Script running with cell ID ...` means the outer script is still running.
Continue receiving that call through `functions.wait` with its `cell_id` before issuing
another AgentNave wait. This is not a timeout or proof that the CLI is stuck.

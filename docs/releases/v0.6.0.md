# AgentNave v0.6.0

This release pairs the MCP runtime with the complete `agentnave-manager` Skill and its five
on-demand CLI references. The Skill covers task handoffs, explicit model options, project
working directories, temporary artifacts, waiting, cancellation and native session continuation.
It does not impose Markdown, result files, or adapter-added prompt instructions.

## Runtime changes

- `wait_agent` reports recent native activity, tool name/call ID, native state, a bounded public
  reply excerpt and observation age. Unknown fields remain null; one observation is not the
  complete state of concurrent work. Tool inputs/results and thinking content are not copied.
- The wait default increases from 30 to 120 seconds. A wait still returns early on completion,
  and its expiry does not stop the invocation.
- `start_agent.timeout_seconds` is now optional. Omitted/null means no AgentNave deadline instead
  of the previous 1,800-second cutoff. Pass an explicit positive value to retain a deadline;
  expiry still terminates the invocation. Provider-native limits remain in effect.
- `describe_provider` no longer returns `defaults` or `guidance`. It reports permitted status
  and supported options; model/effort guidance belongs to the Skill and is passed explicitly.
- Interleaved tool events retain previously observed names by call ID. Invalid event
  discriminators no longer prevent Codex/Grok from preserving valid terminal output/session IDs.
  Activity capture and its temporary name index respect output and invocation-lifetime bounds.

## Install or upgrade

```bash
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.6.0"
```

Install or update the **whole** `skills/agentnave-manager/` directory from the same tag through
the host's Skill installer or existing deployment manager. Keep existing host registrations,
environment and exclusions. Hosts sharing the stable launcher share the runtime update; restart
their MCP connections and load the Skill in a fresh context. Provider authentication, permissions,
history and caches are not migrated. Rollback uses the prior fixed runtime tag; v0.5.0 has no
paired Skill and retains the old schemas/defaults, so treat that choice explicitly.

The [installation guide](https://github.com/TimWongUp/agentnave/blob/v0.6.0/docs/installation.md)
now distinguishes CodeBuddy CLI from WorkBuddy desktop configuration and covers Grok,
Antigravity, Hermes and Skill discovery. Source-archive CI checks ensure all five references ship.

## Validation and limits

The integrated changes passed 94 tests plus format, lint and type checks. macOS/Linux CI builds
and installs the distribution and checks MCP tool discovery. Real STDIO MCP calls verified tool
activity and project cwd for CodeBuddy, Grok, Codex and Antigravity. Claude reported authentication
retries and was cancelled; another explicit-limit run verified timeout behavior, not successful
authenticated Claude execution. These are provider/protocol checks, not complete desktop-host
loading or long-result-rendering certification. POSIX process supervision remains best effort;
AgentNave is not a sandbox, scheduler or persistent workflow engine.

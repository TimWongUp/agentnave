# AgentNave v0.15.0

## Core and studio packages

AgentNave now ships two same-version packages from one repository:

- `agentnave` (core, launcher `agentnave-mcp`) keeps the subagent tools — `describe_provider`,
  `start_agent`, `wait_agent`, `cancel_agent` — and adds in-memory group rounds: `open_group`,
  `run_round`, `wait_round`, `cancel_round`. It creates no data directory, persists nothing,
  listens on no port and writes nothing to the caller's working directory.
- `agentnave-studio` (launcher `agentnave-studio-mcp`) includes every core tool and adds saved
  shows and tasks under `~/.agentnave/` (or `AGENTNAVE_DATA_DIR`), optional review before other
  seats see an answer, host messages, isolated seats, and a local read-only dashboard that starts
  only when `open_dashboard` is called.

Register one launcher per host under the `agentnave` name: the studio replaces the core there
rather than running beside it. The thirteen discussion-room and workbench tools are removed from
the core; the studio keeps the conversation tools (`list_conversations`, `read_conversation`,
`update_conversation`, `delete_conversation`) and its `start_agent` still accepts `title` and
`conversation_id`. `describe_provider` no longer returns `discussion_permitted` (the studio
returns `show_permitted` instead).

## Group rounds

A seat is an ordinary subagent: native tools and permissions, the group's `cwd` or its own, and
explicit provider options. `run_round` asks an ordered list of seats to answer one shared task:

- `parallel`: all seats start together and cannot see each other's answers in this round;
- `serial`: one after another, each seat seeing the finished answers of earlier seats.

Each round's task, answers and absences become entries; every seat receives the entries it has not
yet seen and resumes its own native session, and an optional private instruction goes to one seat
only. Only a successful answer that returns its own native session ID advances that seat's cursor;
other terminal states leave the cursor so the seat's next launch delivers the missing entries.
`wait_round` and `cancel_round` mirror `wait_agent` and `cancel_agent`; cancellation keeps
answers already committed, while serial seats that never started are not recorded. Groups last
only for the server process.

## Studio behavior

- Each conversation keeps one `state.json`, written atomically under an OS lock. The first
  server to write holds the conversation; other servers index and read it without writing.
- With `review=true`, successful answers wait in `pending_review`; `wait_round` returns
  `review_needed`, and `decide_answers` publishes or discards answers as one validated batch.
  Discarded answers never reach other seats; a cancelled round discards undecided answers.
- Restart recovery marks work abandoned by an earlier writer as interrupted, keeps undecided
  reviews pending, and never resumes a native session whose launch was interrupted.
- Isolated seats get their own directory and `restricted_tools`; the studio prepares
  Antigravity's restricted profile there.

## Breaking changes

- The `discussion_mode` provider option is renamed `restricted_tools`.
- Discussion rooms, the workbench and the dashboard tools are removed from the core; hosts that
  used them register the studio launcher instead and move to its tools.
- Antigravity's restricted mode no longer writes into the caller's working directory; it needs a
  dedicated directory that already contains the restricted profile.
- History saved by earlier versions under `~/.agentnave/` is not migrated; the studio lists it
  as unavailable and it can be cleared manually.

## Upgrade

Install the runtime and the complete `agentnave-manager` Skill from the same tag, then reconnect
MCP on every host.

```bash
# core launcher (subagents only)
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.15.0"
# or the studio launcher (adds shows, review and the dashboard)
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.15.0#subdirectory=packages/agentnave-studio"
```

## Validation

The suite adds group-round tests (parallel isolation and unified commit, serial visibility,
private instructions, cursor rules, blocked seats not committed, whole-round and per-seat
cancellation, validation before writes, shutdown) and studio tests for locking, review state,
failed saves and restart recovery, run repeatedly for stability. Real CLI acceptance covered
parallel answers from Codex, Grok and Pi, serial continuation of native sessions, isolated seats,
restart continuation, host messages and the dashboard. Release publication follows the existing
cross-platform CI gates.

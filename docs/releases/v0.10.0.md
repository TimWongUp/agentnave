# AgentNave v0.10.0

## Native Windows support

AgentNave now supports Windows natively. Provider processes are created suspended, assigned to a
kill-on-close Windows Job Object, and then resumed. This preserves AgentNave's process-tree cleanup
contract without requiring WSL or relying on Windows process groups.

The release also adds Windows to the GitHub Actions verification matrix and validates the installed
Windows launcher and MCP tool discovery alongside the existing macOS and Linux checks.

## Install or upgrade

Install the runtime and the complete `agentnave-manager` Skill from the same release tag, then
restart the host's MCP connection so it loads the new runtime and schemas:

```powershell
uv tool install --force --python 3.12 `
  "git+https://github.com/TimWongUp/agentnave.git@v0.10.0"
```

On Windows, register the absolute `agentnave-mcp.exe` path reported by `uv tool dir --bin`.
Existing host exclusions and provider authentication remain unchanged.

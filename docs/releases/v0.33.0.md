# AgentNave v0.33.0

设置页可以直接拖动设定思考档位，新装的模型会自动出现在列表里；更新后也不再要求逐个重开所有 agent。

## 新功能

- 展开 CLI 后，每个模型行的“默认”后面多了一条思考档位条：两端是允许 boss 使用的档位范围，圆点是 boss 未指定时用的默认档。没设范围时允许全部档位。还没设默认档的模型，圆点以虚线预选范围的中间档（例如 Codex 为 medium、Claude 为 high），拖动或点选后才写入；新开始配置的模型直接选上中间档。支持拖动、点选和方向键，与“配置”里的勾选框、下拉框同步。
- 设置页打开时先显示上次的检测结果，同时在后台重新检测本机 CLI 和模型；离开再回到窗口、且距上次超过 30 秒时也会自动检测。列表有变化才提示并刷新，不会打断正在输入的内容。“刷新模型列表”按钮移到底部保存栏，随时可点。

## 改进

- 默认模型优先采用各 CLI 自己设置里指定的模型：Codex `config.toml` 的 `model`、Claude Code `settings.json` 的 `model`、Pi 的 `defaultModel`、Antigravity CLI 的 `model`。读不到时按原规则选；仍选不出就用列表第一个，Pi 和 CodeBuddy 因此也会有默认模型。首份配置仍不写默认思考档位。
- “接入与更新”的宿主卡片不再在每次更新后都要求重开所有 agent：
  - Skill 只改了正文或 references 时不再提示重新加载，只有名称或简介变化才提示。
  - 重新打开宿主或新开会话后，检测到所有连接都是变化之后建立的，提示自动消除，不用再逐个点“我已重新加载”。只重连 MCP、继续原聊天时，该聊天里的 Skill 简介可能仍是旧的。
  - 旧版本留下的重新加载记录不再参与判断，升级后积压的提示会直接消失。

## 升级

在 App 内检查更新并安装。本版只改托盘 App，服务端没有变化。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.33.0"
```

已有会话、组员配置与 Provider 权限保持不变；已有配置中未设默认思考档位的模型不会被补填。

# AgentNave v0.62.0

## 更新

- **Windows 顶栏兼作标题栏**：Windows 上不再有两条栏，顶栏右端放最小化、最大化／还原、关闭按钮，也能拖动和双击缩放。窗口因此变成直角，页面不再画滚动条，滚轮和键盘滚动不受影响。
- **Windows 任务栏图标变大**：图标按 Windows 尺寸单独出图，不再比旁边的应用小一圈。Windows 刷新图标缓存后才会换成新图。
- **失败不再抢前面**：失败已交给 boss 处理，工作区列表、右栏目录和菜单栏面板都不再把它排在前面，也不再标「有失败」；工作区预览和右栏卡片仍写明失败。
- **失败工位自动收起**：失败超过半小时的工位收进「已优化」，再次运行后回到办公室。

## 修复

- Windows 上此前没有生效的顶栏拖动和主题跟随现在可用。

## 升级

- App：走应用内更新或替换 App。
- 本机服务：App 启动时会自动跟到自身版本；这版没有改服务接口和历史格式，不需要迁移。

# AgentNave v0.15.1

## Invocation results and retention

- Finished invocation records expire seven days after completion, including unread results.
  Active work remains available, and rereading does not extend retention. Expiry does not
  delete provider-native sessions, group answers or Studio history.
- Core and Studio startup replies include the requested provider, model and effort without
  repeating the prompt. Omitted model and effort show native inheritance; these fields do not
  claim to verify the CLI's effective settings.
- A server rejects concurrent continuation of the same provider-native session across ordinary
  invocations and group seats. Studio checks before creating running task history. This is a
  process-local guard, not a lock against another server or direct CLI calls.

## Round lifecycle and output

- Unexpected invocation failures return structured errors. A round driver failure settles
  active seats and skips unstarted seats before releasing the group; failed rounds report
  `status=failed` and an error. Studio keeps this state through saved-history recovery without
  reviving undecided answers. Ordinary `finished` still means orchestration ended, not that
  every seat succeeded.
- Finished round elapsed time is fixed on reread.
- `wait_round(include_output=false)` omits answer bodies and running reply tails. Its default
  remains `true`; full answers can be read again, including Studio answers awaiting review.

The existing parallel and serial semantics remain unchanged. Later parallel rounds receive
earlier committed answers; serial order intentionally gives later seats more information.
Answer visibility is not filesystem isolation, and Studio review controls publication rather
than rolling back tool side effects or clearing native session memory.

## Upgrade

Upgrade both installed packages from the same tag, then reconnect each host's MCP connection.
Keep the existing host exclusions, provider permissions and Studio data directory.

```bash
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.15.1"
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.15.1#subdirectory=packages/agentnave-studio" \
  --with "git+https://github.com/TimWongUp/agentnave.git@v0.15.1"
```

Use only the package needed by a host; where both launchers are already installed, update both.
The companion Skill ships in the same tag; install or reuse its complete directory after checking
for local customization. Updating the runtime does not alter host registrations or CLI settings.

## Validation

The regression suite covers exception terminal states, round cleanup, native-session exclusion
across group and task paths, fixed elapsed time, repeatable full output after status-only waits,
Studio review recovery and record expiry. Source checks and installed-launcher verification run
in the existing macOS, Linux and Windows CI workflow before automatic tag and Release publication.

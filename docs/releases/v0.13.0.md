# AgentNave v0.13.0

## Shared data directory across hosts

Several MCP hosts (for example Claude Code, Codex and Antigravity) can share one
`~/.agentnave` directory. Previously the first server to start locked every saved conversation
until it exited, so other hosts saw an empty `list_conversations` and resuming a native
`session_id` there split history into a new conversation.

Each server now indexes saved records read-only and takes a conversation's lock only on its first
write. `list_conversations` refreshes the index and reports `writable`; `false` means another
running service holds the record, which stays readable but is never taken over. Resuming by
`session_id` refreshes the index first, so conversations created by other services after startup
are found. Reloads verify the room identity, refresh read-only dashboard views, and re-read state
under the probe lock so recently finished work is not reported as interrupted. The single-writer
rule and stable `.lock` identity are unchanged.

## Claude Code and CodeBuddy output capture

Claude stream events (token deltas, tool results) no longer accumulate in the 8 MiB capture
buffer. Live activity still observes every event, while capture keeps only the final `result`
event and session ID changes, so long tool-heavy tasks no longer fail with
`output_limit_exceeded`. A single native line larger than the limit still fails as before.

## Lighter dashboard

The avatar sprite shrank from 2.6 MB to about 40 KB, and static assets (`app.js`, `style.css`,
`avatars.png`) are cacheable for a day. HTML, `state` and `transcript.jsonl` remain `no-store`;
Host/Origin checks and CSP are unchanged.

## Skill default

The paired `agentnave-manager` Skill now defaults Codex to `gpt-6.1-sol` with effort `high`.

## Upgrade

Install the runtime and complete manager Skill from the same tag, then reconnect MCP on every host
that shares the data directory. Tools, registrations, provider permissions and history formats
remain compatible.

```bash
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.13.0"
```

## Validation

Coverage adds two workbenches sharing one data directory, a long fake Claude stream exceeding the
former cumulative limit, and exact static cache headers. A real CodeBuddy invocation through
AgentNave confirmed final output and `session_id` with capture reduced from about 359 KB to 2.4 KB,
and a real Codex invocation confirmed the new default model. Release publication follows the
existing cross-platform CI gates.

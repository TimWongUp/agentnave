# AgentNave v0.30.0

新增 DeepSeek Harness 作为第七个 CLI。调用时没指定模型的 Grok、Antigravity 工位，现在也能显示实际使用的模型。办公室里的工位卡片和会议室布局也做了修正。

## 新功能

- 接入 DeepSeek Harness（`provider: "deepseek"`），对应 `dsh --profile headless --json`。
  - 支持 `model`、`effort`、`provider`（模型路由）、`permission_mode`、`stored_credentials` 和 `restricted_tools`。
  - 显式选项写入系统临时目录里的 `--patch` 覆盖层，调用结束即删除，不改用户的 dsh 配置；不传选项时沿用原生设置。
  - `stored_credentials=true` 恢复 DeepSeek Harness App 中保存的认证。headless 默认只读 `DEEPSEEK_API_KEY`。
  - `restricted_tools=true` 停用发行 profile 的全部工具插件和计划模式，并改为只读沙箱。
  - 用返回的 `session_id` 在相同 cwd 续接。
  - macOS 优先使用 `DeepSeek Harness.app` 内置的 `dsh`，找不到再查 PATH。
- 托盘 App 可以为 DeepSeek Harness 配置任务模式和讨论模式的组员。dsh 没有列出模型的命令，模型列表取其内置目录：`deepseek-flash`、`deepseek-v4-pro`。
- Skill 新增 DeepSeek Harness 参考文件。

## 修复

- 调用时没指定模型的工位，现在会确认实际模型，不再一律显示「默认模型」：
  - Grok：结束事件的用量里只有一个模型时，采用这个模型。
  - Antigravity：按本次会话读取 agy 运行日志，日志里只选过一个模型时，采用这个模型。
  - 仍然不从 CLI 配置推测模型。修复前已保存的记录不会回填。
- 「实机检查」这类角色标签和访问标签，挪到工位卡片左上角。角色名超过 6 个字时截断，悬停可以看到全名。标签换行时，卡片不再上下错位。
- 会议室在半宽位置时，改为占满整行。

## 升级

在 App 内检查更新并安装，再按各宿主卡片提示重启或重连。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.30.0"
```

已有会话、组员配置与 Provider 权限保持不变。要使用 DeepSeek Harness，先在它自己的 App 中完成安装和登录。

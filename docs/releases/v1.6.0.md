# AgentNave v1.6.0

Antigravity CLI 在权限放开时改用交互界面运行，省额度；修复 v1.5.0 一键下载视频包失败；Kimi 换成视频版形象。

## 更新

- **Antigravity 交互模式**：
  - macOS／Linux 上权限放开时（App 两个权限档位都是放开），用 agy 的终端界面代替 `-p` 运行，默认打开；Antigravity 员工卡片上的「交互模式运行」可以关掉。Windows 仍用 `-p`。
  - 回合结束以 agy 的 `Stop` hook 为准，会等后台命令跑完；回复从 agy 的完整会话记录读取，不截断。
  - 第一次交互运行会在 `~/.gemini/config/hooks.json` 加一条 `agentnave-interactive`，只在 AgentNave 启动的 agy 里起作用，你自己用 agy 和 Antigravity App／IDE 时不受影响；其他条目原样保留。这一条被停用时任务报受阻，不会被改回启用。
  - 画面识别按 awslabs cli-agent-orchestrator 的做法只看页脚；遇到菜单、看不懂的画面或迟迟没有 `Stop` 时限时报受阻，不会一直挂着，也不会误报成功。
  - 详见 [ADR-0072](../adr/0072-antigravity-interactive-runtime.md)。
- **Kimi 新形象**：坐姿、头像和走路帧换成视频版的银紫长发女仆形象，去掉旧兔耳分层。
- **README**：特点里的宿主与员工数量和支持表对齐，演示动图换成视频小人重录。

## 修复

- 一键下载视频包：v1.5.0 按最新版本查找视频包，找不到文件；现在固定从 v1.4.0 Release 下载，以后发版不用再上传视频包。

## 升级

- App：走应用内更新，或直接替换 App。按 boss 卡片提示重开或重连宿主。不想让 agy 走交互模式的，在 Antigravity 员工卡片上关掉「交互模式运行」；不装 App 的 Linux 在 `settings.json` 写 `"antigravity_interactive": false`。
- 手动安装：用 `@v1.6.0` 重装运行时和 Skill，然后重连 MCP。

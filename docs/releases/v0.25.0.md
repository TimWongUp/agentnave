# AgentNave v0.25.0

同一主控会话启动的 CLI 归入同一个工作区：私聊与会议并存，上下文按主控安排转发，App 以办公室视图展示。决定见 [ADR-0018](../adr/0018-office-workspace-desks-and-meeting-rooms.md)。

## 工位与默认续接（破坏性变更）

- 工作区中的每个 CLI 以工位常驻，身份为 CLI + 模型 + 角色，显示为「模型 · CLI · 角色」。`start_agent` 与协作组席位新增可选 `role`，同一 CLI 与模型需要分身时再起角色名。
- 主控身份已知、且未传 `session_id` 与 `conversation_id` 时，`start_agent` 默认续接同工位最近一次私聊线程，主控不必再保管 `session_id`；回执 `resumed` 标明是否续接。需要干净上下文时传 `new_thread=true`；该线程仍在运行时拒绝。
- 此前不传 `session_id` 总是开新对话。未传 `manager_session_id` 的主控保持旧行为。

## 转发

- 私聊默认不带任何工作区上下文；会议室内已提交条目仍自动共享。
- `start_agent`、`run_round` 新增 `forward`，按消息 ID 引用同一工作区已完成的消息；转入会议室的内容记为独立的转发条目，对接收方声明为数据而非指令。
- 待审、已丢弃、缺席、运行中、失败的消息和其他工作区的消息不能转发；单次最多 20 条。
- 任务终态、轮次、审核与主持人发言的回执返回消息 ID。

## 办公室视图

- App 的群聊页换成办公室：主控办公桌显示待审，工位标出私聊处理中、会议中、待审、失败或空闲，协作组是会议室，白板显示已提交条目数。
- 点工位查看它的全部历史，点会议室查看会议记录，消息列表按时间展示整个工作区；私聊标「🔒 私聊」，转发显示来源并可跳转。
- 托盘面板改为各工作区的办公室缩略版；设置中的组员模式改称「私聊」「会议」，配置格式不变。
- 与宿主同类的 CLI 标为「仅会议」：进会议只为方便参与讨论，执行任务优先使用宿主自带的子代理。

## 升级

在 App 内检查更新并安装，再按各宿主卡片提示重启或重连，使新的工具参数生效。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.25.0"
```

已有会话、组员配置与 Provider 权限保持不变；旧记录归入无角色工位，不迁移历史。

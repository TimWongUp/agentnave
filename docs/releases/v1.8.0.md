# AgentNave v1.8.0

权限档位缺省改为完全放开；账户阻断改按 CLI+模型冷却，托盘与 MCP 新增手动解除入口；托盘大幅降低 CSS 与视频小人的 CPU 和写盘占用，默认用电池时小人不动，CSS 小人坐姿换成与视频版同位的高清帧与软铰链部件；Claude Code 宿主新增 1500 秒长等待档；Claude Code 与 Antigravity 的启动确认屏由服务自动处理，agy 交互运行补齐实时工具状态与耗时；修复 Windows 未开开机启动时保存设置报错、macOS 系统通知不显示及更新后 Dock 多出图标等问题。

## 更新

- **权限档位缺省改为完全放开**：
  - `permissions.json` 缺失或未保存某 CLI 条目时，权限档位缺省为「完全放开」；此前未单独保存过档位的 Claude Code、Codex、Devin、Grok 会从「自动」变为「完全放开」。
  - 已显式保存为「自动」的保持不变，仍可在 App「设置 → 员工」里该 CLI 卡片的「权限」改回「自动」。权限仍由各 CLI 原生机制执行，调用回执照常注明套用的参数。
  - 详见 [ADR-0076](../adr/0076-full-permission-default.md)。
- **按 CLI+模型冷却与手动解除**：
  - 账户阻断改按请求模型记录冷却（未指定模型时退回 CLI 级），同一 CLI 下的其他模型或供应商不再被连带锁住。
  - 认证失败（auth）冷却至手动解除或该模型调用成功；配额耗尽（quota）仅在错误带明确重置时间时冷却至该时间（最长 8 天，目前支持解析 Claude Code、Codex），无明确时间不冷却，避免与聚合网关自身的切号冲突；计费问题（billing）冷却 30 分钟。
  - 托盘「设置 → 员工」页列出当前冷却记录（CLI、模型、类别、到期时间），每条可单独点击「解除」；新增公开 MCP 工具 `clear_provider_cooldown(provider, model?)`（工具总数变为 11 个），仅在用户于当前对话明确要求时由 boss 调用。
  - 详见 [ADR-0081](../adr/0081-account-cooldown-duration.md)。
- **托盘与小人资源占用降低**：
  - CSS 小人与轮询：重写光环旋转与运行中脉冲动画，睡眠滤镜下移到帧图；列表与工作区按 10 秒节拍跳过无变化重绘，空闲时语音状态改为每 15 秒拉取，侧栏启用 `content-visibility: auto`；窗口失焦时暂停 CSS 动画与粒子、轮询放宽到至少 5 秒。同一工作区下，CSS 小人前台三进程 CPU 合计约从 32% 降到 5%，可见但失焦时约从 35% 降到 1.6%。
  - 视频小人直连与回环 HTTP：去掉 `.mov` 的 `blob` 中转，失焦立即暂停、45 秒后将当前帧画入画布并释放解码器（失焦可见时总 CPU 约从 28% 降到 3.7%）。macOS 上 `.mov` 改经托盘在 `127.0.0.1` 随机端口开启、路径带启动令牌的只读回环 HTTP 监听加载，避免 WKWebView 自定义协议按帧发 Range 请求，同一工作区前台 CPU 约从 50% 降到 32%、写盘基本归零。详见 [ADR-0080](../adr/0080-tray-video-loopback-http.md)。
  - 「用电池时小人不动」开关：在「设置 → 常规」中新增并默认开启；用电池供电时视频小人换用静态海报并释放播放器，CSS 小人与粒子暂停，接回电源后自动恢复。
- **CSS 小人高清坐姿与软铰链部件**：
  - 13 个角色的 7 个坐姿状态和眨眼帧换成 544 视频包同状态的高清帧（544×544 透明 WebP），画风和位置与视频模式同位；走路帧仍是旧画风，安装包约大 6MB。
  - glm、grok、hunyuan 的呆毛，grok 的恶魔尾，deepseek 的呆毛、两只鳍和鲸尾，codex 的两只翅膀，qwen 坐姿的发钗吊坠，以及 gemini 原有部件，统一改为置于底图后的软铰链图层绕根部摆动，转动时不露切口。
  - codex 坐姿不再有龙尾，grok 坐姿恶魔尾改为一整段。
- **Claude Code 宿主 1500 秒长等待档**：
  - `wait_seconds` 新增 `1500`（25 分钟），只对 Claude Code 宿主开放，其他宿主传入会被拒绝；默认等待窗口仍为 270 秒。Claude Code 会在约 2 分钟后把 `wait` 转入后台并由完成通知唤醒，长等待档避免每 270 秒反复唤醒重发。
  - App 接入和刷新 Claude Code 条目时，将服务条目 `timeout` 下限从 360000 提高到 1620000 毫秒（27 分钟），已有更长值和 `-1` 保留。
  - 详见 [ADR-0077](../adr/0077-claude-long-wait.md)。
- **启动确认屏自动处理与 Antigravity 实时状态**：
  - Claude Code 与 Antigravity 交互启动时的工作区信任屏，经文件系统核对屏上目录与派发 `cwd` 为同一目录时（含路径大小写拼写差异）由服务自动选择信任，不一致或无法核对时受阻；Claude Code 的外部 `CLAUDE.md` 导入审批屏自动选择允许。确认结果由 CLI 写入各自用户配置；未知启动屏仍受阻，不猜按键。详见 [ADR-0078](../adr/0078-startup-confirmations.md)。
  - Antigravity 交互运行期间从输入框上方的状态行补充工具与思考活动（`run_command`、`view_file`、`edit_file` 等映射为对应中文状态），不再整轮只显示「思考中」；连续多个工具调用时前一个结束后补发下一个工具状态；所有 CLI 的运行状态新增耗时显示（如「思考中 · 23s」「正在运行命令 · 1m05s」），每秒刷新。详见 [ADR-0079](../adr/0079-agy-screen-activity.md)。
- **插话引导与并行写入边界**：
  - `agentnave-manager` 新增「插话引导」：运行中不能直接追加消息时，打断后用同一 `session_id` 续接以补充或纠正方向；会议席位改在下一轮通过私密指令引导。
  - 编排规则写明并行写入的前提是各单元互不依赖且各用独立 worktree，做不到（如项目规定不建 worktree）就串行；自定义规则里复制过的旧句自动迁移。

## 修复

- **Windows 未开开机启动时保存设置报错**：未开启开机启动（注册表 `Run` 下无 `AgentNave` 值）时，将该 Win32 HRESULT 识别为键或值不存在，保存视频小人、主题等设置不再报 `os error -2147024894`，关闭本不存在的开机启动项也不再报错。
- **macOS 系统通知不显示**：macOS 改用 `UNUserNotificationCenter` 投递通知，修复开启系统通知后测试通知和提醒被静默丢弃的问题（App 在后台时正常弹出横幅，在前台时进入通知中心）。
- **macOS 自动更新后 Dock 多出图标**：安装更新后改为等旧进程退出再启动新进程，固定在 Dock 里的图标保留运行小点，右侧最近使用区不再多出第二个图标。
- **中断会议每次读取都排到最前**：崩溃恢复补记中断席位时改用该会议最后一条已保存记录的时间（无记录取创建时间），不再每次读取都把 `updated` 刷成当前时间，旧会议不会一直排在工作区最前，历史自动清理也能正常过期。
- **宿主 YAML 配置同缩进块序列**：宿主配置解析支持空值映射键后紧跟同缩进的块序列项（如 Hermes `config.yaml` 中由 PyYAML 生成的 `toolsets:`、`command_allowlist:` 列表），不再误报 `YAML 映射无效` 或把 Windows 盘符冒号误判为映射键；去掉已失效的详情入口提示文案。
- **WorkBuddy 与会议异常收尾**：`ProviderOption` schema 将布尔排在字符串前，修复 WorkBuddy 把布尔选项 `false` 转成 `"false"` 的问题；CodeBuddy／WorkBuddy 原生会话支持识别 `providerData` 标记并读取 boss 模型；会议轮次异常或取消收尾时保留无需审核的已成功席位答案；权限降级警告注明来自 App 权限档位回退设置。
- **托盘气泡与转发收听**：私聊任务和转发消息不再显示多余的 `@名字`，会议消息的 `@`、头像、职责和长名字支持自动换行；修复转发私聊任务时「收听」把员工回复念成 boss 提问、二次转发无法跳转到原消息且朗读误判为 boss、以及原消息不在当前列表时误当成 boss 本人说话的问题。

## 升级

- App：走应用内更新，或直接替换 App（安装包因高清坐姿帧约增大 6MB）。
  - **默认权限变化**：未单独保存过权限档位的 CLI（Claude Code、Codex、Devin、Grok）升级后缺省改为「完全放开」；想保持原有档位的，在「设置 → 员工」里把对应 CLI 卡片的「权限」改回「自动」。已显式保存为「自动」的保持不变。
  - **电池静止默认开启**：「设置 → 常规 → 用电池时小人不动」默认打开，用笔记本电池供电时视频小人会换静态海报、CSS 小人会暂停；想在电池下继续看动画可在常规设置里关掉。
  - **宿主重连与配置刷新**：App 启动后会更新本机服务与 Skill，把 Claude Code 宿主的条目 `timeout` 补到至少 1620000 毫秒（27 分钟），并迁移编排规则里的并行写入句子（自定义档里未改动的旧句也会自动迁移）。按「设置 → boss」里的 boss 卡片提示重开或重连宿主，新增的第 11 个工具 `clear_provider_cooldown`、Claude Code 1500 秒长等待档以及服务侧更新才会对现有会话生效。
- 手动安装：用 `@v1.8.0` 重装运行时和 Skill，然后重连 MCP（确认 11 个工具可见）。使用 Claude Code 宿主且手动维护配置时，建议把 `agentnave` 条目的 `timeout` 设为 `1620000`（毫秒）。不装 App 的环境缺省权限同样变为 `full`。

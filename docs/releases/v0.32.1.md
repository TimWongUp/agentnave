# AgentNave v0.32.1

修复一个续接 bug，并减少服务和托盘 App 的重复写盘与解析。界面和功能没有变化。

## 修复

- 默认续接漏掉了运行中的新线程。用 `new_thread=true` 开的线程，在运行结束前还没有原生会话；这期间，同一工位的默认续接会悄悄续上更早的线程，或者另开一个并行线程，导致历史分叉。现在运行中的线程也算作工位最近的线程，默认续接会被拒绝，并提示等它结束或改用 `new_thread=true`。

## 改进

- 中继的连接文件只在内容变化时重写。内容没变时只刷新修改时间，文件被删除后会自动写回。此前每 5 秒以及每条 MCP 回复后都会整份重写。
- 取得写锁时，只有状态真正改变才保存 `state.json`，不再每次都整份保存。
- 托盘 App 收到活动心跳时，如果文件内容没有变化，就沿用已解析的结果，不再重新解析。

## 升级

在 App 内检查更新并安装。服务端有变化：服务中继会在空闲时自动换用新安装，也可以重启宿主或重连 MCP。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.32.1"
```

已有会话、组员配置与 Provider 权限保持不变。

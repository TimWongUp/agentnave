# AgentNave v0.46.1

换上新的 App 图标。

## App 图标

- 程序坞、访达和安装包里的 App 图标换成与菜单栏一致的一笔画 N 加圆点，取代旧的金底衬线 N。v0.45.0 起菜单栏和 App 内已经是新标志，App 图标这次补上。N 比旧图标稍大，线条粗细与菜单栏标志的比例一致。
- macOS 26 上图标随系统切换：浅色外观是浅底黑 N，深色外观是深底白 N。深色版是否出现取决于「系统设置 › 外观 › 图标与小组件样式」，保持默认时即使在深色模式下也显示浅色图标。
- 更早的 macOS 只显示浅色版。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.46.1"
```

- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.46.1 的完整目录。
- 工具接口没有变化，无需重连 MCP。历史、组员配置与设置无需迁移。
- 从 v0.45.0 或更早版本升级、接入过 Gemini CLI 的，按 [v0.46.0 发布说明](v0.46.0.md) 处理旧配置。
- 程序坞里的图标可能要等 App 重启后才会更新。

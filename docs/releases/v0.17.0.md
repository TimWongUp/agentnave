# AgentNave v0.17.0

核心与工作室合为一个包，新增只读的 macOS 菜单栏应用并支持应用内更新，工作台界面重做；另增两个多任务工具，排除项只约束单任务。

## 单包双入口

`agentnave-studio` 并入 `agentnave`：一个包同时安装 `agentnave-mcp`（核心）与 `agentnave-studio-mcp`（工作室）。入口名、工具和历史不变，宿主注册无需修改；核心仍不落盘、不开端口，也不加载工作室代码。见 ADR-0009。

## 菜单栏应用（macOS）

- 新的 `AgentNave` 菜单栏应用只读展示 `~/.agentnave` 中全部宿主的工作室会话，无需启动 MCP 服务。菜单栏标题显示运行中与待审核数量；左键面板列出正在进行（含各席位最新一句回复）、需要处理和最近的会话，点开进入工作台窗口。应用不调用工具、不写数据根、不监听端口。
- 本 Release 附带通用安装包 `AgentNave_0.17.0_universal.dmg`。应用未经 Apple 签名公证，首次打开须在访达中右键“打开”。
- 应用内更新：启动时与每天检查一次新版本，也可在右键菜单“检查更新”；只在点击“更新并重启”后下载、验证签名并替换，不静默安装。
- 若 uv 安装的 `agentnave` 比应用旧，面板会提示并可复制升级命令；应用本身不升级本机服务。
- 工作室写会话时同步写出视图快照 `views.json`，有工作运行时写出临时运行文件 `live/*.json`（结束即删除），供应用读取；见 ADR-0008。

## 工作台界面

浏览器看板与应用窗口共用重做后的双栏工作台：会话侧栏（需要关注／其他／已结束）配总览或详情，节目详情分“本轮现场”和“公开记录”，任务按调用倒序；安全的 Markdown 渲染、长文折叠、浅深色主题与窄屏布局。公共页仍只含已提交条目。

## 工具与 Provider

- 新增 `wait_any`：在五分钟窗口内等待多个 Invocation，返回已就绪的子集；新增 `list_invocations`：只读列出活跃与保留期内的 Invocation 元数据，不含 prompt 与正文。核心与工作室都有，见 ADR-0007。
- `AGENTNAVE_EXCLUDED_PROVIDERS` 只拒绝 `start_agent`；协作组与非隔离节目可让宿主自身的 CLI 入席。`show_permitted` 保留并恒为 `true`。
- Codex 凭据被拒、Claude 未登录判为 `blocked`；Codex 回合无回复且用量为零时判为 `failed`，不再当作空的成功结果。

## 升级

已分装两个包的机器须先卸载旧的工作室工具，再从本 tag 安装：

```bash
uv tool uninstall agentnave-studio
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.17.0"
```

随后在各宿主重连 MCP，并从本 tag 更新完整的 `agentnave-manager` Skill 目录。数据目录、排除项与 Provider 原生配置保留。菜单栏应用从本 Release 的 DMG 手动安装一次，此后可在应用内更新。

# AgentNave v0.40.1

CodeBuddy 和 Claude Code 某个工具被拒、自己换工具接着做时，不再把 boss 叫醒。App 里的更新只剩一条提醒、一个按钮，打开设置页时会自动查一次新版本。

## 改进

- 面板：App 有新版时只显示一条「更新并重启」，说明里写明会一并升级本机服务，不再同时出现「一键升级」。
- 设置页「版本与更新」：同一时间只有一个主按钮（「全部更新到 vX」或「升级本机服务」），检查按钮改为次要的「立即检查」「重新检查」。说明写明启动时和每天自动检查；切到这一页时，若上次成功检查超过一小时，会静默再查一次，只在发现新版时提示。
- `agentnave-manager` Skill 新增「先计划后实现」的用法，并写明打断后续接重问的措辞：上一轮已被打断、不重跑已执行的命令、先交出已有结论。

## 修复

- Claude Code、CodeBuddy 在非交互模式下单个工具调用被拒，不再作为执行阻塞提前叫醒 `wait`。API 层的权限、登录、额度错误照旧叫醒；任务最终失败且有工具被拒时，终态仍为 `blocked`。
- 检查进行中，「全部更新」不再显示为可点却不生效；打开设置页时的自动检查失败时不报错，也不会清掉已发现的更新。

## 升级

在 App 内选择「全部更新」，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.40.1"
```

- 「全部更新」会更新 App、本机服务和由 App 管理的 Skill。手动升级时还需安装同版本 App，并把外部管理的完整 `agentnave-manager` Skill 目录（含 `references/`）更新为 `v0.40.1`。
- MCP 工具和保存的历史都没有变化，不需要重连或迁移。

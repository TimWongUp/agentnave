# AgentNave v0.29.0

App 换成了手绘的办公室：一眼能看到 boss 在等谁、哪个工位在忙、哪间会议室有回答待审核。原来大量显示「未记录模型」的工位，现在大多能显示实际模型。

## 新功能

- 主窗口改为手绘办公室，中间是办公室，右侧是对话栏。
  - boss 坐在电脑前，桌上放着待审回答。
  - 每个工位常驻，人物和笔记本盖子上的标志按模型家族选取；没有对应形象的模型用新画的默认形象和终端标志。
  - 进行中的会议室画出会议桌和会议记录板，参会者会从工位走到席位。
  - 点 boss、工位或会议室，对话栏切换到对应范围。
- 对话栏消息头写明「谁 对 @谁 做什么」，`@boss`、`@all` 是仅有的保留称呼。
  - 私密指令带锁，只给一席。
  - 待审回答标「等 boss 审核」。
  - 只有部分席位作答时注明本轮回答者。
  - 被丢弃的回答折叠显示。
- 菜单栏面板重做：每个 boss 一行，连到它的办公室缩略版。
  - 有待审回答时顶部先提示。
  - 工位格显示角色头像、CLI 小标、模型名和状态。
  - 最近没有动静的办公室折叠到底部。
  - 设置、检查更新和退出收进「⋯」菜单。
- 菜单栏标题改为「待审 N · 运行 M」，按调用计数。
- 工作区标题改用项目名，Agent worktree 归到所在仓库。
- 主窗口和面板支持跟随系统、浅色、深色三种外观。
- 协作组上限从 6 席放宽到 7 席。

## 修复

- Codex 会话文件里有生图产生的超大行时，读不到模型。现在改为从文件末尾倒序读取。
- 调用时没指定模型的工位，现在显示 CLI 回报的实际模型；两者都没有时显示「默认模型」，不再写「未记录模型」。Grok、Antigravity 的输出本身不带模型名，未指定时显示「默认模型」。
- 修复前已保存、当时没读到模型的记录，不会回填。

## 变更

- 移除 v0.28.0 加入的运行中消息：`send_agent_message` 工具和 `start_agent` 的 `enable_messages` 参数不再提供，MCP 回到十六个工具。需要补充要求时，等任务结束后用 `session_id` 续接。取舍见 ADR-0019。
- 界面与文档里的「主控」改称 boss，「白板」改称会议记录。协议字段 `manager_*` 不变。

## 升级

在 App 内检查更新并安装，再按各宿主卡片提示重启或重连。工具清单有变化，宿主需要重连 MCP 才能刷新。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.29.0"
```

已有会话、组员配置与 Provider 权限保持不变。

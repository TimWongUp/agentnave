# AgentNave v1.12.0

只读隔离任务支持自动释放和续接重建，固定工位增加中等档，交接与办公室显示也更加便于使用。

## 更新

- **隔离目录与读写**：成功的只读隔离任务在目录未改动且满足释放条件时自动释放，续接同一线程可在原位置重建；被忽略的文件也会随释放丢弃。工位读写改为默认值，派发时显式声明的读写优先。
- **工位与决策**：固定编排工位可配置中等档；缺中间档时选择低一档。决策模型档可开启同档候选随机选，分摊额度；固定工位派发按规则块选工位，需要时再查询目录。
- **交接**：待接手工作区置顶，有会话的工作区可取消交接并保留交接说明；修正点名接手时部分宿主的会话定位。
- **办公室与菜单**：菜单头像随小人状态变化，空闲会议成员进入空闲区，工位按最近派活排序；修复电池静止、失焦暂停与插电恢复的配合。
- **Antigravity**：同款 CLI 私聊任务默认由 AgentNave 另开；改善启动时投递与回合收尾，减少已回复任务误报阻塞。

## 升级

- App：应用内更新或替换 App，按提示重连宿主。v1.11 服务和托盘会把含固定工位 `medium` 档的 `orchestration.json` 判为无效；v1.11 托盘会把含 `random_candidates` 的 `decision-seats.json` 判为无效，v1.11 服务则忽略该字段。先更新 App 并重连新版服务，再使用这些选项。「用电池时小人不动」默认改为关闭，未手动设置过的用户如需原行为请重新开启。Antigravity 宿主此前手动选择「用 boss 自己的子代理」的用户需重新选择一次；没有应用身份的旧连接需重连新版服务才会使用新默认值。
- 手动安装：从 `@v1.12.0` 重装运行时与 Skill 并重连 MCP；使用 `medium` 或 `random_candidates` 前先确认服务已更新；手写的 `decision-seats.json` 里形如 `worker-medium`、`explorer-medium` 的工位 ID 现为保留名，升级前需改名。工位读写现在只是默认值，显式声明优先；成功的只读隔离任务可能自动释放未改动的目录及其中被忽略的文件，续接时会在原位置重建。无头宿主参见 [Linux 接入指引](../linux-headless.md)。

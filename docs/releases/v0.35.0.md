# AgentNave v0.35.0

工具从 16 个合并成 8 个，结果更短；一个子代理就是一个工位，App 能看清同时有几件事在做；新增同时运行上限，防止一次派太多把机器拖慢。

## 破坏性变更

- 工具合并为 8 个：`start_agent`、`wait`、`cancel`、`list`、`list_members`、`run_round`、`decide_answers`、`read_conversation`（ADR-0024）。
  - `wait`、`cancel` 同时接受任务的 `invocation_id` 和轮次的 `round_id`，取代 `wait_agent`、`wait_any`、`wait_round`、`cancel_agent`、`cancel_round`。
  - `run_round` 不带 `group_id` 时开新节目，不带 `seats` 时发主持人发言，取代 `open_group` 和 `post_host_message`。
  - `list_members(provider=...)` 取代 `describe_provider`；`list` 取代 `list_conversations` 和 `list_invocations`。
  - `update_conversation` 已移除：标题在创建时给出，之后在 App 里改名。
- 审核决定改为公开 `publish` 和不公开 `private`。不公开的回答留在 boss 和该席之间，App 里显示为「🔒 未公开」的私聊回复；该席下一轮会被告知这条回答没公开。旧记录里的 `discard` 按 `private` 读取。
- `access` 只记录、只显示，不再拒绝与之前声明不同的调用。
- 一条原生线程就是一个工位，会议的每个席位也是一个工位；`role` 只是工位上的标签（ADR-0025）。`continue_desk` 和回执里的 `resumed` 已移除，续接只用 `session_id`。还在传 `continue_desk=true` 的旧调用会静默得到新线程。
- 看板只在调用 `list` 时启动，保存操作不再返回看板链接。

## 新功能

- 同时运行上限：私聊任务和会议席位合计默认最多 8 个同时运行，在 App 设置里可调（1–32）。超出时新的任务或轮次直接被拒绝，等部分结束后再派。办公室最多画出同样数量的工位，运行中和待审的总是画出，其余进入「已优化」组，只以文字列出。
- `read_conversation` 返回和 App 一样的最终消息时间线，可以用 `since_round` 只读后面的轮次，用 `include_private` 看私密指令和不公开的回答。
- 工具结果以去掉空值的紧凑 JSON 返回，工具定义和组员列表都明显变短。
- App 管理会话页可以给空闲会话改名；设置页新增「编排偏好」，给出推荐写法，并能打开各宿主已有的全局规则文件（App 不写入这些文件）。

## 修复

- App 在中继过旧、或新版本安装超过十分钟仍未切换时提示重连；中继会清理已退出连接留下的观测文件。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.35.0"
```

然后在各宿主重连 MCP，让新的工具列表和同版本 Skill 生效。依赖旧工具名或 `continue_desk` 的调用方需要改用新工具和 `session_id`。已有会话、组员配置与 Provider 权限保持不变。

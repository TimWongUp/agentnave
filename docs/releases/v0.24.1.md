# AgentNave v0.24.1

修复 App 设置与群聊展示，明确主控会话归属、模型身份和私密消息。

## 设置和导航

- 稳定按钮、开关与三页顶部导航的位置，禁用导航链接拖拽。
- 补齐工具、模型、默认设置和会话清理的说明；界面明确标出哪些修改需要保存。

## 群聊

- 按主控的聊天 session 归组，同一 CLI 的不同聊天分别显示；原生子代理会话仍可续接。
- 区分调用指定模型和原生回报模型，逐消息保存；可从精确匹配的 Codex／Claude 原生会话读取模型。无法确定时显示 CLI 身份，不把“原生设置”当模型名。
- 主控消息以头像显示实际收件席位，悬停查看名称，点击定位；相同模型的不同席位也分别定位。
- 裸 JSON 与 JSON 代码块使用相同气泡样式，代码和长行在气泡内换行。
- 补齐各轮被标记为 `discard` 的历史回答，并显示「🔒 私密」；这些正文只进入私有视图，公开页与其他席位仍看不到。

## 审核回执

`decide_answers` 返回轮次 `status` 及可选 `error`。全部执行和审核已完成时，等待本地提交收尾后返回终态；`status=finished` 可直接开始下一轮。部分审核、串联中途仍通过 `wait_round` 继续观察。

## 升级

在 App 内更新并重启 AgentNave；服务与配套 Skill 更新后，重启宿主或重新连接 MCP。WorkBuddy 需按接入提示重新信任 MCP。

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.24.1"
```

主控应为每次 `start_agent`、`open_group`、`run_round`、`post_host_message` 传入同一个 `manager_session_id`。宿主没有原生聊天 ID 时，在当前聊天生成并持续复用一个 UUID。旧连接 ID 不会被当成新聊天身份；缺少可靠关联的旧记录独立保留，不猜测或回填模型。

已有会话与配置保持可读；旧展示缓存由新服务扫描或继续会话时刷新。更新不会改变 Provider 原生权限、登录配置或模型参数。

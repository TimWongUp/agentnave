# AgentNave v1.11.0

工位支持备选顺位和额度组冷却，只开会档改用专门的会议 Skill；决策模型按工作性质选择难度，DeepSeek 可选择认证方式。办公室支持收起两侧栏并调整工位布局，菜单和会话扫描也更稳定。

## 更新

- **工位备选与额度组冷却**：评审、固定编排、生图和决策模型工位可按顺序配置最多三个备选；新任务启动前主选不可用时采用第一个可用备选，回执说明顺位和跳过原因。显式指定 CLI 或模型、续接以及启动后失败不切换。配额硬阻断按 CLI 声明的额度组冷却，无法对应时按模型或 CLI 冷却；宿主同类 CLI 可按 boss 设置交给宿主子代理、由服务启动或跳过，会议不受影响。
- **只开会档**：只使用会议室，「boss 可主动开会」开关默认关闭，升级后不再主动开会；按档位安装 `agentnave-meeting` 或 `agentnave-manager`，两者互斥。评审时机和记录去处交给用户规则决定。
- **决策模型与派发回执**：按工作性质和各档含义判断简单、中等、困难，专业工位缺档时选最接近的难度；推荐和派发回执带难度。隔离目录未带入的源目录改动提示列出具体路径，便于检查。
- **DeepSeek 与 Pi**：DeepSeek 成员设置可选择登录账号、官方 API Key 或沿用 CLI 设置；未指定模型且选择登录账号时，不静默切到已存官方 Key。Pi 未指定模型的调用保留后端选项。
- **办公室**：顶栏按钮可隐藏或显示工作区列表和对话栏，隐藏后悬停边缘或按钮可浮出；boss 工位随员工工位缩放，开放工位每排最多五个。boss 两侧的私聊和会议列表与 boss 等高、贴两边且限宽 320px；私聊行显示职责和「模型 · 推理档」。
- **Skill 等待与收尾**：Codex 宿主等待 AgentNave 时不缩短让出时间，无进展不发送消息；收尾行增加「待 boss 决定」，完成状态按任务要求判断，纯讨论的会议轮次不加收尾行。
- **设置与模型**：设置的「高级」改名为「技能」，全局规则文件移到编排页；模型选择新增包含以后新模型的「全部模型」，也可只用勾选的模型。
- **性能与显示**：会话扫描跳过未变化的会话；菜单里工作中的工位按开始顺序排列，不再随新消息跳动。使用电池时，开启「用电池时小人不动」后，窗口失焦会暂停小人并放慢轮询。

## 升级

- App：应用内更新或替换 App，按 boss 卡片提示重连宿主，让现有连接加载新版服务与 Skill。v1.10 服务会把含 `fallbacks` 的 `orchestration.json`、`review.json` 或 `decision-seats.json` 判为无效，请先重连新版服务再添加备选；旧版服务或托盘也可能忽略额度组冷却记录。只开会档要恢复主动开会，在 App 中打开「boss 可主动开会」开关。
- 手动安装：从 `@v1.11.0` 重装运行时与 Skill 并重连 MCP；只开会档安装 `agentnave-meeting`，其他档安装 `agentnave-manager`，切档时移走另一份。只开会档要恢复主动开会，无头宿主在 `orchestration.json` 设 `meetings_options.meetings: true`，并把对应规则写进宿主指令入口。无头宿主参见 [Linux 接入指引](../linux-headless.md)。

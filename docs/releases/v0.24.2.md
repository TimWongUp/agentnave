# AgentNave v0.24.2

将版本更新与宿主接入合并，明确显示更新后各宿主的重启确认状态。

## 接入与更新

- 设置合并为“接入与更新”：同页查看 App／本机服务版本、执行更新并管理宿主，旧更新页链接仍可用。
- 每个已接入宿主分别显示“待重启确认”或“已确认重启”；未接入的宿主无需重启。
- 完成重启或重连后，可在对应卡片点击“我已重启 / 重连”。确认按当前 App／服务版本、接入配置及 Skill 状态保存；这些内容变化后重新提醒，重开 AgentNave 不会丢失状态。
- 清楚区分安装完成、连接配置完成与宿主接口生效。重启确认来自用户操作，不代表 App 自动验证了当前聊天的工具接口。
- 修正更新页和托盘的自动切换说明：中继切换服务进程不保证宿主刷新工具接口。

## 升级

在 App 内检查更新并安装。更新完成后，按同页各宿主卡片的提示重启或重连；例如完整退出并重新打开 Codex，再返回原聊天继续。支持重连的宿主也可重新连接 AgentNave MCP。仅重启 AgentNave 或新建聊天不保证刷新工具接口。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.24.2"
```

已有会话、组员配置与 Provider 权限保持不变。本次不新增模型调用或自动关闭宿主的行为。

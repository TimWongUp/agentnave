# AgentNave v0.53.1

执行者页能列出 Antigravity CLI 的模型了。

## 修复

- 托盘探测 CLI 模型时，每条列举命令最多等 45 秒（原为 15 秒）。`agy models` 要联网拉取，约需 20 秒；原先每次都超时，Antigravity 卡片一直显示「15 秒内未完成」，打开设置页时的自动重新探测也每次失败。

## 升级

在 App 内选择「全部更新」，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.53.1"
```

- 「全部更新」会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.53.1 的完整目录。
- 这次的修复在 App 里，随 App 更新生效；上面的手动命令只更新本机服务，App 仍需更新到 v0.53.1。
- 工具接口没有变化，无需重连 MCP；历史、组员配置和设置都不用迁移。
- 从 v0.52.0 或更早版本升级的，另见 [v0.53.0 发布说明](v0.53.0.md)。

# AgentNave v0.26.0

工位可以声明访问等级，只读的探索代理不会再被续接成写入代理。决定见 [ADR-0018 修订](../adr/0018-office-workspace-desks-and-meeting-rooms.md)。

## 访问等级声明

- `start_agent` 与协作组席位新增可选 `access`：`read` 或 `write`。工位在同一工作区内以第一次声明为准，之后省略即继承，回执 `access` 返回生效的等级。
- 同一工位声明不同等级会被拒绝，并提示改用另一个角色，用转发或会议传递探索结论；显式用 `session_id` 续接另一工位已声明的线程也会被拒绝。
- 声明只是约定：它被记录并在办公室工位上显示为「只读」「可写」，不改变 CLI 的原生权限，也不会被服务推断。真正的权限边界仍是 Provider 原生权限。
- 不传 `access` 的调用行为与 v0.25.0 相同。

## 角色协作

agentnave-manager Skill 新增角色协作规则：探索、规划、评审声明只读；实现声明可写并续接自己的线程；评审不用实现工位本身；并行实现分属不同角色并各自隔离；分歧进会议室讨论，信息只经转发或会议在角色之间流动。

## 升级

在 App 内检查更新并安装，再按各宿主卡片提示重启或重连，使新的工具参数生效。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.26.0"
```

已有会话、组员配置与 Provider 权限保持不变；旧记录没有声明，不受新规则限制。

# AgentNave v1.2.0

Claude 改用交互模式运行，运行中的弹框由 boss 代答；语音改成限时收听，播放器重做了一遍。

## 更新

- **Claude 交互模式**：macOS 和 Linux 默认用伪终端驱动 Claude Code，代替 `-p`，以省订阅额度；员工页 Claude 卡片的「交互模式运行」可以关掉，Linux 没有 App，由 boss 传 `interactive=false`。Windows 仍用 `-p`。详见 [ADR-0056](../adr/0056-claude-interactive-runtime.md)。
- **boss 代答弹框**：权限框、提问框和计划确认交给 boss，用新工具 `answer_prompt` 回答一次。弹框和答复写入审计，工具输入先打码。详见 [ADR-0057](../adr/0057-boss-answers-native-prompts.md)。
- **Claude 权限档位互为退路**：所选的权限模式不可用时，改用另一档重跑一次，回执 `warnings` 注明。详见 [ADR-0059](../adr/0059-claude-tier-fallback.md)。
- **语音**：
  - 收听改成限时：默认 1 小时，设置里可选 30 分钟、1、2、4、8 小时。到时自动停止。
  - 每场会议或私聊是一张专辑，封面由参与的小人组成，最多 6 个。
  - 播放器重做：上一条、下一条、连读和停止都是图标按钮，顶栏下拉菜单和菜单栏面板一致。
  - 播放页的标题是会议名或私聊 role，小标题是模型名，点它跳到正在读的消息。
  - 停止后保留播放页 1 分钟，可以重播最后一条，期间有新播放就替换。
  - 菜单栏面板只显示正在运行的工位，结束或失败的留 5 分钟，开会的工位放进会议栏。
- **失联任务**：宿主或服务异常退出后，托盘确认会话锁无人持有时，把卡住的运行中记录显示为已中断，不改写历史。详见 [ADR-0060](../adr/0060-tray-detects-orphaned-running-work.md)。

## 修复

- 在终端挂起 boss（Ctrl+Z）时服务继续运行，派出的子代理不再中断。
- WorkBuddy 派发 CodeBuddy 不再因继承监听端口挂起，也不再要求重新登录。
- 员工设置取消「全部模型」时保留当前模型集合，之后仍能逐项取消。
- Hermes 换模型后第一轮 App 显示的 boss 模型正确，`local-` 会话也能读到模型。
- 在设置里点菜单的说话人跳转后，消息列表不再空白。
- 暂停或积压时点读摘要会立即开始；工作区收听放宽读取范围后不再读到旧消息。

## 变更

- **交互模式的痕迹**：Claude 子代理的会话会出现在 Claude Code 的 `/resume` 列表，任务原文进入 `~/.claude/history.jsonl`，目录信任和确认过的 API key 末 20 位永久记入用户的 Claude Code 配置。不想要这些就关掉交互模式。
- **自动朗读已移除**：之前开着自动朗读的用户升级后不再自动播放，要听时点「收听」。
- **Claude 认证**：服务不再把 `CLAUDE_CODE_OAUTH_TOKEN` 传给子进程，Claude 子代理统一用 Claude Code 自己存的登录。只靠这个环境变量认证的环境，要先在 Claude Code 里登录。详见 [ADR-0058](../adr/0058-claude-stored-login.md)。
- 收件箱模式的 `wait` 既无显式 boss 身份、也无宿主注入身份时直接报错，不再可能收走其他聊天的结果。

## 升级

- App：走应用内更新，或直接替换 App。App 启动后会安装 1.2.0 服务，**之后逐个重连各宿主的 MCP**，重连后才有 `answer_prompt`。Hermes 还要把它加进已保存的工具勾选，否则等弹框的任务会一直停着。
- 手动安装：用 `@v1.2.0` 重装运行时和 Skill，然后重连 MCP。

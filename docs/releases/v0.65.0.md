# AgentNave v0.65.0

## 更新

- **语音自动读**：「新消息自动读」覆盖当前整个工作区，收起消息栏或停在目录时也会读。「从头读」改为「点读后连播」开关：点一条消息，就从那条往下读。两个开关默认关闭；打开语音设置后可以马上操作。
- **按场景摘要**：开启摘要后，所有消息都先经摘要模型再朗读。App 会告诉摘要模型谁在对谁说（私下交代、会上点名、员工回复、转述），由模型补全主语和称呼。不开摘要时，读开头约 100 字，在段落或句末截断。摘要失败时改读开头，并在界面上提示。
- **摘要缓存**：摘要提示词的固定部分放在前面，并补了示例，达到缓存门槛；同一配置的请求共用一个会话 ID，平台的提示词缓存可以命中。输入上限 6000 字，朗读稿上限 300 字。
- **默认人设**：boss 和各角色有默认人设，取自社区的二次元人设，可以在设置里修改或恢复默认。
- **会议点名**：一轮只点了部分员工时，议题显示被点名的人，不再一律写 `@all`。@ 显示在气泡开头，职责在前、名字在后，和头像旁的名字写法一致。
- **boss 交接**：工作区交接后，新 boss 在工作区发言前，boss 工位保持旧 boss；新 boss 发言后，工位换成新 boss，旧 boss 的头像装进相框挂在左侧。boss 下方不再写「boss」。
- **消息头像**：消息列表的头像改为方形并略微放大，名字和头像顶端对齐，气泡尖角指向头像。boss 头像改用小人，按发言时的模型显示。
- **MCP 返回更精简**：工具说明去掉重复；返回结果省略空字段；`list_members` 改为紧凑结构；子代理的前置说明压缩；派发、`list` 和读回的返回也更短，减少进入 boss 上下文的内容。

## 修复

- 宿主重启并建立新连接后，已退出的旧中继留下的回执不再让「需要重新加载」多显示约 150 秒。
- Skill 写明传 `seat` 时也要写 `role` 说明职责。

## 变更

- 摘要平台下架 Anthropic、xAI、Groq。之前选了这三个平台的设置会改回 Magpie。
- 去掉语速设置；ElevenLabs 默认模型改为 `eleven_v4_turbo`。

## 升级

- App：走应用内更新，或直接替换 App。
- 本机服务：App 启动时自动升级到 App 的版本，不需要迁移。升级后每个宿主重连一次，以加载精简后的工具说明。

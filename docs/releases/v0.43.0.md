# AgentNave v0.43.0

修复 macOS 终端里正常启动的 Pi、Claude 等宿主可能拿不到 AgentNave 工具的问题。办公室现在用本聊天第一个自定义会话标题命名工作区，改名、删除和清理会话都在办公室内完成。

## 修复

- 移除子代理嵌套识别和零工具分支。每次私聊、会议席位及原生会话续接都附加统一指令：完成分配任务后回报主控，不再调用 AgentNave，遇阻交回主控。这是模型的行为约定，Provider 原生权限仍是安全边界。
- 按天数清理会重新核对整个工作区并持有全组锁；有新增会话、新活动、待审、占用或无法确认的时间时，整组保留。
- 清理覆盖办公室展示列表之外的旧工作区；无法归组或时间不明的记录可从“其他记录”逐条选择，再确认删除。
- 自定义的 `review 任务` 等标题不会再被误判成默认 CLI 任务名。创建和改名共用同一份 Unicode 宽度数据，汉字和 emoji 的 48 列限制保持一致。

## 办公室

- 工作区名取第一个自定义会话标题；默认的 CLI 任务名顺延，后续任务标题不会覆盖工作区名。项目名显示在副标题。
- 工作区和会议室支持右键改名、删除；工作区支持 ⌘／Ctrl、Shift 多选，以及 7／30／90／180 天清理。删除前均需确认。
- 三栏分隔线可以拖动，双击恢复默认；右侧对话栏可以收起、展开。宽度与收起状态会记住。
- 移除独立“会话”页，旧 `/manage/` 地址跳转到办公室。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.43.0"
```

- 同步更新 App、本机服务和外部管理的完整 `agentnave-manager` Skill 目录。
- 已经停在零工具状态的旧 MCP 连接无法自动切换，需要重新连接 MCP 或重启对应宿主。
- 已有历史、组员配置与评审工位配置无需迁移。已有长标题保留；新建和改名时应用 48 列限制。

# AgentNave v0.18.0

菜单栏面板改为实时群聊；入口改经中继启动，此后升级本机服务后，各宿主会在空闲时自动换用新版本，托盘可一键升级服务；失败的会话不再常驻“需要关注”。

## 群聊面板

- 菜单栏面板像群聊一样按时间汇总进行中、待审核与近两小时有活动的会话：
  - 主控派出的任务与节目题目；
  - 各模型“正在输入”的最新内容与完成的回答；
  - 失败、缺席的提示。
  
  长回答折叠，点任一条打开对应会话；近两小时没有动静时列出最近会话。
- 工作室任务历史现在保存主控发出的任务原文，面板与工作台的任务详情都会显示。此前保存的任务没有原文。见 ADR-0008 第 7 条。
- 失败、受阻、中断是已交给主控的结果：面板去掉“需要处理”分组，工作台“需要关注”只收进行中与待审核的会话。

## 升级后自动换用新服务

- `agentnave-mcp` 与 `agentnave-studio-mcp` 先启动只用标准库的中继，由它把服务作为子进程运行。
- 重新安装后，中继在满足以下条件时自动换用新进程，宿主不断线：
  - 两个方向都没有在途请求；
  - 没有运行中或结果未读的调用；
  - 核心入口没开过协作组。
- 新增的工具与 Skill 文字仍需宿主重连才可见。见 ADR-0010。
- `list_invocations` 的终态新增 `result_read`，表示等待或取消是否已返回过最终结果。

## 托盘一键升级本机服务

本机服务比托盘旧时，面板提供“一键升级”：托盘调用 uv 从对应 tag 安装，必要时先卸载旧的 `agentnave-studio`，并显示进度与结果；失败时可重试或复制命令。只在点击后执行。

## 其他

- 发布元数据检查在 PR 中改以基线提交为对照，rebase 后强推不再误报。

## 升级

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.18.0"
```

随后从本 tag 更新完整的 `agentnave-manager` Skill 目录，并**最后一次**重启或重连各宿主的 MCP：v0.17.0 的服务还没有中继。此后的升级不再需要重连。菜单栏应用会在应用内提示更新到本版本；更新后，面板的“一键升级”可以代替上面的命令。

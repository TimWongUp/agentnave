# AgentNave v0.11.0

## Local workbench and discussion rooms

A private local workbench now groups **一起聊** (discussion), **各自答** (independent answers),
and **做任务** (ordinary CLI work). Search and filter conversations by purpose and ended state.
Program pages separate public dialogue from the private director desk; ordinary tasks have only
private result pages. The browser is read-only; the calling Agent remains responsible for orchestration.

All five provider adapters can participate in explicit discussion rooms, including the host CLI.
Each seat retains its own native session and receives unread public dialogue plus its own instruction.
Provider-specific restrictions limit tool use without changing ordinary invocation defaults; these
restrictions are not an OS sandbox. The director can speak publicly as the host.

Independent answers are collected directly from each CLI, sealed privately and explicitly revealed
as a round. The director can mark an unanswered seat absent, label partial results and continue
with a discussion after reveal. Exposed history is never treated as a fresh blind test.

## Upgrade and data behavior

This release adds twelve tools to the four core MCP tools. `start_agent` accepts optional `title`
and `conversation_id`, and returns conversation links alongside the existing lifecycle fields.
Ordinary calls now persist private task metadata, native session bindings and final replies. Grouping
is presentation only: it does not forward results to another CLI or change native permissions.

History defaults to `~/.agentnave/`; `AGENTNAVE_DATA_DIR` can select another fixed directory. Records
survive restart; running invocation handles do not. Busy histories are not taken over. Uninstalling
or downgrading does not delete history. Interrupted discussion histories require an explicit seat
reset before reuse; a reset does not delete provider-native history.

Install runtime and complete Skill from the same tag, then reconnect each host's MCP server and
load a fresh Skill context. Existing launcher registrations and ordinary-task exclusions remain valid.

```bash
uv tool install --force --python 3.12 \
  "git+https://github.com/TimWongUp/agentnave.git@v0.11.0"
```

## Validation

The feature passed 130 local tests and the Ubuntu, macOS and Windows CI checks. Browser verification
covered navigation, filtering, private/public views, sealed-answer display and copying. Five real CLI
providers were previously verified through AgentNave with persistent sessions; release metadata
validation does not repeat those paid calls. R3 review covered privacy and lifecycle behavior;
adversarial review found and verified a fix for recovery after consecutive write failures.

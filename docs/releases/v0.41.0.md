# AgentNave v0.41.0

App 换了个样子：所有页面并到窗口顶部一排导航，有新版本时右上角直接出现更新按钮；配色改成 macOS 的黑白色调；接入和执行者两页改成一项一行的列表，一眼看清装了什么、接没接入。

## 改进

- 顶部导航合并为一排：办公室 · 会话 · 执行者 · 接入 · 头像 · 编排。设置页去掉了大标题和第二排页签；在设置的各分区之间切换，不会丢掉执行者页还没保存的修改。
- App 或本机服务可以更新时，窗口右上角出现「↑ 更新到 vX」或「↑ 升级本机服务」，点一下就和设置页的「全部更新」一样执行。
- 配色改为 macOS 黑白中性色：浅色是浅灰底、白色卡片、黑字，深色反过来；主按钮和开关用黑（浅色）或白（深色），警示统一用橙色。
- 接入页：每个宿主一行，写明状态和 Skill 情况，右边是操作按钮；入口、配置文件和高级设置收进「详情」。已接入的宿主不再显示「未实测」。
- 执行者页：每个 CLI 名称旁显示图标和本机版本；没安装、也没在名单里启用的 CLI 折叠成一行「未安装的 CLI」。

## 修复

- WorkBuddy 桌面已经通过真实调用验证，App 里改标为已实测。

## 升级

在 App 内选择「全部更新」，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.41.0"
```

- 「全部更新」会更新 App、本机服务和由 App 管理的 Skill。手动升级时还需安装同版本 App，并把外部管理的完整 `agentnave-manager` Skill 目录（含 `references/`）更新为 `v0.41.0`。
- MCP 工具、保存的历史和 `members.json` 都没有变化，不需要重连或迁移。以前收藏的 `/settings/#hosts`、`#updates` 链接仍会打开对应分区。

# AgentNave v0.45.0

新的菜单栏图标与面板整理，同时收紧 MCP 调用：参数写错或漏传会话 ID 时直接报错，不再静默照常运行。

## 托盘

- 新 N 图标：一笔画的圆角 N，右上角一个小圆点。点击菜单栏图标时，圆点像水滴一样落下再弹回；鼠标移到 App 内的品牌图标上也会动一下。App 内图标不再加框，浅色模式下是黑色，深色模式下是白色。
- 菜单栏图标右侧显示正在运行的子代理数（如 `=3`），空闲时不显示。
- 电脑盖子上改用 CLI 图标（来自 LobeHub 开源图标库），小人仍是模型形象，二者不再混用。
- 菜单栏面板：去掉没有实际作用的升级提示，检测到更新时在右上角显示一个小的升级按钮；重画 boss 与工位之间的连线；休息中的工位不再画出，只计数。
- 面板与办公室里，久未活动的工位改叫“休息中”，不再和空闲同名。

## MCP

- 所有工具的输入 Schema 声明 `additionalProperties: false`，传入未列出的参数会整批拒绝。例如 `model`、`effort` 写在 `start_agent` 顶层时，以前会被忽略并回落到 App 默认模型，现在会报错并提示放进 `provider_options`。
- `start_agent` 与 `run_round` 必须带 `manager_session_id`（或由宿主按聊天注入 `AGENTNAVE_HOST_SESSION_ID`），否则拒绝，不再产生不属于任何聊天的记录。
- 节目续轮与主持人发言按实际身份校验归属，注入的身份不能写入其他聊天的节目；不属于任何聊天的旧节目不能再续轮或发主持人发言，仍可读取并处理待审回答；要继续讨论请新建节目。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.45.0"
```

- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.45.0 的完整目录。
- 工具接口有变，更新后请重连 MCP。历史、组员配置与评审工位配置无需迁移。

# AgentNave v0.27.1

修复工位访问等级声明的续接漏洞，并统一相关说明。

## 修复

- 已声明访问等级的工位不再续接它在声明之前留下的未声明线程。此前，一个工位先做过未声明的写入任务、之后首次声明 `access="read"` 时，自动续接会接上那条写入线程并把它当作只读；现在会开一个新线程。
- 自动续接只接与工位生效等级相同的线程。
- 显式用 `session_id` 续接本工作区已记录的线程时，该线程最近记录的等级（包括未声明）必须与本次生效等级一致，否则拒绝并提示改用另一个角色、以转发或会议传递结论。本工作区未记录过的原生线程不受此限。
- 未声明 `access` 的工位行为不变。

## 说明同步

- agentnave-manager Skill 的「问意见」「交叉复核」「分头做」「接力」场景按角色与访问等级规则改写，与「角色协作」一致。
- ADR-0018 修订写明：线程按记录时的等级归属；“会议只产出决定、不在会上改代码”只是 Skill 约定，服务端不保证。
- 文档工具表补上 `access` 参数。

## 升级

在 App 内检查更新并安装，再按各宿主卡片提示重启或重连。

手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.27.1"
```

已有会话、组员配置与 Provider 权限保持不变。

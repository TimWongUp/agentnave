# AgentNave v0.59.0

「高级」设置改为保存后才生效，编排可以按 boss 分别选档位；每次派发都带上模型和档位；Antigravity 默认放开权限；AgentNave 可以在 Windows 上原生运行；Boss 办公室换上九套宿主专属桌椅。

## 新功能

- 技能并入「高级」。技能安装、评审工位、编排档位与工位先进草稿，按「保存设置」才写入，可以放弃修改，离开设置页前会询问。各部分分别保存，失败的保持未保存，可以重试。
- 编排可以按 boss 选择档位，`orchestration.json` 增加可选的 `apps`；读同一规则文件的 boss 合成一个选项，用组内第一个单独设过的档位（ADR-0041）。
- 同时运行上限移到「员工」页，随员工一起保存。
- 选默认模型时同时写入档位，只有一档时自动写入；模型有多档却没选时报错（ADR-0042）。
- 调用最后仍没有档位时，服务按 `cli-defaults.json` 补上 CLI 自身的默认档位，回执注明 `effort (CLI default)`。boss 只在用户点名时才传 `model`、`effort`。
- 评审与 Explorer／Worker 工位补上的模型和档位不再受「单独干活」名单约束（ADR-0038 修订）；宿主排除和 boss 显式传的值照常校验。
- Antigravity 的默认档改为 `--dangerously-skip-permissions`；Antigravity、CodeBuddy、DeepSeek、ZCode 不再显示权限选项，`list_members` 报 `full`（ADR-0032）。
- AgentNave 可以在 Windows 上原生运行，托盘和服务走专用的 supervisor 与 Job Object。
- Boss 办公室新增九套宿主专属办公桌、老板椅和笔记本；普通工位的杯子和盆栽拆成独立图层，按工位固定分配。

## 修复与改进

- 技能保存失败时保留选择；编排读取途中的修改不再丢；编排文件损坏或读取失败时不给编辑。
- 共用规则文件的 boss 中，后接入的不会改掉已生效的档位。
- 打开规则文件时检查结果，失败原因显示在对应行，预览版也能打开。
- 档位探测保留没有默认模型的 CLI，不猜未解析的 Claude 别名，正确处理带 `[1m]` 的模型 ID。
- boss 模型识别保留宿主原生的模型身份。
- Windows 专属路径和探测不再混入跨平台代码。

## 升级

通过 App 更新，或手动安装配套服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.59.0"
```

- App、服务与完整 Skill 目录使用同一版本；更新后重启或重连宿主以刷新 Skill 说明。
- 历史、组员配置与认证无需迁移。旧 `orchestration.json` 含义不变；存成空的旧档位由服务兜底，下次在设置页保存时会要求补上。
- **权限变宽**：Antigravity 派发现在跳过原生权限确认。`access="read"` 只是声明，只读靠 prompt 约束。
- 此前升级说明见 [v0.58.0](v0.58.0.md)。

# AgentNave v0.49.0

换新小人，呆毛、猫耳和翅膀会动。

## 更新

- Claude 换成抱小螃蟹的橙发少女，Grok 换成戴蝙蝠发饰的金发哥特少女，Gemini 换成藏青卫衣猫娘；同步更新头像、坐姿和走路帧。
- Claude、Grok 和 DeepSeek 的呆毛会随状态摆动，工作、说话、完成和睡觉时各有不同的节奏；Gemini 的猫耳在清醒时抖动，睡觉时保持原有姿态。
- GPT 去掉呆毛，坐姿的蝙蝠翅膀持续扇动，工作时加快、睡觉时放缓；走路帧保持原有翅膀。
- 在设置里替换的小人套装继续按原有方式显示。

## 升级

在 App 内选择“全部更新”，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.49.0"
```

- 从 v0.48.0 升级时，先查看更新内容，确认后按需升级服务、安装 App 并自动重启。
- “全部更新”会更新 App、本机服务和由 App 管理的 Skill；外部管理的 `agentnave-manager` 须替换为 v0.49.0 的完整目录。
- 工具接口没有变化，无需重连 MCP。历史、组员配置与设置无需迁移。
- 从 v0.45.0 或更早版本升级、接入过 Gemini CLI 的，按 [v0.46.0 发布说明](v0.46.0.md) 处理旧配置。

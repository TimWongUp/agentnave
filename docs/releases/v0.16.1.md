# AgentNave v0.16.1

每次 CLI 调用的保留标准输出硬上限从 8 MiB 收紧到 1 MiB，包含必要的协议数据；错误输出仍为 64 KiB。采用过滤捕获的 Provider 保留原每条 8 MiB 的协议解析上限，避免正常图片或工具结果因大于回复预算而误失败；过滤后的事件不累积保存。按字节计算，超限继续报告 `output_limit_exceeded` 并终止该调用，不把不完整正文当作成功结果。

主控在派发前按交付需要和剩余上下文安排多席合计回复预算，状态查询可省略正文。普通任务的长报告、日志和附件可由 CLI 按明确指令保存文件，返回摘要与绝对路径；服务不会自动转存超长回复或传输附件。隔离节目限制文件工具，因此预先控制回答长度或分多轮，不承诺文件交付。最终回答在容量内仍完整返回，没有新增字数截断。

核心与 Studio 同步升级至 0.16.1，工具数量和权限设置保持原样。两个已安装包应从本 tag 一起升级；宿主重新连接 MCP 后加载新上限。长输出从旧版的 1–8 MiB 可成功范围变为失败，应在派发前安排文件交付；历史记录不裁剪、不迁移。

# AgentNave v1.18.0

新增 Claude 多账号：同一台机器上的多个 Claude 账号可同时在线，各自登录、各自冷却，工位与内嵌终端都能选账号。

## 更新

- **Claude 多账号**：设置 → 员工 → Claude Code 卡片新增账号区域，可新建托管账号（目录位于 `~/.agentnave-accounts/claude/<id>`，在独立登录终端里完成 Claude 原生登录）、关联已有配置目录、改名和移除；账号状态只在 App 本地显示。每个具名账号用自己的 `CLAUDE_CONFIG_DIR` 运行，默认账号保持原有环境不变；AgentNave 只向账号目录同步自己的接入与 Skill，不同步个人配置。
- **按账号派发与冷却**：评审、编排与自定义工位的主选和备选可指定 Claude 账号，同模型不同账号可互为备选；冷却按账号独立记录与解除，未登录账号会触发认证冷却并换到下一顺位；不同账号之间不能续接同一线程。`start_agent`、会议席位与 `clear_provider_cooldown` 新增可选 `account`，`list_members` 列出已登记账号。
- **办公室终端**：「+」菜单开 Claude 时可选账号，续接按工作区所属账号打开。
- **宿主环境隔离**：派发 Claude 时补齐剥离宿主会话变量，覆盖交互、`--print` 与用量探测全路径。

## 升级

- App：应用内更新或替换 App，按提示重连宿主。本版把 `agentnave.db` 单向迁移到第 5 版（工作区新增可空的 `owner_account` 列），迁移后旧版无法打开该数据库。
- 手动安装：从 `@v1.18.0` 重装运行时与 Skill 并重连 MCP（本版更新了 `agentnave-manager` Skill 文本，请替换完整 Skill 目录）。
- 从 v1.17 或更早版本升级，仍适用 [v1.17.0](v1.17.0.md)、[v1.16.0](v1.16.0.md)（含 Antigravity `agy` 1.5.10+ 要求）、[v1.14.0](v1.14.0.md) 与 [v1.13.0](v1.13.0.md) 的升级说明。

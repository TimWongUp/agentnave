# AgentNave v1.17.0

新增本机 CLI 用量统计面板与 boss 办公室会话统计，完善内嵌终端推送、续接与交互体验，并优化并发派发时的选型避让与错峰启动。

## 更新

- **用量统计面板与 boss 办公室统计**：顶栏新增「用量」页，读取本机 8 家 CLI（Claude Code、Codex、Antigravity CLI／桌面端、Pi、CodeBuddy、DeepSeek Harness、Grok、ZCode）原生日志并独立索引至 `usage.db`；提供「总体消耗」（今天 24 小时时段／7 天／30 天堆叠图、Token 分类、缓存命中率与折算花费，价表内置并低频只读刷新 `models.dev`）和「按项目」（boss 与员工消耗拆分）两个视图；Devin 因无逐调用 token 字段暂不支持。boss 办公室新增当前工作区用量简报，支持手动刷新。（#487）
- **Codex 内嵌终端**：改走 `app-server` 结构化推送，提升终端交互、推送重试与状态同步稳定性。（#486）
- **App 内 boss 推送唤醒**：任务或会议结果就绪时由 App 主动推送提醒 boss 收取；推送期间暂存用户输入并保护未发送草稿，存在未发送草稿时静默五分钟后再推送。（#483）
- **内嵌终端续接**：办公室终端支持续接 Grok 与 Antigravity 的历史聊天。（#481）
- **办公室交互与浅色终端**：boss 办公室标题栏新增「全部消息」按钮，开着终端也能一键查看全部消息；浅色模式下终端背景改为纯白并优化 Claude Code 消息条对比度。（#482）
- **终端运行状态与动画**：内嵌终端中的 CLI 未退出时，办公室 boss 与左侧终端 agent 显示「工作中」，优化点击 boss 后的右栏范围并收紧左侧项目列表间距；点击内嵌终端回到前台时恢复小人动画。（#479、#485）
- **同档随机选型避让**：同档随机选工位时优先避开当前在用模型，选出后立即内存预占直至启动或失败，减少并发重复命中同一模型。（#484）
- **派发措辞与错峰启动**：派发提示改为自然措辞，子代理可见文字统一以第一人称称呼派活人（Skill 收尾行改为「待决定」）；同一服务进程内同 CLI 相邻启动错峰 1–3 秒，降低瞬时限流。（#477、#478）

## 升级

- App：应用内更新或替换 App，按提示重连宿主。本版没有 `agentnave.db` 数据库结构变更（用量统计数据独立保存在 `usage.db` 中，首次扫描自动创建）。
- 手动安装：从 `@v1.17.0` 重装运行时与 Skill 并重连 MCP（本版更新了 `agentnave-manager` 与 `agentnave-meeting` Skill 文本，请替换完整 Skill 目录）。
- 从 v1.16 或更早版本升级，仍适用 [v1.16.0](v1.16.0.md)（含 Antigravity `agy` 1.5.10+ 要求）、[v1.15.0](v1.15.0.md)、[v1.14.0](v1.14.0.md) 与 [v1.13.0](v1.13.0.md) 的升级说明。

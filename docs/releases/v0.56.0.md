# AgentNave v0.56.0

工位会自动使用 App 中选定的模型和档位；App 显示更新进度，并在工作区对话里显示交接说明。

## 改进

- **工位设置自动套用**：`start_agent` 的 `role` 指明评审角色，或 `explorer-easy`、`explorer-hard`、`worker-easy`、`worker-hard`，且 `provider` 与该工位一致时，服务先补上工位的模型和配套档位，再套用组员默认值。显式参数优先；回执 `defaults_applied` 标明来源。工位文件缺失或损坏时不套用；值过期时仍按白名单校验并报错。
- **更新进度**：弹窗显示下载百分比、下载量、当前步骤和耗时。已发现且检查仍有效的更新直接打开更新内容；检查过期时再确认新版本。离线检查失败仍可使用已有更新，安装失败保留步骤与原因并支持重试。
- **工作区交接消息**：全部消息里显示最近一次交出的时间、交出和接手宿主（有记录时）及交接说明。长说明可以展开，内容按纯文本显示。接手时间没有记录，不以交出时间代替；不保存完整的多次交接历史。

## 修复

- 工位档位已失效时，评审 Skill 的回退指引改为显式传入有效档位；错误诊断保留真实原因和工位来源。
- App 更新与仅升级服务明确区分，避免并发检查或重试时静默切换目标；回执区分新启动与已有失败状态。
- 服务升级超时时，POSIX 下终止独立进程组并等待回收，避免 Git 或构建子进程残留。
- 交接状态变化会刷新列表摘要；再次从 App 交接不沿用旧说明，撤回交接会清除该次交出时间和说明，交接消息不会生成空线程。

## 升级

在 App 内更新，或手动更新本机服务：

```bash
uv tool install --force --python 3.12 "git+https://github.com/TimWongUp/agentnave.git@v0.56.0"
```

- App、运行时和 Skill 使用同一配套版本。未通过 App 接入的宿主须手动替换 `agentnave-manager`、`agentnave-review` 的完整目录。
- 按 App 提示刷新、重启或重连宿主，以加载新的工具与 Skill 指引；历史、员工配置和设置无需迁移。
- 从旧版更新到本版时使用旧版更新器；新的进度和重试界面在更新完成后生效。
- 更早版本的升级注意事项见 [v0.55.0 发布说明](v0.55.0.md) 及其中的历史链接。

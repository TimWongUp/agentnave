# 内嵌终端收尾：布局、配色统一与续接冲突

Status: Ready

决定的背景见 [ADR-0103](../adr/0103-tray-embedded-terminal.md)。本文只定这一次工作（分支 `feat/tray-terminal` 上、合入前）的范围和验收。决定来自 2026-11-19 与用户的逐项确认，以及会议「终端收尾与配色统一」「办公室、终端与消息布局」的结论。

## Problem

托盘办公室右栏已能运行真终端，深浅两套皮肤也能跟随 App，但还有以下问题：

- **终端行为有缺陷。** 终端页重新挂载时，重放的历史输出里的查询会再被应答一次，应答作为输入写进正在运行的 CLI。在预览里续接一段正在别的终端里运行的对话，两边都会停下。终端固定按 100×30 启动，进入右栏才缩窄，欢迎框会折断。
- **布局让终端太窄。** 右栏默认约 50 列、最多占 42% 窗宽。窄窗时的覆盖层最宽 400px。
- **办公室和右栏头部对不上。**
  - 中栏 boss 两侧的私聊/会议列表和右栏目录重复，终端开着时还会把会议室、工位挤出首屏。
  - 右栏头部在消息和终端两种模式下给同一个 boss 起了两个名字。
  - 点 boss 桌的去向与 ADR 不一致，选中框也不跟随右栏。
- **配色不统一。**
  - 消息区和终端用两个近似却不相等的底色。
  - boss 气泡是孤立的微信绿。
  - 开放工位卡的层级在深浅两套里相反。
  - 左栏标题混入身份色，红色读起来像出错。
  - 窗口右缘有 15px 异色竖条。
  - 状态色深浅不成对，设置页有引用不存在或硬写的颜色。
- **入口和标题。** agent 标题与 CLI 自己的会话名不一致。「添加项目」藏在左栏底部，用户找不到。

## Outcome

- 终端只对新输出应答查询。启动即按右栏实际行列数排版。打开一段正在别处运行的对话前，用户能看到它在哪个程序里、是运行中还是已暂停，再决定是否续接。
- 有终端的 agent，右栏默认约 80 列，同一 agent 内切换消息和终端时不变宽。窄窗下终端仍至少约 59 列，覆盖层约 92 列。
- 办公室、右栏头部、左栏用同一个 agent 标题，跟随 CLI 的会话名。点击去向和选中框与右栏实际显示的对象一致。
- 深浅两套的底色层级、气泡、工位卡、状态色关系一致，所有颜色都来自 `theme.css`。
- 左栏「项目」标题旁可以新建项目：可选已有文件夹或新建文件夹，并直接开第一个 agent。

## Scope

### 1. 终端行为

1. **区分重放与新输出。** 服务端按会话记录已交付给页面的字节水位。从水位以前读取时，只返回到水位，并标明这是重放；页面写重放段期间不向 PTY 发送任何应答，写完后照常处理新段。
2. **外观通知。**
   - 页面外观没有变化时不再通知 CLI（窗口聚焦、可见性变化都会重写 `data-theme`）。
   - 首包里的外观查询只应答一次。
   - 输出被截断后，mode 2031 订阅状态不丢。
3. **按实测尺寸启动。** 新开、重启、续接都按右栏实测的行列数启动 CLI。
4. **续接冲突确认（修订 ADR-0103「不检测跨客户端占用」一条）。**
   - 判断条件：这段聊天的中继进程存活，且不在 App 任何终端的进程树下。
   - 满足时，点「续接」先弹确认，写明所在程序（沿进程祖先找到的第一个 `.app` 名）和状态（运行中或已暂停），选项只有「仍然续接」「取消」，并提醒原处恢复后两边会冲突。
   - 未检测到时直接续接。
   - 已在 App 终端里打开时，照旧聚焦那个终端。
5. **终端外壳。**
   - 背景、光标反色、选区、滚动条改为读取 `theme.css` 的 token。
   - 覆盖 xterm 默认的 IME 合成框黑底白字和滚动顶部黑影。
   - 光标闪烁跟随「减少动态效果」。
   - 浅色 ANSI 基色在 `#eeeeee` 上原生达到 4.5:1，最低对比度仍为 4.5。
6. **结束状态。**
   - 正常退出不在终端末行写退出码，非 0 才写。
   - 退出时立即通知父页更新头部。
   - 已派活 agent 的已结束终端，可在左栏右键「关闭终端」。

### 2. 布局

1. **右栏两档宽度。**
   - 按「这个 agent 有没有终端」分两档，各自记住，同一 agent 内切换消息和终端不变宽。
   - 有终端时默认约 80 列（1440 宽约 660–690px），办公室至少约 350px；去掉 42% 上限，改按办公室最小宽度限幅。
   - 没有终端时沿用现在的宽度。
2. **窄窗规则（所有 agent 共用一套）。**
   - 921–1100px：左栏收成图标条，有终端时右栏为 `min(660px, 窗宽 − 64 − 360)`。
   - ≤920px：右栏为覆盖层，宽 `min(760px, 窗宽 − 64px)`，保留图标条。
   - ≤760px：铺满。
3. **点击与选中。**
   - 有终端时点 boss 桌，回到终端并聚焦。
   - 中栏选中框跟随右栏实际显示的对象：显示终端时亮 boss 办公室，显示某个工位或会议时只亮它。
4. **办公室。**
   - 去掉 boss 桌旁的私聊列表（私聊对象都画在开放工位里），保留会议列表（含已结束会议）。不对称排版要在预览里调好看，窄办公室下也要成立。
   - 顶栏只留 agent 标题和 boss 名字，去掉项目名和「boss 在 X 里」。
   - 左栏每个 agent 行同样只留标题和 boss 名字（运行状态看头像圆点），只有待释放的隔离目录仍另起一行提示。
5. **agent 标题。** 左栏、办公室顶栏、右栏统一显示同一个标题，按以下顺序取第一个有值的：
   1. 用户在 App 里改的名
   2. CLI 里用户起的名（Claude `custom-title`）
   3. CLI 自动生成的标题（Claude `ai-title`、Codex `session_index.jsonl` 的 `thread_name`，其他 CLI 参照 magpie 的读法）
   4. boss 首次派活写的标题
   5. 第一句话

   App 只读取 CLI 的会话记录，不写回。新开、还没派过活的 agent，在第一次对话后用 CLI 自动生成的标题：
   - Claude 新开时由 App 用 `--session-id` 预先指定会话 ID，会话记录位置从一开始就确定。
   - 其他 CLI 取同一文件夹里、终端启动后新建的会话记录，只有恰好一份时才采用。
   - 对不上时显示「新 agent」，等中继确认工作区后按聊天对应。
6. **右栏头部。**
   - 左格按当前对象命名：终端为「boss」/「Claude Code」（结束后为「Claude Code · 已结束」，悬停显示完整路径）；目录为「全部消息」；工位、会议沿用现状。
   - 「‹ 全部」留在头部原位，并且带文字。
   - 「结束」改为「结束终端」。在 App 不能续接这段聊天（含未派活的新 agent），或这个 agent 还有组员在运行时，先确认，默认焦点「取消」。
7. **新建项目。**
   - 入口移到左栏「项目」标题旁的「＋」，原来底部的「添加项目」去掉。
   - 系统窗口允许新建文件夹。
   - 选定后项目加入左栏，并立即弹出与项目旁「＋」相同的 CLI 菜单，选一个就开第一个 agent，也可以不选。
   - 项目名取文件夹名。
8. **其他。**
   - 去掉消息模式底部「只读」栏。
   - 修复未派活 agent 每次渲染都强制展开右栏、隐藏折叠按钮，导致窄窗覆盖层关不掉的问题，改为只在新开时展开一次。
   - 右栏目录的会议卡补上右键菜单。
   - 「消息/终端」切换控件改用顶栏分段控件的选中样式。

### 3. 配色（只改 token 值和引用，不重做设计语言）

1. **阅读底。** 消息区与终端共用一个阅读底色：深 `#141414`、浅 `#eeeeee`。
2. **boss 气泡。** 低饱和青绿：深 `#1f3b39`；浅色从 `#e5f4f2` 加深到约 `#cfe9e5`，私聊气泡同步调整。正文和「@全部」用气泡正文色。
3. **右栏卡片。** 卡片、成员气泡用 `--surface` 实底。
4. **办公室。**
   - 开放工位卡与所在区块同底，悬停、选中时才显示底色。
   - 区块标题由 `--faint` 改为 `--muted`。
   - 中栏底部动态栏改为实色。
5. **左栏。** agent 名字用正文色，身份色只留在竖条和头像上。
6. **细节。**
   - 办公室页取消根元素的 `scrollbar-gutter`，去掉右缘竖条。
   - CLI 图标白底补一圈 `--line` 描边。
   - 消息区左内边距对齐 16px。
   - 「收听 agent」按钮底色对齐顶栏按钮。
   - `.gi-term` 改用 `var(--mono)`。
   - 修正 `theme.css` 的缩进。
7. **状态色成对。**
   - 浅色 `--review` 提到 ≥4.5:1，深色 `--warn` 降饱和。
   - 「作答中/工作中」气泡保持实心，深浅两套调到一样醒目。
8. **设置页及其他零散处。**
   - `--panel`、`--panel-2` 改用已有 token。
   - 推理档位标签不再借用身份色。
   - 额度告警改用 `--warn`。
   - 评审状态统一引用 `--review`。

### 4. 文档

- 用 `tim-domain-modeling` 修订 ADR-0103：续接冲突的检测与确认、agent 标题来源（App 读取 CLI 会话记录，只读；Claude 新开时预先指定会话 ID，只用于定位会话记录）、点 boss 桌回终端、头部三格文案。
- `CONTEXT.md` 中「agent」的标题含义如有变化，同步更新。

## Scenarios

- **页面重载后的重放。** 切换语言后整页重载，或从设置页回到办公室：运行中的 Codex/Claude 输入框里不出现多余字符；之后切换外观，Claude 仍会换色。
- **离开期间有新查询。** 离开期间 CLI 又发了查询：重挂载后旧查询零次应答，新查询应答一次。
- **在 App 里续接正在终端里运行的对话。** 这段对话正在 Ghostty 或 Terminal 里运行，或已被 Ctrl+Z 挂起：点「续接」弹确认，写明程序名和状态；选「取消」不启动任何进程。
- **别处的 CLI 没连 AgentNave。** 检测不到，直接续接。这是已接受的局限。
- **16 寸 MacBook 半屏（约 864px）。** 终端以覆盖层显示，约 92 列；点 × 回到办公室，终端继续运行。
- **1100px 窗口。** 左栏为图标条，终端约 80 列，办公室约 376px，会议列表和 boss 桌排版成立。
- **已结束的会议。** 办公室里已不画会议桌，可从 boss 旁的会议列表点开，也可从右栏「全部消息」打开。
- **新开 Claude agent 后发第一句话。** 还没派活，Claude 生成 `ai-title` 后，左栏、办公室、右栏都换成这个标题。
- **同一文件夹里同时新开两个 Codex agent。** 候选不唯一，两者都先显示「新 agent」，等第一次派活后再按聊天对应。
- **结束 Grok 终端。** 不能续接，所以弹确认；结束空闲且可续接的 Claude 终端，直接结束。

## Accepted decisions

- **重放用服务端水位。** 不用「已读过」布尔值，也不按 `offset === 0` 静音：前者会吞掉离开期间的新查询，后者会让新会话的启动查询超时。
- **续接冲突只确认，不禁止。** 被挂起的 CLI 中继仍然存活，用户可能不知道它在哪，禁止会让用户卡住。
- **右栏宽度跟随「有没有终端」，不跟随当前模式。** `975e0f66` 已撤掉「切到终端就加宽」的跳动。
- **窄窗只用一套断点（920）。** 不按 agent 分别设断点，避免切换 agent 时右栏在并排和覆盖之间跳动。
- **目录在右栏。** 中栏只保留会议列表，因为已结束的会议在办公室别处看不到；私聊列表与开放工位重复。
- **「结束」确认不看「CLI 正在输出」。** 动画会误报，等待审批会漏报。
- **配色。**
  - 阅读底跟随 Grok 的 `#141414`，这样深色 Grok 能贴边无缝。
  - boss 气泡用固定色，不用身份色：右栏没有挂身份类，按身份变色还会在切换 agent 时跳色。
- **不让手填。** 新建项目不起名、不带第一句话；文件夹名即项目名。
- **未派活 agent 也用 CLI 自动标题。** 用户要求第一次对话后就换掉「新 agent」。Claude 预先指定会话 ID 只用来定位会话记录，工作区对应仍按进程树（ADR-0103）；其他 CLI 不能预先指定，所以只在候选唯一时采用，宁可暂显「新 agent」也不认错会话。

## Verification

- **Rust（`apps/tray`）。**
  - 在 `src/terminal/tests.rs` 扩展现有输出测试（参照 `old_output_is_dropped_past_the_limit`），覆盖四种情况：首次读取无重放标记；读到末尾后从 0 读，截到水位并带重放标记；水位后的新段正常返回；超过保留上限截断后标记仍正确。
  - 续接冲突的判断（中继存活且不属于终端进程树）沿用 `links.rs` 的中继与进程树对应，扩展 `a_relay_under_a_terminal_names_its_workspaces` 一类测试。
  - 标题读取在 `boss_app.rs` 已扫描 Claude transcript 的先例旁边做，用 fake 会话文件测试优先级。
  - 门：`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`AGENTNAVE_PREVIEW=1 CARGO_TARGET_DIR=target/preview cargo clippy --all-targets -- -D warnings`、`cargo test`。
- **前端（`apps/tray/ui`）。**
  - `node --test tests/*.test.cjs`。
  - 在 `chat-office.test.cjs` 补可观察行为：点 boss 桌回终端、选中框跟随右栏、私聊列表去掉而会议列表保留。
  - 外观去重放进 `appearance.test.cjs` 一类测试。
- **对比度。** 用一次性脚本按 `theme.css` 的最终值，核算以下前景/背景组合，结果写进 PR 说明：状态色、区块标题、boss 气泡正文与「@全部」、浅色 ANSI 16 色。
- **真实 CLI。**
  - 在终端里跑 Claude、Codex，验证重载后不出现乱码、外观仍能实时切换。
  - 补跑 DeepSeek、ZCode 的启动检查（真实调用已预授权）。
- **预览目测。** 用 `scripts/preview_tray.sh` 在 1440、1100、920、864 四种宽度，深浅两套下看办公室和右栏，确认终端实际列数（以 xterm 回报为准）。

## Acceptance criteria

- **重放。**
  - 重挂载活会话时，历史中的 DA1、OSC 10/11、DSR、`?996n` 对 PTY 产生零次输入。
  - 离开期间新到的查询恰好应答一次。
  - 新会话首包里的查询恰好应答一次，`997` 不重复。
- **外观通知。** 外观未变时，窗口聚焦、可见性变化不触发终端重设主题，也不向 CLI 发 `997`。
- **启动尺寸。** 新开、重启、续接传给 PTY 的初始行列数等于右栏实测值。
- **续接冲突。** 中继存活且不属于 App 终端时，点「续接」先弹确认，写明程序名和运行中/已暂停；「取消」不启动进程。
- **宽度。**
  - 1440 宽时，有终端的 agent 默认终端 ≥80 列（xterm 回报），办公室 ≥350px；同一 agent 内切换消息和终端，右栏宽度不变。
  - 1100 宽时终端 ≥76 列；864 宽时覆盖层终端 ≥88 列，× 可关闭。
- **点击与选中。** 有终端时点 boss 桌显示终端；任何时刻中栏至多一个选中框，且对应右栏实际显示的对象。
- **办公室与标题。**
  - boss 旁只剩会议列表，含已结束会议。
  - 办公室顶栏和左栏 agent 行只显示标题和 boss 名字。
  - 左栏、办公室顶栏、右栏的 agent 标题一致，并按标题优先级取值（fake 会话文件测试覆盖）。
  - 未派活的 Claude agent 在 CLI 写出 `ai-title` 后改用该标题；其他 CLI 只在候选唯一时采用。
- **右栏头部。**
  - 终端模式左格为「boss」/CLI 名；目录为「全部消息」；按钮为「结束终端」。
  - 不能续接，或仍有组员运行时，先确认，默认焦点「取消」。
- **新建项目。** 「项目」标题旁的「＋」能选择或新建文件夹，并接着弹出 CLI 菜单；左栏底部不再有「添加项目」。
- **配色。**
  - 消息区与终端底色相同。
  - 深浅两套中，开放工位卡与区块同底。
  - 窗口右缘无异色竖条。
  - 不存在未定义或硬写的颜色引用（`--panel`、`--panel-2`、告警硬编码色）。
  - 状态色和气泡文字的对比度核算结果 ≥4.5:1；「作答中」气泡等大面积填充除外，按用户决定保持醒目。
- **整体验收。** 所有门通过；用户在预览版里确认后才推送、开 PR。

## Out of scope

- 不支持 mode 2031 的 CLI 在切换外观时的提示或强制重启。
- 修改各 CLI 自己的配置、主题和信任记录（含测试遗留的信任条目）。
- Devin 的主题询问、CodeBuddy 饱和的改动块、Grok 暗灰被最低对比度提亮。
- 其他 CLI 的续接开放（Grok、Pi、CodeBuddy 等），以及没连 AgentNave 的外部会话的占用检测。

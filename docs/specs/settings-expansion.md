# 设置页扩展与去掉看板

Status: Ready

## Problem

托盘 App 的设置页能调的项很少：没有界面语言、主题和界面大小，没有开机启动和提醒，语音摘要只能手写要求，历史记录永不自动清理，语音缓存上限写死 200 MB。界面只有中文。

同时，用户要在三端去掉浏览器看板，Linux 只运行服务、没有 App。现有清理只在 App 里（ADR-0012），去掉看板后 Linux 上的历史既不能自动清理，也没有手动清理入口。

## Outcome

- macOS、Windows 的设置页新增「常规」「数据与存储」两个分区；员工、语音、关于分区扩充。界面可在中文和 English 间切换。
- 服务按设置的天数自动清理过期工作区，Linux 也能通过 `settings.json` 开启。
- 三端都没有浏览器看板，MCP `list` 不再返回看板链接；托盘照常显示头像和会话。
- 所有新设置的默认值等于升级前的行为，只有用户明确决定的语音摘要「标准」档例外（见语音）。

## Scope

1. 去掉浏览器看板（服务、MCP 回执、Skill、文档）。
2. 设置页底座：两个新分区、App 偏好文件、双语框架。
3. 常规分区。
4. 员工分区的提醒。
5. 语音分区扩充。
6. 数据与存储分区，以及服务端自动清理。
7. 关于分区的「自动检查更新」。
8. 界面文字中英双语。
9. 已完成待确认的「员工视图连播按屏幕显示读」修复（分支 `fix/desk-chain-read`）随本批确认和发版。

## Scenarios

- 用户关掉 App 窗口挂机跑长任务：完成或失败的提醒照常弹出。
- 会议一轮四个席位：只在整轮结束时提醒一次，某一席答完不提醒。
- 多个宿主同时运行各自的服务进程，共用一个数据根：每天只有一个进程执行清理，任何进程正在使用的会话不被删除。
- Linux 只装服务：在 `settings.json` 写清理天数即可生效；没有该键时永不清理。
- 预览版与正式版并存：预览版不执行开机启动、不触发清理，不写正式数据。
- 升级后首次启动：旧主题选择保留；没有新设置文件时所有行为与升级前一致。

## Accepted decisions

### 交付与分工

- 顺序：去看板 → 底座 → 常规、员工提醒、语音、数据与存储并行 → 双语文案最后合。
- 去看板和底座没有可见界面变化，评审后直接合并，不单独发版。四路功能和双语合成一个预览版给用户确认，再分别开 PR、评审、合并，最后发一个版本。导出 Markdown 跟随下一版。
- 分工：Antigravity 做界面（含双语），GPT（Codex）做后端，Claude 做架构（边界、合同、ADR 与架构文档），DeepSeek 做简单的活。并行写入各用独立 worktree，同一组文件同一时间只有一个写入者。

### 去掉看板

- 删除 `dashboard.py`、看板前端（`dashboard_assets` 的 `index.html`、`app.js`、`style.css`）、`Conversations.open_dashboard`，以及 MCP `list` 回执的 `dashboard_url`、`dashboard_error` 和工具说明里的看板描述。
- 保留 `views.py` 生成并写入数据库的视图快照：托盘读取它们（ADR-0008）。
- 头像资源（`avatars.js`、`avatar-*.svg`、`AVATAR-SOURCES.md`）现由 `apps/tray/src/avatars.rs` 从 `src/agentnave/dashboard_assets/` 编译进托盘，迁到托盘自己的目录后再删看板目录。
- 同步更新 Skill（`skills/agentnave-manager` 等）、README、`CONTEXT.md`、`AGENTS.md`、`docs/context/architecture.md` 中看板相关描述；`scripts/real_suite.py`、`scripts/verify_install.py` 中依赖看板的部分一并调整。

### 设置的存储

- App 自己的设置存在 `app_config_dir` 下的 `preferences.json`（与已有 `window-size.json` 同目录），按分区组织，保存时保留不认识的键。正式版和预览版的 `app_config_dir` 不同，天然隔离；Rust 能读，托盘菜单可跟随界面语言。
- 服务也要读的设置留在数据根的 `settings.json`：本次新增清理天数。App 保存 `settings.json` 时必须保留不认识的键（现 `settings.rs::validate` 只保留 `version`、`max_running`，需改）。
- 语音设置继续存在 `voice.json`。
- 主题从浏览器本地存储迁入 `preferences.json`，旧值首次读取时迁移。
- 预览版只放行写入自身 `app_config_dir` 的偏好路由；清理、开机启动和数据根写入不放行。预览版现已拒绝写 `/app/settings`（`main.rs` 的 `preview_refuses` 白名单），补一条回归测试。

### 双语

- 范围：界面文字（HTML、JS、托盘菜单）和语音摘要的输出语言。Rust 与 Python 返回的错误提示保持中文；写入宿主的 Skill 与编排偏好不随界面切换；CLI 名、模型名、用户数据不翻译。
- 框架先进底座：`AN.L("中文", "English")` 按 `<html lang>` 取词，各页面加载时按偏好设置 `lang`；跟随系统时以 `en` 开头的系统语言用英文，其余用中文。并行分支的新文字直接用它；已有文字的翻译最后由 Antigravity 补齐。

### 常规

按顺序：

| 设置 | 选项（默认） |
| --- | --- |
| 界面语言 | 跟随系统（默认）、中文、English |
| 主题 | 跟随系统（默认）、浅色、深色；顶栏和托盘面板的快捷按钮保留，三处读写同一份数据 |
| 减少动效 | 跟随系统（默认）、开、关；关掉小人走动、打字等动画和界面过渡 |
| 界面大小 | 90%、100%（默认）、115%；整页缩放，只作用于主窗口，不作用于托盘面板 |
| 开机启动 | 关（默认）、开；预览版不可用 |
| 启动时打开主窗口 | 开（默认，等于现状）、关（只驻留菜单栏或托盘） |
| 点托盘图标打开 | 托盘面板（默认，等于现状）、办公室窗口 |
| 菜单栏显示工作人数 | 显示（默认，等于现状）、隐藏 |
| 员工工作时不让电脑睡眠 | 关（默认）、开；只在有运行中的任务或席位时阻止系统睡眠，结束即释放 |

### 员工：提醒

- 提醒方式：不提醒（默认）、系统通知；旁边有「发一条测试通知」按钮。
- 提醒哪些：私聊任务和会议、只提醒会议。会议在一整轮所有席位结束时提醒一次；有答案等待审核也算这一轮结束；单个席位答完不提醒。
- 耗时门槛：不限、超过 10 分钟（默认）、超过 30 分钟；会议按整轮耗时算。
- 失败或受阻时提醒：开、关（默认关）。只看失败和受阻（`blocked`），不含待审核，不受耗时门槛限制。
- 由 App 后台轮询发出，窗口关着也提醒；App 启动时以当前状态为基线，不补发历史。

### 语音

- 摘要详细程度：简短（约 40 字）、标准（约 150 字以内，默认）、详细（约 300 字以内），字数为大约值。标准档由现在的 80–120 字放宽，升级后默认摘要略长，由用户决定。现有手写摘要要求收进语音页底部「高级」折叠区，继续可用。
- 朗读语言：跟随原文（默认）、中文、English；摘要关闭时置灰，直接读原文。
- 朗读哪些消息：全部（默认）、只读员工的回答、只读 boss 的发言、只读会议。只影响自动读和连播，手动点读总是读该条。
- 代码和路径：跳过不读（默认，等于现状）、说「这里有一段代码」。
- 语音缓存：上限 100 MB、200 MB（默认）、500 MB、不缓存；显示当前占用，可立即清空。「不缓存」时摘要和音频都不落盘。清空与正在写入的缓存要互斥。
- 详细程度、语言和代码处理方式拼入生效提示词，提升 `PROMPT_VERSION`，旧摘要缓存自然失效。
- 不做语速。

### 数据与存储

- 消息记录自动清理：永不（默认）、30 天、90 天、180 天，存于 `settings.json`。
- 由服务执行：服务启动后执行一次，之后每天一次；共用数据根的多个服务进程通过数据根下的锁保证同一时间只有一个执行。
- 按工作区判断：工作区内所有会话的最后活动时间都早于期限，且没有运行中、被其他进程持有或待审核的会话，才整组删除；删除每个会话时沿用现有会话锁协议（`locks/<会话ID>.lock`，锁内重读状态）和级联删除，语义与 `apps/tray/src/manage.rs` 的 `cleanup` 一致。
- 设置页从「永不」改为某个天数时，先显示将删除的工作区数量，确认后才保存。
- 清理归属由托盘改为服务，取代 ADR-0012 中「托盘清理、服务不负责保留策略」的部分；App 现有手动「清理…」本次保留，以后再考虑改为调用服务端逻辑。
- 数据目录：显示路径和占用，提供「打开文件夹」；只显示，不支持迁移。
- 语音缓存不在本分区重复出现。

### 关于

- 「自动检查更新」：开（默认，等于现状：启动时和每 24 小时检查）、关。不做自动下载。

## Acceptance criteria

- 三端没有浏览器看板；`list` 回执不含看板字段；托盘头像正常显示；Skill 与文档不再提及看板。
- 各新设置在 App 重启后保持；没有 `preferences.json`、`settings.json` 缺新键时，行为与升级前一致（语音标准档除外）。
- App 保存 `settings.json` 后，服务写入或手写的未知键仍在；旧版本服务读取新文件不报错。
- 切到 English 后，界面不再出现中文文字（用户数据、服务端错误除外）；切回中文与现在一致；托盘菜单随之切换。
- 清理天数设为 N 后，最后活动早于 N 天且空闲的工作区被删除；有运行中、被持有或待审核会话的工作区保留；多进程同时运行时不重复删除、不报错；未设置时不删除任何记录。
- 提醒：超过门槛的私聊任务完成、会议整轮结束各弹一次通知；单席答完不弹；失败或受阻按开关弹出；App 启动不补发；测试按钮能弹出通知。
- 语音：三档摘要长度可区分；朗读语言、朗读范围、代码处理、缓存上限与清空按决定生效；手动点读不受朗读范围限制。
- 预览版不能开启开机启动、不触发清理、不改正式数据。
- 全部验证命令通过，CI 绿。

## Out of scope

- Rust 与 Python 错误提示的翻译；Skill 与编排偏好的英文版。
- 语速；退出前确认；保留会议总结；头像风格；名字显示方式；自动下载更新；程序坞图标；全局快捷键；长消息折叠、色弱配色、说话风格、清理前自动备份、复制诊断信息、恢复默认。
- 导出 Markdown（下一版，入口放办公室工作区菜单，导出到下载文件夹）。
- 数据目录迁移；App 手动清理改为调用服务端逻辑。
- Linux 托盘 App。

# ADR-0092：无改动的隔离目录在成功结算时自动释放，续接时原位重建

- 状态：已接受
- 日期：2026-11-14
- 修订 [ADR-0085](0085-service-managed-isolated-dirs.md) 中「只显式释放」与「不自动回收未释放的目录」两条规则。
- 不改变 [ADR-0085](0085-service-managed-isolated-dirs.md) 的其余边界：默认不隔离、目录平铺在 `.agentnave-worktrees/`、仓库级锁与租约机制、`.worktreeinclude` 拷贝上限、不执行 hooks/setup 脚本、任何 boss 可跨工作区显式释放剩余目录。

## 背景

[ADR-0085](0085-service-managed-isolated-dirs.md) 为避免误删未经确认的文件，规定所有可用隔离目录必须由 boss 显式调用 `isolated_dirs` 释放。但实际编排中，「先派只读工位调查，再按同一线程续接转入实现」是高频主线：只要调查阶段为了避免冷启动而开启隔离，哪怕工位一行源码都没改，boss 也必须额外走一次显式释放；结果 boss 为了省去收尾成本而不在调查时开启隔离，一旦调查转入实现就只能另开隔离线程，丢失原有对话上下文。

参考子代理隔离的惯例，理想体验应当是：隔离目录随只读调查一起近乎零成本开启；如果任务顺利结束且相对起点没有任何实质改动，由服务直接释放；若之后要继续在这条线程上实现或深入，再无缝衔接原路径与原原生会话。

## 决定

- **严格无改动自动释放**：隔离任务在终态结算并释放自身租约后，只有同时满足以下全部条件时，服务才自动删除 worktree 目录、受管分支及 `worktrees.db` 登记：
  1. 任务终态为 `succeeded`；`failed`、`blocked`、`cancelled`、`launch_error` 一律保留，以便排查保留在忽略目录里的日志／构建现场或继续续接。
  2. 当前任务拥有该隔离目录的线程所有权（由本任务创建，或经原任务 `session_id` 续接重建／继承进入），且该隔离目录登记在当前工作区名下；借用他人隔离目录作 `cwd` 的普通任务或跨工作区借用只在结束时释放自己的租约，不触发自动删除。
  3. 释放自身租约后，该隔离目录不再有任何其他活跃租约。
  4. 在仓库级锁下重新核验工作树完整且仍未修改：HEAD 与受管分支严格停留在原 `base_oid`（捕获空提交与“提交后回滚”）、未切换或分离分支、无工作区／暂存区／未忽略未跟踪变更、无嵌套或忽略目录内的嵌套 git 仓库、无 `assume-unchanged`／`skip-worktree` 等隐藏索引标志、无进行中的 git 操作标记。
- **被忽略文件随自动释放丢弃**：符合无改动标准时，被 `.gitignore` 忽略的文件（如 `.venv`、构建缓存）随目录删除一并丢弃，不在删除前扫描保留。因此需要跨阶段保留的复现或测试脚本，必须放在未被 `.gitignore` 忽略的路径或工作区外约定位置。
- **同路径同起点原位重建**：经自动释放的线程之后携 `session_id` 续接（且不传入 `isolation`）时，因为 Claude Code、CodeBuddy、Pi 等 CLI 按 `cwd` 索引原生会话与目录信任记录，服务必须在校验 `cwd` 之前、在仓库级锁下按该任务持久化的原隔离 ID、路径、受管分支与 `base_oid` 原位重建 worktree 并重拷 `.worktreeinclude`：
  - 若期间同路径已被并发续接重建并处于 `ready` 状态，自动降级为获取该目录的新租约。
  - 若原目录是由 boss 通过 `isolated_dirs` 手动释放（而非服务自动释放）、原 `base_oid` 已被 `git gc` 清除、或目标路径／受管分支已被意外占用，则直接拒绝并报错，不静默换路径或改用新的 `HEAD` 冒充。
- **回执体现与失败兜底**：结算回执的隔离摘要增加 `auto_released` 标识并保留本次结算快照；自动释放若因仓库锁争用或 IO 异常失败，保留原目录与登记并附带 warning，不阻断任务终态返回与历史落库。

## 取舍

- **不用“diff 文件列表为空”作为唯一判据**：已有改动摘要为展示设计，不持有仓库锁、不查活跃租约，也无法识别空提交或提交后回滚；自动释放直接复用带锁删除前核验并严格比对 `head_oid == base_oid`，宁可少删也不误删。
- **失败与取消默认保留而不自动清理**：用户可能接着同一 `session_id` 追问失败原因，也可能依赖被忽略目录里的临时产物排错；真不需要时，`isolated_dirs` 对干净目录本就可以无确认一步释放，保留的代价远低于误清现场。
- **宁可拒绝续接，不静默换路径或换 `base_oid`**：换路径会令按 `cwd` 存会话的 CLI 退化为冷启动，换 `base_oid` 会让模型误以为自己还在调查时读过的同一提交上修改代码，两者都会破坏主线一致性。
- **被借用的目录不由借用方自动删除**：避免同工作区内另一只读借用任务先结束时，提前删掉仍待原线程续接或等待复核的目录。

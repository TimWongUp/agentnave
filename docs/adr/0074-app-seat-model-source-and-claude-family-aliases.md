# ADR-0074：App 工位模型作为选择来源，Claude 原生子代理使用同系列别名

- 状态：已接受
- 执行边界由 [ADR-0090](0090-quota-group-cooldown-and-host-cli-choice.md) 补充：同类 CLI 可按 boss 选择交给原生子代理、由服务启动或跳过；Claude 同系列别名规则仍适用于使用原生子代理时。
- 日期：2026-11-10
- 修订 [ADR-0068](0068-rules-hold-authorization-skill-holds-method.md) 的「归属」与「退化」：区分任务编排授权和已保存工位的模型选择，仅为 App 工位模型来源及 Claude 同系列映射明确例外；任务派发、并行写入和开会的授权规则不变。
- 「决策模型」档下工位不可用「按同难度规则兜底」由 [ADR-0087](0087-decision-model-recommends-seats.md) 修订：由 boss 从公布的目录里自选。
- 「不可用边界」中工位不可用即报告并按同难度规则兜底，由 [ADR-0089](0089-seat-fallback-order.md) 修订：先按用户配置的备选顺位取第一个可用，全部不可用才报告不可用并兜底。

## 背景

用户在 App 保存了工位模型，宿主自带子代理却可能只接受系列别名。如果把规则块视为模型选择的唯一授权来源，关闭编排或使用自定义档时，即使已有可用工位，也会丢失用户的模型选择，或被要求重复授权。用户选择让 Claude 宿主直接使用同系列别名，接受其并非精确版本，也不要求逐次说明版本或能力差异。

## 决定

- **选择来源**：用户在 App 保存的工位模型与推理档设置视同明确选择，包括 App 预填后由用户保存的值。Manager 使用当前可用工位的这份选择，原生子代理也遵从；这不授权 Manager 从宿主默认值另猜模型，也不扩大模型名单或工位可见范围。
- **Claude 映射**：宿主支持工位指定模型时优先使用；只支持系列别名时，用户保存该工位即授权将可明确归类的 Claude 模型映射为同系列别名，无需额外规则块授权，也不逐次说明版本或能力差异。系列映射不代表精确版本或能力等效，不扩展为跨系列、跨 Provider 或推理档替换。工具字段、枚举与具体传参仍由 Skill 和运行时 schema 承载。
- **适用范围**：上述选择来源与 Claude 映射在 off/custom 下同样适用，仅作用于当前可用且本次派发已获授权的工位。off 不因此开启编排或恢复隐藏工位；custom 不因此补入或改写用户正文。ADR-0068 中「删掉的授权不推定」继续约束任务派发、并行写入和开会，不能由保存工位模型推导出这些授权。
- **不可用边界**：带 `[1m]` 的系列别名（`opus[1m]`、`sonnet[1m]`、`haiku[1m]`、`fable[1m]`）按对应系列别名传递；写明具体版本又带 `[1m]`（如 `claude-sonnet-4-5[1m]`）时，因为系列别名可能指向另一个版本，仍按不可用处理，不擅自去掉 `[1m]` 或换模型。无法明确归类、不能满足必要能力或已设推理档、需要映射却没有可用同系列别名时，报告工位不可用，按同难度规则兜底；超出上述范围的特定替代仍须用户明确授权。推理档为空时不自行补，有值时只按宿主工具支持的字段和取值传递。
- **执行边界**：映射由 Manager 在使用宿主原生子代理时执行。App 仍保存工位设置，服务仍投影其模型选择；不改数据根文件、MCP 合同、Provider Adapter 的参数规则或原生权限。

2026-11-24 修订：修订上文「不可用边界」中关于 `[1m]` 的认定。此前假定 Claude Code 的系列别名不带 `[1m]` 长上下文能力，因此把所有带 `[1m]` 的工位模型一律判为不可用。经 Claude Code 2.1.331 在单个账号上实测，`opus`／`opus[1m]`、`sonnet`／`sonnet[1m]`、`haiku`／`haiku[1m]` 均解析到同一模型（分别为 `opus-5-5`、`sonnet-5-5`、`haiku-5-5`），上下文窗口均为 `1000000`（`fable` 及其他账号本次未实测）。因此系列别名加 `[1m]`（`opus[1m]`、`sonnet[1m]`、`haiku[1m]`、`fable[1m]`，大小写与首尾空格不敏感）视为等同该系列别名；写明具体版本又带 `[1m]` 的模型（如 `claude-sonnet-4-5[1m]`）因 Agent 工具只接受系列别名且别名可能指向另一版本，仍按不可用处理，不擅自去掉 `[1m]` 或替换模型，按兜底规则兜底。其余决定不变。

## 取舍

接受同系列别名随宿主变化而不锁定精确版本，避免重复授权和逐次解释；任务必要能力仍须满足。保留规则块承载任务编排授权的边界，明确工位模型选择的独立来源，避免为提供映射而给 off/custom 注入新规则或修改用户正文。

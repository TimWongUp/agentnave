# ADR-0043：服务统一追加非交互与只读说明

- 状态：已接受
- 日期：2026-11-02
- 补充 [ADR-0031](0031-prompt-only-orchestration.md)、[ADR-0038](0038-role-applies-app-seat.md)。

## 背景

boss 每次手写「不改文件、不提交、不推送、不发评论」和「这是非交互任务」，写法不一，也常漏写。统计本项目会话，401 次派发里 167 次手写了只读条款，最近 36 次里 16 次手写了非交互条款。

## 决定

- 每次派发的前缀（ADR-0031）增加非交互说明：运行中没有人能回答，需要新授权或用户选择时写进最终回答，不调用现场提问工具，不绕过原生权限。
- 任务或席位声明 `access=read` 时，前缀再加只读说明。工位推出的 `read`（ADR-0038）同样生效。
- 只读说明在回执 `defaults_applied` 注明；保存的任务原文仍是 boss 自己写的内容。
- 说明由服务入口和核心追加，不下沉到 Adapter。

## 取舍

- 说明只是约定，真正的只读仍靠 Provider 原生权限。权限放开的 CLI 仍然能写。
- 服务只加这两条与具体任务无关的说明。评审职责、返回格式和项目禁令仍由 Skill 和 boss 决定。
- 只读说明的措辞固定，boss 想放宽（如允许写临时文件）时改声明 `write`，或不声明，并在 prompt 里写清。

# ADR-0017：按主控聊天归集 App 群聊

原 `manager_session` 是 MCP 连接的 UUID，常驻宿主可能在多个聊天间共用一个连接，重连又会把同一聊天拆开。App 群聊因此改用调用方每次创建任务或协作组时提供的主控聊天 ID；宿主未公开原生 ID 时，由主控为当前聊天生成并复用一个 UUID。明确按聊天注入的环境变量仅作兜底，不扫描宿主日志或依据 CLI、目录、时间推测归属。

保存的分组键由宿主身份与原始 ID 确定性散列，并加 `s-` 前缀，与旧版连接 UUID 区分。真实身份未知时各记录独立展示；旧历史没有足够信息重建主控边界，保留内容并独立展示，不伪造归属。live 顶层改用 `connection_id` 表示服务连接。此决定修订 ADR-0013 的进程级主控身份。

Provider 原生 session 继续用于 CLI 续接，与主控聊天身份独立；自动寻找任务历史绑定限于当前主控会话。跨主控续接同一个 Provider session 可以创建当前主控的新记录，但不能把另一主控的任务记录并进来；未知身份的旧调用仍可续接旧记录。任务续接在独立于聊天的原生 session 启动锁内扫描活跃绑定并落盘，避免不同聊天在首次记录尚未保存时并发启动同一原生 session。主控聊天环境变量不传给子 CLI。

# ADR-0029：设置页只提供选择，不提供手填输入

- 状态：部分取代
- 日期：2026-10-24
- 权限参数不能在 App 编辑的取舍由 [ADR-0032](0032-cli-permission-tiers.md) 修订
- 档位条与默认模型交互由 [ADR-0035](0035-member-cards-one-row-per-cli.md) 取代
- 不手填约束由 [ADR-0037](0037-app-writes-orchestration-rules.md) 修订：允许自定义编排规则。
- 不手填约束由 [ADR-0044](0044-meeting-voice-cloud-and-key-input.md) 修订：允许语音密钥、自定义摘要连接、prompt 与人设。

## 背景

App 面向不熟悉 CLI 参数的普通用户。设置页原先在每个模型后有“配置”按钮，展开后可手填其他参数的键和值、写说明、为当前场景单独覆盖，还可以手动添加模型 ID。头像设置要手填模型 ID，接入页可手填宿主配置根目录，同时运行上限和会话清理天数是数字输入框。这些输入没有可选项，用户必须知道参数名、取值和路径才能填对；档位已经可以在档位条上直接拖动设置。

## 决定

- 设置页、头像设置、接入页和会话管理页只提供开关、单选、下拉和档位条，不提供自由文本或数字输入：
  - 去掉模型行的“配置”按钮及其展开内容（其他参数、说明、按场景覆盖、允许档位勾选与默认档位下拉）。允许档位范围和默认档位只用档位条设置；设置了默认档位时，档位条上可“改回 CLI 默认”。
  - 去掉手动添加模型；可选模型来自 CLI 探测结果与已配置的模型。
  - 头像“指定模型”改为先选 CLI、再从它的模型中选。
  - 接入页不再提供配置根目录输入；以前手动指定过的，仍显示来源并可“恢复自动”。
  - 同时运行上限与会话清理天数改为下拉选择。
- `members.json` 中已有的 options、notes、按模式覆盖继续按原规则生效，服务和文件格式不变；App 保存时原样保留。

## 取舍

- 需要特殊 CLI 参数（包括权限类参数）的用户不能再在 App 里编辑，只能保留已有值；这类需求由 boss 在调用时显式传参，或直接使用 CLI 自身配置。
- 探测失败或 CLI 不列出某模型时，无法在 App 里添加它；boss 仍可在调用时直接指定。
- 已有的按场景覆盖不再可见；档位条编辑的是当前场景实际使用的那份设置。

# ADR-0049：服务主动终止任务的情形

- 状态：已接受
- 日期：2026-11-03
- 补充 [ADR-0002](0002-lightweight-cli-subagent-adapter.md) 的执行边界，以及 [ADR-0007](0007-wait-any-ready-subset.md) 的等待语义。

Invocation 没有总运行时限，停止原则上只靠 Manager 显式 `cancel`。服务只在两种故障情形下主动终止整个进程树：

1. **输出超限**：保留的 stdout 或 stderr 超过上限时立即终止，返回 `output_limit_exceeded`，不把截断后的输出当作成功。
2. **持续重试卡死**：Provider 连续报告重试满五分钟仍没有任何输出时终止，返回 `provider_error`。只有重试事件一直在出现（相邻两次间隔不超过一分钟）才算连续；重试一次后安静下来的，视为已经恢复。

这两种都是故障判定，不是时限：任务只要还在产生输出，或者没有在重试，就可以一直运行。终态的 Invocation 句柄在进程内存里保留七天，之后过期；历史另存于会话库，不受这个期限影响。

## 考虑过的方案

- **重试卡死时只报告给 Manager，不终止**：Codex 遇到某些网络故障时会无限重试，而 Manager 只有在 `wait` 里才看得到，往往会一直等下去。由服务判定并终止，失败原因能写进终态，Manager 可以直接决定重派还是续接。

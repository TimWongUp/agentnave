# ADR-0036：本服务的 Skill 只由 App 管理

- 状态：已接受
- 日期：2026-10-30
- 修订 [ADR-0015](0015-app-host-integration.md) 与 [ADR-0030](0030-optional-review-gate-skill.md) 中“外部 Skill（包括符号链接）只标 external、跳过写入”的规则。

## 背景

`agentnave-manager` 与 `agentnave-review` 的副本只要不是 App 写的（没有版本标记、内容清单对不上、被改过，或是符号链接），App 就把它标为“由其他方式管理”，不更新也不删除，技能页把开关置灰。旧副本于是一直停在旧版本，与服务的工具不配套，界面还要额外解释这份副本归谁管。

## 决定

- 这两个 Skill 只由 App 管理。Skill 路径上已有的其他内容（包括指向别处的符号链接）在接入、刷新或打开开关时先备份其中的普通文件，再整体换成 App 的副本；移除宿主或关闭开关时同样备份后删除。符号链接只删除链接本身，它指向的内容不动。
- 只有 Skill 所在目录经过符号链接时不写入（写入会落到链接指向的别处），状态为 `blocked`，界面写“无法安装”。
- 界面不再写“由 App 管理”“由其他方式管理”这类说明；Skill 正常时不提，只在待更新、未安装、无法安装时写出。

## 取舍

- 用户手动改过或链接到别处的副本会被换掉；可从备份目录找回原文件，但备份只保留最近 30 份 Skill 文件。
- 未接入的宿主不写 Skill；开关关着的可选 Skill 路径上已有的其他副本不主动删除，打开开关即替换，移除宿主时删除。

# ADR-0008：托盘应用只读展示工作室数据，工作室写出视图快照与运行文件

- 状态：已接受（第一期：工作室数据合同；第二期：macOS 菜单栏应用 `apps/tray`；第三期起：macOS 发布产物与应用内更新；第四期：群聊面板与任务原文）
- 日期：2026-10-15
- 取代 [ADR-0002](0002-lightweight-cli-subagent-adapter.md) 中“不提供桌面状态 App”的条款；核心包边界不变。
- 视图快照改存 SQLite `views` 表，`state.json`／`views.json` 不再存在，见 [ADR-0026](0026-sqlite-conversation-store.md)。

## 背景

工作室看板是每个 MCP server 进程内的本机网页：随宿主启动、端口与路径随机，只投影本进程读到的会话，运行尾部只在内存。用户希望从菜单栏或托盘查看所有会话，不必打开浏览器；同时 Windows 也要能看。

只写一套 HTML/JS 界面，用系统原生 webview 显示在托盘面板与窗口中，另保留浏览器模式给无桌面环境：AgentNave 复用现有看板前端，不写第二套界面。

## 决定

1. 新增跨平台托盘应用（Tauri 2）：macOS 菜单栏、Windows 托盘，单实例常驻，只读展示 `~/.agentnave`（或 `AGENTNAVE_DATA_DIR`）中全部宿主的工作室会话；不是控制端，不调用 MCP 工具、不改写数据。详情窗口与浏览器看板共用同一份前端；托盘另有一个菜单栏面板，以群聊形式按时间汇总进行中、待审核与近两小时有活动的会话：主控发出的任务与题目、各模型正在写的内容与完成的回答、失败与缺席提示；点任一条即进入详情窗口。
2. 投影逻辑只在 `views.py` 一处。工作室持锁写入会话时，在 `state.json` 旁原子写出 `views.json`（版本 1）：会话摘要、导演视图与公开视图，链接指向托盘路由 `/`、`/c/<id>/`、`/p/<id>/`。未被任何服务持有的会话，扫描时在探测锁下补写缺失或早于 `state.json` 的快照。快照写入失败不回滚已保存的状态。
3. 有工作运行时，每个工作室服务每 1.5 秒维护 `live/<pid>-<随机>.json`：版本 2 只含进程号、宿主标识与运行中任务和席位的回复尾部及回报模型，由托盘叠加到 `views.json` 上；内容变化才原子重写，未变化只刷新修改时间，避免长会话运行期间持续整份写盘。无运行工作或服务退出时删除；崩溃残留由托盘按修改时间（超过约 10 秒）忽略，工作室在下次写入前清理一小时以上的文件。版本 1（每次写出运行中会话的整份快照）只为旧服务保留读取。
4. 浏览器看板保留，作为 Linux、WSL、SSH 等无托盘环境的后备，行为不变。
5. 托盘随版本发布：版本工作流把 macOS 通用（universal）`.dmg`、Tauri 更新包与 `latest.json` 附到同一 GitHub Release。更新包用 Tauri 更新签名私钥（仓库 Secret）签名，公钥写在应用配置中，且签名必须带被签版本号。应用启动时和此后每 24 小时只向该仓库 `releases/latest` 的 `latest.json` 检查一次；发现新版只提示，用户点击后才下载、校验、替换并重启，不静默安装。暂不做 Apple Developer ID 签名与公证。
6. 托盘读取 uv 工具目录中 `agentnave-<版本>.dist-info` 的名称，低于托盘版本时在面板提示。（v0.18.0 起由 [ADR-0010](0010-launcher-relay-swaps-upgraded-server.md) 修订：提示提供“一键升级”，由托盘执行 uv 安装命令，宿主经入口中继在空闲时自动换用新服务；原为只复制升级命令、由各宿主重连。）
7. 工作室任务记录保存主控发出的任务原文（`prompt`），供面板与工作台显示，修订 [ADR-0005](0005-director-controlled-discussion-rooms.md) 中任务不保存 prompt 的条款；原始工具事件与推理仍不保存。视图摘要增加最近活动时间 `updated`（消息、任务开始或结束中最晚者），属于向后兼容的新增字段，快照版本不变。

## 后果

- 运行尾部从“只在内存”变为“运行期间写入 0600 数据根下的临时文件”。尾部可能含任务正文；同一数据根的 `state.json` 已保存完整最终输出，暴露面未扩大。
- 任务原文进入数据根，可能含主控贴入的代码与上下文；它与已保存的最终回复同在仅用户可读的会话目录，删除会话时一并删除。此前保存的任务没有原文，面板只显示回复。
- 托盘不重写投影，无宿主运行时仍能查看历史；跨宿主的会话在一处可见。
- 视图快照是派生数据，结构变化需提升 `version`，托盘按版本兼容。
- 托盘新增唯一的出站请求：向 GitHub Release 检查与下载更新；仍不监听端口、不写数据根。替换自身应用包需要应用所在目录可写，装在“应用程序”中即可。
- 更新签名私钥丢失后，已安装的应用无法再验证新版本，只能手动重装换了公钥的版本；私钥须在 GitHub Secrets 之外离线备份。
- 未做 Apple 签名与公证：从浏览器下载的 DMG 首次打开须右键“打开”放行；应用内更新由应用自己下载，不受此限制。
- Windows 托盘、安装包与更新在后续阶段确定。

# ADR-0016：统一核心与 MCP 入口

- 状态：已接受
- 日期：2026-10-17
- 取代 ADR-0006、ADR-0009 的核心／工作室分层与双入口约定，以及 ADR-0010 的核心内存组固定旧进程条款。
- 工具集由 [ADR-0024](0024-consolidated-tools-and-private-review.md) 收敛为 8 个。

App 已统一承担接入、配置、展示和清理，继续让用户选择“核心”或“工作室”会使历史和工具能力取决于启动命令。用户明确选择收缩为一个核心，并允许撤销旧核心不保存历史的承诺。

发行包只保留 `agentnave`，唯一入口为 `agentnave-mcp`。同一套 MCP 服务提供完整 16 个工具；普通任务与协作组均保存历史，审核、主持人发言、隔离席位与只读看板沿用原有能力。执行、会话存储和展示仍各有内部模块，但不再是两套产品或运行时。Manager 与 Provider 的决策、权限所有权不变。

这是一项破坏性变更：旧 `agentnave-studio-mcp` 命令和模块移除，原核心用户也会保存任务原文、最终回复及会话绑定；`open_group` 要求标题并保存组状态。App 确认统一运行时已安装后，迁移各用户层已识别的旧命令，保留其他配置并备份；项目级配置和自定义 wrapper 手动处理。旧连接必须重连，原核心内存组不能迁移；已有保存会话的数据根、ID 和格式保持兼容。卸载和升级不删除历史。

统一入口仍按宿主连接启动 STDIO 服务，不引入共享控制守护进程。运行、待审及回写失败期间保持会话锁，保存完成且空闲后释放；嵌套或无法判定时仍只提供无副作用的零工具服务。中继可以在空闲时重建保存的组，不再因曾打开组而永久固定旧服务。

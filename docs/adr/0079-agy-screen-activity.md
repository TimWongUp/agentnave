# ADR-0079：Antigravity 交互活动从屏幕状态行补充

- 状态：已接受
- 日期：2026-11-10
- 修订 [ADR-0072](0072-antigravity-interactive-runtime.md) 的活动只来自 transcript 的约定。

## 决定

agy 交互运行期间，helper 从输入框上方的状态行补充思考和工具活动，状态变化时发出事件；无法识别的文字归为思考。transcript 与屏幕各自更新活动，transcript 继续负责回复和工具结果，Stop hook 继续负责结束判定。已结束的任务不因屏幕残留重新显示为运行中，后台任务和卡住判定沿用原规则。

## 取舍

transcript 在模型整轮输出完才更新，不能及时展示工具或思考；屏幕状态行能及时展示，但格式可能随 CLI 改变，因此只识别特定位置和格式，无法判定时不猜工具。

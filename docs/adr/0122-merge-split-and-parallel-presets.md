# ADR-0122：并行分工并入分工协作，两个派活档共用正文和三个开关；规则块删掉别处已有的用法

- 状态：已接受
- 日期：2026-11-24
- 修订 [ADR-0037](0037-app-writes-orchestration-rules.md) 的档位集合；[ADR-0051](0051-parallel-preset-without-recheck.md)、[ADR-0068](0068-rules-hold-authorization-skill-holds-method.md) 中「并行分工」作为单独一档、两档按并行写入由谁拍板区分的条款；[ADR-0073](0073-dispatch-by-default-with-small-task-boundary.md) 中「boss 只负责编排」由分工协作、并行分工两档共用的条款；[ADR-0087](0087-decision-model-recommends-seats.md) 中决策模型档有自己的规则块正文的条款；[ADR-0117](0117-private-dispatch-without-skill.md) 中「何时加载 Skill」同时写进规则块的条款。
- 不改变：派发是默认做法及小事边界（ADR-0073、[ADR-0110](0110-boss-writes-when-holding-context.md)）、按 boss 选档（[ADR-0041](0041-orchestration-mode-per-boss.md)）、只开会档（[ADR-0083](0083-meetings-only-preset.md)、[ADR-0091](0091-meetings-only-skill-and-auto-meeting-switch.md)）、规则只靠文字约束（[ADR-0031](0031-prompt-only-orchestration.md)）。

## 背景

分工协作和并行分工只差并行写入由谁拍板、主动开会缺省开不开，决策模型档已经把这两项做成了开关。同一件事一处是档位、一处是开关，每加一种选工位或执行的方式都要在两档各做一遍。

规则块每轮注入，而 ADR-0117 已把私聊用法写进工具描述和回执，规则块里还留着同样的操作说明；并行写入在块内写了两条。分工协作和决策模型的正文各有一份，大半逐字相同。

## 决定

- **档位**：关闭、只开会、分工协作、决策模型、自定义。两个派活档只差谁选工位：分工协作由 boss 按类型和难度从固定工位选，决策模型由决策模型从用户自建工位选。
- **开关**：两个派活档都有「并行写入由 boss 判断」「有分歧时主动开会」「boss 只负责编排」，缺省都关。前两个按档各存一份（`split_options`、`decision_options`），「只负责编排」仍是全局一份。
- **共用正文**：适用范围、授权、小事边界、只负责编排、简报、并行写入的前提、评审与验收两档用同一份；派法各一段；开关决定并行写入和开会两句，并行写入的前提和由谁拍板写在同一句。适用范围写明主会话和用户直接交谈的派生终端会话（[ADR-0109](0109-in-app-derived-sessions.md)），被派发的任务、会议席位、T3 子线程和宿主原生子代理只完成自己的任务，只开会档同文。验收句只要求用隔离目录写的改动合入，只读任务不合入。规则用中文写：App 里给用户看和改，自定义档的旧句迁移也靠原句识别；英文只省一成左右的 token。
- **删减的标准**：只删工具描述、回执、Skill 里已有的操作说明（何时加载 Skill、决策模型档的调用细节与生图步骤、回执怎么读）。决定派不派、谁能写、怎么验收的判断标准和授权句都留着，句子可以写短，小事边界保留原文。Claude 同系列别名的授权和没有生图工位时不顶替留在规则块，工具输出不能代替授权。决策模型档的生图步骤先移进 `start_agent`、`start_agents` 的描述再从规则块删除。
- **旧数据**：App 读到并行分工时按分工协作处理，并换成等价的开关：并行写入打开，主动开会照搬（缺省为开）。默认档和各 boss 里两档都有时，开关共用后只在两档原本都开的情况下才开，不因合并放宽授权。下次写文件时存成新形式；服务和手写的 `orchestration.json` 仍接受 `parallel`，服务按分工协作处理。

## 取舍

- 不同 boss 不能再分别用「须用户指明」和「boss 判断」并行写入，除非一个用分工协作、一个用决策模型；换来每种选法只维护一份规则。
- 降级到旧版 App 后，带并行写入开关的 `split_options` 会被旧版判为无效，需用户重选一次档位。
- 自定义档不迁移：旧生成句的含义没有变，用户自己的文字不动。
- 没有把小事边界一并压短：它是 ADR-0073 针对 boss 很少派发加的，别处没有，压短会退回原状。

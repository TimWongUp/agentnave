# ADR-0045：去掉浏览器看板

服务不再提供浏览器看板。`list` 只返回句柄和保存的会话，不再启动本机 HTTP 页面或返回链接；服务因此不再监听任何端口。

托盘 App 的办公室已覆盖看板的全部用途（工作区、会议、私聊、审核状态与消息流），并且能改名、清理会话，看板只是只读后备，同时维护两套前端的成本高于它的价值。用户确定三端都去掉看板：macOS、Windows 用托盘 App；Linux 只运行服务，不提供界面，boss 通过 `read_conversation` 读回会话。

服务继续生成并写入视图快照，托盘读取它们（ADR-0008）；只为看板存在的令牌、访问刷新和公开页投影随之删除。头像资源原放在看板目录、由托盘编译时引用，改放托盘自己的目录。

去掉看板后 Linux 上没有任何清理历史的入口，因此历史的自动清理改由服务执行，见 ADR-0046。

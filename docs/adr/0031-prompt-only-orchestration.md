# ADR-0031：单向编排使用派发指令约束

- 状态：已接受
- 取代 ADR-0011，以及 ADR-0016 的嵌套检测与零工具条款。

祖先进程识别会把 macOS Terminal 的特权 `login` 进程读取失败当成检测不可用，误禁用正常宿主的全部工具。用户选择将单向编排作为 Agent 的行为约定，移除运行时嵌套识别、supervisor 环境标记与零工具分支，服务正常提供完整工具。

统一核心在 Adapter 编码每次实际派发之前，为私聊、会议席位及原生会话续接添加固定指令：完成分配任务、回报 Manager、不再调用 AgentNave，遇阻交回 Manager。调用方原始任务文本继续保存在历史中。Adapter 只负责传输，不各自添加策略。

接受模型可能不遵守指令的限制；此约定不构成工具权限或安全隔离。宿主身份的尽力识别与 Provider 原生权限边界保持各自职责。

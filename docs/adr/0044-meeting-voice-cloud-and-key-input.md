# ADR-0044：会议语音使用云端引擎并允许配置摘要接口

会议语音仅使用 ElevenLabs 与 MiniMax 云端引擎，默认引擎为 ElevenLabs，功能默认关闭。用户开启并保存所选引擎的密钥后才发起合成，由托盘 Rust 端调用，页面只负责播放，密钥不回传页面，不运行本地模型。

Edge TTS 曾作为免费默认候选，但真实调用返回 HTTP 403，用户也不接受其效果，因此放弃并移除其协议实现与界面入口，不继续维护非官方接口。

长发言逐字合成会消耗较多 TTS 额度，截取开头又可能遗漏结论，因此增加可选的口语摘要：使用用户选择的快速模型把长发言改写成简短口语，再交给原音色合成。摘要结果与音频分别缓存，重播或换音色可复用摘要；摘要失败时报告错误，避免回退全文增加合成支出。

摘要优先接入 Magpie 本机网关，复用其中的供应商与动态模型目录，同时保留用户自行填写的 OpenAI 兼容接口，不绑定某一家摘要供应商。AgentNave 只读 Magpie 的端口配置，不接管其供应商认证或修改其设置。模型价格与实际速度由所选供应商决定。

只给 Magpie 和手填接口对没有 Magpie 的用户没有用，因此摘要来源改为平台列表：订阅只接 ChatGPT，走 OpenAI 面向本机应用的 Sign in with ChatGPT，令牌直接请求 OpenAI API；其余订阅的第三方接入可能违反厂商条款，不接入。其他平台用各厂商的按量 API 与两家转售平台，用户只需填密钥，每个平台单独保存密钥。

外部 API 的认证、自定义连接及用户要求的口语表达无法完全靠预设选项提供，因此设置页允许语音引擎和摘要 API 的密码型密钥粘贴框、自定义摘要接口的地址和模型 ID，以及摘要模型设置中的 prompt 与小人人设。这是用户明确要求的 ADR-0029 不手填约束的局部例外；Magpie 模型仍从其目录选择。人设定义语音中的性格、措辞与口吻，不进入 CLI 任务；修改 prompt 或人设后不复用旧摘要。密钥原子写入本机独立文件，Unix 权限为 0600。启用摘要和云端合成意味着回答内容会发送给对应服务，设置页明确告知；预览版使用自己的设置、密钥与缓存目录，以便试听而不修改正式数据。

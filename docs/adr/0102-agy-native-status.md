# ADR-0102：Antigravity 交互运行采用原生状态事件

- 状态：已接受
- 日期：2026-11-18
- 修订 [ADR-0072](0072-antigravity-interactive-runtime.md) 的 hooks、会话绑定和结束判定，以及 [ADR-0079](0079-agy-screen-activity.md) 的结束判定。

权限放开的 Antigravity 交互调用使用 agy 1.5.10 起提供的原生终端状态事件，不再安装或依赖全局 AgentNave hooks。每次调用使用私有运行日志绑定新会话；续接使用指定会话。投递仍等待实际就绪与实验刷新，transcript 提供本轮回复、工具活动和实际模型，原生状态事件与本轮 transcript 共同确认完成，包括后台任务后的最终回复。提问或其他运行时对话框受阻并保留会话及已有输出，不代答。旧版本报告升级要求，不静默切换模式；受限席位和非交互模式不变。

原生事件避免修改用户与其他应用共用的 hooks 配置，私有日志避免并发同文任务的会话归属歧义。事件或 transcript 不足以确认完成时受阻；进程所有权、启动确认、活动展示与有界清理沿用原合同。卸载时仍清理旧版留下的条目。

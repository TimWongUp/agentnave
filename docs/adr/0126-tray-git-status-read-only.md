# ADR-0126：托盘的 Git 与 PR 只显示状态，不再提供提交、推送、开 PR 等操作

- 状态：已接受
- 日期：2026-11-26
- 修订 [ADR-0115](0115-tray-git-status-and-basic-ops.md)：
  - 第 3 节「基础操作」：除打开链接外全部撤掉。
  - 第 5 节「隔离目录」中「可直接在隔离目录上提交、推送、开 PR」一条：撤掉。
  - 对 [ADR-0029](0029-settings-without-free-text.md) 的补充（提交说明、PR 标题可手填）：随操作一并失效，托盘不再有手填内容的 Git 界面。
- 不改变 ADR-0115 的适用范围（第 1 节）、只读状态（第 2 节）、数据与刷新（第 4 节）、已合并判定与手动删除（第 5 节其余各条）和自动清理（第 6 节）。

## 背景

ADR-0115 照 Claude 桌面端在托盘上加了提交、拉取、推送、开 PR、合并 PR 五个操作。实际用下来，这些事都由 agent 在用户授权下完成，托盘上的按钮是同一件事的第二个入口；用户也不方便点确认卡、填提交说明。herdr 的 Git 部分同样只有状态显示和 worktree 的建与删，不做提交、推送和 PR。用户决定托盘只保留状态。

## 决定

- **只显示状态**：会话的分支、未提交改动、领先／落后、关联 PR 的角标、CI 与评审状态照常显示，点击在浏览器打开 PR 或检查页面。
- **撤掉写操作**：托盘不再提交、拉取、推送、开 PR 或合并 PR，相应的确认卡、提交说明草拟和接口一并删除。这些事交给 agent 或用户自己的工具。
- **隔离目录不变**：列表状态、按分支关联 PR、已合并判定、手动删除与自动清理照旧。

## 取舍

- **不跟 agent 对话的用户少了一键提交和开 PR。** 托盘本来就不是独立的 Git 客户端，boss 会话或用户自己的 Git 工具能做同样的事。
- **少一个与 agent 同时改仓库的入口。** ADR-0115 为此在 CLI 工作时禁用按钮；撤掉后托盘写用户仓库只剩隔离目录的删除与清理。
- **偏离 Claude 桌面端与 t3code 的界面。** 两者都有提交和开 PR 入口；托盘的 Git 部分改为参照 herdr，只显示不操作。

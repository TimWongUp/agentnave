# Security Policy

## Supported versions

AgentNave has not published a stable release. Until the first tagged release, security fixes are
applied only to the latest commit on `main`; earlier commits and development branches are not
supported.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Earlier commits and branches | No |

## Report a vulnerability

When this repository is public and its **Report a vulnerability** button is available, use GitHub's
private vulnerability reporting: open the **Security** tab, select **Advisories**, and choose
**Report a vulnerability**. Do not disclose the vulnerability in a public Issue, pull request,
Discussion, or other public channel.

GitHub only provides this reporting channel for public repositories. Until the button is enabled,
the public launch is not complete and the repository has no external security-reporting channel.

Include the affected component and revision, potential impact, reproduction steps or a proof of
concept, and any suggested remediation. Remove credentials, provider transcripts, and unrelated
private data from the report.

The maintainer will coordinate remediation and public disclosure through the private advisory.
